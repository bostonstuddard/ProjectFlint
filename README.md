# ProjectFlint
ProjectFlint is a Minecraft overhaul mod seeking to re-envision the core Minecraft gameplay.

It will feature comprehensive gameplay overhauls, including but not limited to entire technological reworks, new progression systems, overhauled world gen, mob spawning mechanics, and more.

ProjectFlint takes inspiration from Vintage Story, TerraFirmaCraft, Better Than Wolves, real-life human history and technological advancement, GregtechCEU, and more.

AI / License info:
ProjectFlint utilizes AI for bug fixing and troubleshooting; all code is manually reviewed by a human and is verified before publishing major releases. (no guarantees for beta/alpha releases)
ProjectFlint utilizes assets from many open source, fully unlicensed works, and follows all requirements by those projects to their legal minimums.
