# Project Flint 0.1.0-alpha.22.1

## Intent
Replace the Clay Grinder's generic grindstone wheel art with the project owner's custom clay wheel while leaving alpha.22 systems unchanged.

## Player-facing behavior
The Clay Grinder's visible grinding wheel now uses the newly supplied clay-colored grindstone texture in both placed-block and inventory rendering.

## Architecture
No runtime architecture changed. The existing `projectflint:block/clay_grinder_wheel` texture reference remains authoritative; only the PNG behind that resource was replaced.

## Design reasoning
The alpha.22 grinder model was already wired to a dedicated wheel texture, so an asset-only replacement is sufficient and avoids unnecessary geometry or gameplay changes.

## Tuning snapshot
No timings, yields, stack sizes, durability values, tool speeds, recipes, or processing rules changed.

## Assets and licenses
The new 16×16 Clay Grinder wheel is the project-owner-created PNG supplied directly in chat as `minecraft_grindstone_round (1).png`. It is copied byte-for-byte into the mod with no assistant-side pixel edits.

## Advancement coverage
No advancement triggers or descriptions changed.

## Validation
Texture provenance records the direct user upload and its SHA-256 hash. The release validator permits direct owner-supplied assets while continuing to require byte-identical provenance coverage for every Project Flint PNG.

## Known limitations
Only the wheel face was replaced. The grinder's other wood/clay support textures and existing block geometry are unchanged.

## Next release pressure
Continue alpha.22 gameplay testing and add actual Clay Grinder recipes only when their progression role is defined.
