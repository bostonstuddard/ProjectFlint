# Project Flint 0.1.0-alpha.23.5

- Advanced Kiln progress indicator is now a normal left-to-right bar and no longer drains backward.
- Flint Plant Cutters durability increased to 320.
- Advanced Flint Multitool dirt harvesting now yields 3 Dirt Piles.
- Fixed inventory display names for Sleeping Bag, Crushed Stone, Baked Kiln Bottom, and Baked Kiln Top.
- Sleeping Bags recovered with the Advanced Flint Multitool retain their dye color when placed again.
- Added Mortar Brick Slabs and Crude Clay Slabs, each produced 1 block -> 2 slabs in the Clay Grinder.
- Added Unfired/Fired Clay Pot Molds and the reusable Clay Pot progression. The pot fills after two Clay blocks instead of four.
- Advanced Flint Multitool now retrieves the complete Baked Clay Kiln and Clay Grinder rather than only salvaging their materials.
- Moved stripped-log -> wooden slab processing from hand knapping to the Clay Grinder.
- Flint Axe can re-mine supported stripped logs and wooden slabs.
