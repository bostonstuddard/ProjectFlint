# Project Flint v0.31.39-b

## Recipe guide
- Removes fuel/instruction paragraphs from Brick Furnace and Fireclay Forge recipe pages. These pages show actual inputs and outputs only; machine-specific help remains in machine GUIs.
- Groups recipes sharing the same output/count/components and ingredient-slot count, cycles valid input arrangements rather than mixing combinations, and lists all accepted alternatives when hovering an input.
- Fireclay Forge Controller Wooden Grinder recipe: 32 Wooden Sheets + 32 Fireclay Brick Blocks.

## Basin
- Basin model now uses Minecraft Cobblestone and Oak Planks, with an additional wood insert visible for each supported stripped Oak/Birch log or wood.
- Right-click with a supported input to insert; empty hand retrieves one. Landing on the Basin after a jump processes one item into two Tannin at a cost of one hunger point (half a shank). Stored input persists and drops when the Basin is recovered.

## Tools and utility vest
- Wooden Pickaxe handles Stone and Crushed Stone consistently through the attack-permission, mining-progress and server harvest layers. Wooden Shovel likewise works on Dirt, Loose Soil and other soft shovel targets.
- Wooden Axe attack damage: 4.5, retaining vanilla attack speed.
- Utility Vest hand-clearing permission no longer depends on holding an empty hand. Supported vegetation follows vanilla hand loot with an extra 2% Flax Seed roll for grass. Eligible blocks successfully placed by players are recorded persistently per dimension and can be recovered with the Vest, excluding structural inventories and machine blocks. Existing pre-patch placements are not retroactively recorded.
- Fireclay masonry and Forge Controller dismantling explicitly require Advanced Flint-tier tools.

## Compatibility
- No PF-EMI integration added. The ProjectFlint recipe and processing registries remain authoritative. Full Gradle compilation requires the locally available Minecraft/Fabric/Loom dependency set; static checks are not a substitute for an actual Java compilation.

## Intent
Make the newest early-tool tier reliable and remove explanatory clutter from crafting reference pages.

## Player-facing behavior
Wooden tools reliably process their intended materials; Utility Vest privileges work while holding other items, with natural vegetation loot. Basin processing now uses visible stored wood and jumping.

## Architecture
The guide reads authoritative ProjectFlint recipe registries and presents grouped alternatives; PF-EMI remains external. Player placement evidence uses per-dimension persistent SavedData.

## Design reasoning
Grouping equivalent outputs removes redundant recipes without pretending any combination of alternatives is valid. Machine fuel instructions belong in the machine itself.

## Tuning snapshot
Wooden Axe 4.5 attack damage. Basin costs 1 hunger point per processing, produces 2 Tannin. Flax Seeds from grass while wearing Utility Vest: additional 2% chance.

## Assets and licenses
Basin uses existing Minecraft Cobblestone and Oak Planks textures. Existing provided Basin stitched texture is retained in the source/provenance archive but no longer sampled by the live Basin model. No generated textures were introduced.

## Advancement coverage
No advancements or quest events added. Personal crafting and Wooden Grinder recipe guide coverage updated.

## Known limitations
Only placements recorded after installing this patch are Vest-recoverable; earlier placements are not inferred as player-created. Prototype Basin supports only stripped Oak and Birch wood/log input.

## Validation
Validator and simulated patch application check gameplay/guide wiring, JSON validity, and external PF-EMI boundary. Full Gradle build depends on local Loom availability.

## Next release pressure
In-game verify Basin jump height, Vest placement recovery, Minecraft vanilla loot handling and recipe-guide alternation with PF-EMI active.
