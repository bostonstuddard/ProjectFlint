# Project Flint 0.1.0-alpha.21.4 — Human-made Texture Sweep and Minecraft 1.21.11 Build Fix

## Intent

Alpha.21.4 is deliberately narrow. It does two things only:

1. fixes the Minecraft 1.21.11 compile regression introduced by the support-check callbacks in the kiln/grinder blocks; and
2. replaces **every Project Flint PNG texture currently present in the project** with an exact, unmodified human-made source texture from one of the two resource packs supplied by the project owner.

No texture in this sweep was generated or pixel-edited by the assistant.

## Build fix

Minecraft 1.21.11 changed the protected `BlockBehaviour.neighborChanged(...)` signature used by the current Mojang mappings. The broken alpha.21.3 source used the older form with a `BlockPos fromPos` parameter.

The actual 1.21.11 signature is:

`neighborChanged(BlockState, Level, BlockPos, Block, Orientation, boolean)`

Alpha.21.4 updates these three classes to use `net.minecraft.world.level.redstone.Orientation`:

- `BakedKilnTopBlock`
- `ClayGrinderBlock`
- `ClayGrindingBaseBlock`

This directly addresses the six compile errors reported by the alpha.21.2/alpha.21.3 build attempt.

## Strict texture policy

This release establishes the following texture rule for Project Flint:

- no AI-generated textures;
- no assistant-generated pixel art;
- no assistant recoloring;
- no compositing;
- no resizing;
- no cropping;
- no filtering;
- no manual pixel edits by the assistant.

Every Project Flint `.png` shipped in this release is copied **byte-for-byte** from one of the two user-provided asset archives:

- `textures.zip`
- `§b§l      ⸎ §bLegendsRPG.zip`

The supplied packs contained enough usable material for the entire current Project Flint texture tree, so no external web texture was required for this sweep.

## Full sweep coverage

All **66** PNG files under `assets/projectflint/textures/` were replaced and then byte-compared against their recorded source files.

This includes the current texture families for:

- rocks / refined stone / crushed stone;
- twigs / burnt twigs / branches;
- plant fiber / bindings / reeds / string / petals;
- crude tools, multitools, Flint tier tools, and firestarter;
- forage bushes;
- dirt / dirt piles;
- clay balls, fired clay, bowls, kiln materials;
- crude/baked kiln textures;
- campfire stone and ground-component textures;
- Clay Grinding Base / Clay Grinder textures;
- Scrambled Egg and Plant Seeds.

`docs/TEXTURE_PROVENANCE.md` contains a human-readable target-to-source ledger with SHA-256 checksums. `docs/texture_provenance.json` contains the same mapping in machine-readable form.

## Gameplay behavior

No gameplay tuning, recipes, yields, durability, advancement logic, or progression behavior was intentionally changed in alpha.21.4.

The only Java changes are the three `neighborChanged(...)` API compatibility corrections and version-label updates.

## Validation

- all Project Flint JSON resources pass the project release validator;
- every Project Flint PNG has an entry in the texture provenance map;
- every destination PNG is verified byte-identical to its recorded source archive entry;
- the corrected `neighborChanged(...)` signature was checked directly against the cached Minecraft 1.21.11 Mojang-mapped `BlockBehaviour` class;
- the normal Gradle build cannot be executed inside this artifact environment because the Fabric Loom 1.14.10 plugin artifact is not available to the local Gradle plugin resolver, but this is separate from the user-reported Java compile failure.

## Known limitations

Because this release forbids all assistant-side pixel editing, some source textures are deliberately reused or are only approximate matches for the custom item's exact concept. Future replacements should be authored by a human or imported unchanged from a clearly approved human-made source.

## Player-facing behavior

- All visible Project Flint textures now come directly from unchanged human-made source files in the two approved user-provided packs.
- The previous support-dependent kiln/grinder blocks retain their intended support behavior, but now use the correct Minecraft 1.21.11 callback signature so the project compiles past those errors.
- No recipe, yield, durability, combat-stat, timing, or progression values were changed.

## Architecture

The only code-level compatibility change is the `neighborChanged(...)` API correction in three block classes. Texture loading remains standard Minecraft resource-pack behavior; the provenance documents are release metadata only and do not add runtime systems.

## Design reasoning

The texture sweep intentionally prioritizes provenance over visual uniqueness. If the available human-made source pool does not contain an exact conceptual match, an unchanged approximate human-made source is preferable to assistant-authored or assistant-edited art. This keeps every shipped texture traceable and lets future human-authored replacements be swapped in without changing IDs or gameplay.
