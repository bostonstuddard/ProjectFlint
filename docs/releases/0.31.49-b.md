# Project Flint v0.31.49-b — Hardwood and Field Guide corrections

## Intent
Align real Hardwood mechanics, recipe-discovery screens and survival instructions with the intended progression, while preventing renewable Fat fuel from replacing a paid resource.

## Player-facing behavior
- Newly placed Fat-Burning Torches hold **zero** fuel. Apply **Fat** to the placed torch and use a Firestarter before it can burn. Breaking/replacing the torch does **not** refill fuel. The torch's crafting recipe is Stick + String + Charcoal, with Fat separately provided to start the light.
- All existing Wooden Axe Log/Stripped Log → 2 Planks crafts accept a Hardwood Axe as an alternate tool, without consuming the axe; a durability point is charged.
- Hardwood Crafting Table costs two Hardwood Alloy, Cobblestone and a **Bound Wood Processor**.
- The recipe guide's Basin station displays Planks → Wood Dust and its Fireclay Forge station displays Hardwood + Charcoal → Hardwood Alloy, processed for five minutes.
- The Field Guide contains current in-world mechanics, instructions and recipe information. Development/release commentary and registry identifiers are not displayed.

## Architecture
- Fat Torch block entities default to 0 charges; saved charges remain saved, without a missing-NBT fallback that recreates fuel.
- Fireclay Alloy and Basin Wood Dust already existed in gameplay logic; this update adds their entries to the separate K-key recipe presentation, and aligns the Forge material tooltip with the recipe.
- Item tag `projectflint:plank_cutting_axes` provides alternate tool matching for the durable Log-to-Plank recipe serializer, preserving its built-in tool wear behavior.
- Exact Hardwood Crafting Table (3x3) and crafting material recipe JSONs are authoritative; no ProjectFlint-side EMI integration is added.

## Design reasoning
A placed fuel-burning torch must not regenerate fuel by being recovered. The axe upgrade should be interchangeable with the earlier axe in existing wood crafts. Every accessible progression operation must be discoverable without developer context.

## Tuning snapshot
- Torches: 0 initial Fat charges; each use of Fat adds 1; burning one charge remains 30 minutes.
- Basin: 1 Plank → 1 Wood Dust; 1 hunger point lost as previously implemented.
- Fireclay Forge: 1 Hardwood + 1 Charcoal fuel → 1 Hardwood Alloy in 6000 game ticks (5 minutes).
- Hardwood Table: 2 Hardwood Alloy + 1 Cobblestone + 1 Bound Wood Processor.
- Log crafts: existing 2-Plank outputs, axe durability cost of 1 per craft unchanged.
- Hardcore mining, fish behavior, crafting delay and tool balance unchanged.

## Assets and licenses
No new art; all existing user-authored block and item sprites are retained. The Handbook uses in-game icons.

## Advancement coverage
Minecraft advancements remain retired in favor of Flint Quests. This release does not add new progression triggers or direct quest/EMI ownership.

## Known limitations
The full Gradle/Minecraft client runtime is not available in this environment. Code and resource checks do not demonstrate a live Forge or Basin playtest.

## Validation
1. Craft a Fat Torch, place it, try lighting without Fat; refuel, light, break and replace it. Verify no free charge returns.
2. Craft Hardwood Table from the Bound Wood Processor (not recovered Lumber Processor).
3. Craft Log/Stripped Log → Planks with Wooden and Hardwood Axes and verify tool durability/retention.
4. Feed Planks to Basin and use K-key Basin recipes; feed Hardwood and Charcoal to a working Fireclay Forge and confirm K-key recipe entry and 5-minute output.
5. Use G-key manual, search and Item Atlas, and review all sections for only current player instructions.
6. Run validator, build with Java 21 and test under Fabric 1.21.11.

## Next release pressure
Gameplay testing should focus on timed Forge output, alternate-tool crafting and fuel state persistence across saves and world reloads.
