# Project Flint v0.28.17-a — Wattle and Daub Construction

## Intent
Introduce the first deliberately weak-but-buildable shelter material tier between loose primitive materials and later masonry, using Project Flint's existing reeds, twigs, string, dirt, leaves, water, campfires, and kilns.

## Player-facing behavior
- Work 12 Crude Reeds in the main hand with 12 Twigs in the offhand to produce 4 Wattle.
- Work 1 Wattle with 1 Crude Plant String to produce 1 Tied Wattle.
- Use a Dirt Pile directly on water to produce a Mud Pile.
- Use a Mud Pile on any leaf block to consume the leaves and produce a Daub Pile.
- Use a Daub Pile directly on water to produce a Wet Daub Pile.
- Work 4 Tied Wattle with 2 Wet Daub Piles to produce 2 Unfired Wattle and Daub.
- Fire 1 Unfired Wattle and Daub in the permanent primitive campfire, Baked Kiln, Mortar Kiln, or Advanced Kiln to produce 3 Wattled Daub Bricks.
- Wattled Daub Bricks are gravity-sensitive structural blocks.
- A load-bearing column is capped at 4 blocks tall.
- A valid four-high column can support connected brick ceiling pieces up to 2 blocks outward in each cardinal direction.
- A fifth vertical brick is invalid, and unrelated BlockItems cannot be placed directly on top of Wattled Daub Bricks as a spacer exploit.
- The bricks can be broken by hand or any tool. Ordinary breaking crumbles one brick into 1 Crude Reed + 2 Twigs.
- A Flint Multitool or Advanced Flint Multitool recovers the Wattled Daub Brick intact instead, costing 1 durability.

## Architecture
`WattledDaubBricksBlock` owns the structural support calculation. It uses scheduled neighbor updates and falling-block entities rather than encoding support state into block properties. Vertical foundation checks and horizontal ceiling-reach checks are centralized in the block so the four-block height rule and two-block roof rule cannot drift apart.

The existing `StoneWorkingSystem` gains three deterministic handworking operations for Wattle, Tied Wattle, and the Unfired Wattle-and-Daub assembly. Water/leaf transformations stay in `PrimitiveInteractionSystem`. Timed firing uses `PrimitiveProcessingRegistry`; the Advanced Kiln receives a matching direct firing path through its processing input slot.

## Design reasoning
The material should be useful enough to create the first real shelter but intentionally inferior to later masonry. Gravity, a strict four-block vertical limit, short ceiling reach, and destructive hand recovery prevent it from becoming an effortless permanent building material. Flint-tier recovery represents the point where the player can dismantle early construction without destroying it.

The original three-block concept was raised to four blocks for practical interior headroom. Every dependent structural rule in this release uses the same four-block load-bearing requirement.

## Tuning snapshot
- 12 Crude Reeds + 12 Twigs -> 4 Wattle.
- 1 Wattle + 1 Crude Plant String -> 1 Tied Wattle.
- 1 Dirt Pile + water -> 1 Mud Pile.
- 1 Mud Pile + 1 leaf block -> 1 Daub Pile.
- 1 Daub Pile + water -> 1 Wet Daub Pile.
- 4 Tied Wattle + 2 Wet Daub Piles -> 2 Unfired Wattle and Daub.
- 1 Unfired Wattle and Daub -> 3 Wattled Daub Bricks when fired.
- Maximum load-bearing column height: 4 blocks.
- Maximum supported ceiling reach: 2 horizontal blocks from a valid four-high column top.
- Crumble recovery: 1 Crude Reed + 2 Twigs.
- Intact recovery: Flint Multitool or Advanced Flint Multitool, 1 durability.

## Assets and licenses
No Wattle/Daub texture pixels are included in this release by explicit request. The new items and block intentionally have no finished Project Flint item/block art resources yet. Texture hookup is deferred until the owner supplies the finalized artwork.

## Advancement coverage
Added milestones for Wattle, Tied Wattle, Mud Pile, Daub Pile, Wet Daub Pile, Unfired Wattle and Daub, and Wattled Daub Bricks. Inventory fallback tracking was also extended so obtaining these items cannot leave their milestones stuck.

## Known limitations
- New Wattle/Daub visuals intentionally render as missing/null assets until the dedicated texture follow-up.
- The Advanced Kiln reuses its existing process-input slot for Unfired Wattle and Daub; a more general heat-processing GUI can replace this later if the kiln system is broadened.
- The structural system supports cardinal two-block ceiling projections from valid four-high columns; it is not a full engineering/weight simulation.

## Validation
- New and modified JSON resources parse successfully.
- Project release validator checks the 4-block height cap, 2-block ceiling reach, recipes, material transformations, crumble/intact recovery behavior, version format, and intentional absence of new Wattle/Daub texture pixels.
- `tools/validate_release.py` passes for v0.28.17-a.
- A full Gradle `compileJava --offline` was attempted, but this sandbox cannot resolve the uncached Fabric Loom `1.14.10` plugin artifact, so a successful full Gradle build is not claimed.
- A standalone `javac` dependency check was also attempted, but the supplied project-local cache does not contain all of Minecraft/Fabric's external compile-time libraries outside Loom; this did not produce a meaningful full-project compile result.

## Next release pressure
The immediate follow-up is the dedicated Wattle/Daub texture pass using the owner's finalized assets. After the shelter material is visually complete, this construction branch can naturally expand into framed walls, doors/openings, roof materials, drying behavior, insulation/shelter value, and later timber-frame or plaster upgrades.
