# Project Flint v0.31.64-b — Wooden Progression, Bushes and Forge

**Intent:** Restore early wooden-tool availability; prevent recipe duplication and unnecessary fuel loss.

## Player-facing changes
- Fixed missing personal Wooden Axe, Pickaxe and Shovel recipes. Added 2×2 Sword and Hoe alternatives; the Hardwood Table still supports its separate wooden tools.
- Fixed Oak Wooden Sheets and Boards missing in personal crafting and appearing twice at the Hardwood Table. Personal yields: 3 Sheets or 1 Board. Hardwood Table yields: 4 Sheets or 2 Boards for any plank type.
- Wearing a Tanned Utility Vest now lets you clear vanilla Bushes, Firefly Bushes and Dry Grass, but never mine stone or ore.
- The Fireclay Forge can relight for another valid Charcoal processing batch. It never spends Charcoal without a compatible input and output space.

## Architecture and decisions
- `RecipeManagerMixin`: filter vanilla crafting namespace, not personal ProjectFlint recipes. Preserve custom durable crafting with returned tools.
- Specific Oak sheets/boards are personal recipes; universal `#minecraft:planks` variations belong to Hardwood-only.
- Utility Vest target list extended for modern vanilla flora only.
- Forge idle-tick guard triggers `ignite()` for valid charcoal recipes with working Firestarter; wood fuel remains manually ignited.
- ADR 0023 records these durable decisions.

## Tuning and assets
- No changes to tool damage/speed, stone restrictions, Basin odds, mining drops, lighting, item textures or new assets. Forge cycle remains 6000 ticks with fuel/Firestarter consumption per charge.

## Quests and reference coverage
- Existing Flint Quests break events remain unchanged. G Field Guide Fireclay instructions now match automated valid batches. K personal reference includes Sword and Hoe and retains existing Wood Tool and Oak yields.

## Verification / limitations
- Static resource and regression checks should be run on the reconstructed v0.31.63-b base plus this update. This release is not a demonstrated full Gradle build or survival playthrough in this environment. Manual checks: first Wooden Axe in 2×2, personal Oak sheets/boards, vest bush/dry grass, Forge automatic valid burn and idle-block guard.
- Flint Axe joins Wooden/Hardwood Axes in the personal Log-to-Planks ingredient tag, making the first Planks obtainable before Wooden Axe crafting.
