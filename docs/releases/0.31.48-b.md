# Project Flint v0.31.48-b — Field Guide rendering hotfix

## Intent
Stop the confirmed client crash when the player presses G to open the v0.31.47-b Field Guide, without disrupting any mod gameplay systems or the existing guide content.

## Player-facing behavior
- Opening the **G**-key Field Guide should no longer trigger Minecraft's single-blur-per-frame safeguard.
- The rest of the screen is unchanged: leather frame, parchment background, 25 chapters, searching, pagination, item atlas, hover item tooltips and Recipes shortcut.
- Background behind the book is darkened with a simple translucent overlay instead of a separate blur pass.
- **K** still opens the existing Recipe Guide unchanged.

## Architecture
- v0.31.47-b called `Screen.renderBackground(GuiGraphics, ...)` inside `ProjectFlintFieldGuideScreen.render()` before drawing the book. The reported Minecraft 1.21.11 crash follows `Screen.renderBackground` → `GuiGraphics.blurBeforeThisStratum` → `IllegalStateException: Can only blur once per frame`.
- The single changed render operation is `g.fill(0, 0, width, height, 0xA0000000)` which does not invoke the blur pipeline. The existing opaque book panel, page, icon, scissor, tooltip and `super.render` logic remain as before.
- No mixins, server packets, registries, blocks, crafting, quests or EMI integration were touched.

## Design reasoning
Avoiding repeated blur work makes the Field Guide safer alongside other UI hooks and screen effects. A translucent backdrop performs the visual separation needed by this opaque book UI without relying on exclusive ownership of the frame's blur pass.

## Tuning snapshot
- New mining, combat, crafting, recipe, durability or progression changes: **none**.
- Default shortcuts remain **G** (Field Guide) and **K** (Recipe Guide).
- Field Guide content remains **25 chapters** plus the automatically populated Item Atlas.
- Screen overlay: **0xA0000000** (semi-transparent black).

## Assets and licenses
No new textures, models, fonts or external assets. Overlay is a built-in `GuiGraphics.fill` operation.

## Advancement coverage
No changes to Flint Quests or advancement systems. The manual remains a client-side, read-only reference screen.

## Known limitations
- The crash was reproduced in the supplied log, but no Minecraft client runtime is available for an in-game verification of the patch.
- Existing unrelated resource-load warnings about Leather Backpack equipment data and Drying Rack texture references were observed in the log and not changed as part of this targeted hotfix.

## Validation
1. Build v0.31.48-b from the fully patched v0.31.47-b source.
2. Launch the Fabric 1.21.11 client with the same mod set as the report, enter the world, then press **G**. Verify no `Can only blur once per frame` crash.
3. Navigate chapters/pages, use the search bar, scroll, and hover items in Item Atlas. Open Recipes through the guide and close to return; test K independently.
4. Confirm Hardwood Hammer/Hardwood Pickaxe speeds and all prior progression mechanics unchanged.
5. Run source validator; compile GUI class against Minecraft 1.21.11 mappings; verify patch-only archive integrity.

## Next release pressure
If visual/interaction issues remain, evaluate the handbook's small-GUI layout, item tooltip integration and recipe-guide navigation during a full client playtest; avoid widening a dedicated crash fix into unrelated changes.
