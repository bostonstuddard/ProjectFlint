# Project Flint v0.31.69-b — Hardwood Crafting and Weak Dynamite Tuning

**Baseline:** v0.31.68-b · **Minecraft:** 1.21.11 Fabric · **Release type:** root-relative source patch.

## Player-facing changes
- Packed Mud and Mud Bricks (including slabs, stairs and walls) now use the Fireclay Brick recovery tier: a qualifying pickaxe-capable tool is required, and recovered blocks drop intact. Bare hands and the Utility Vest cannot mine them.
- New Hardwood Table recipe: five Wood Dust (top row and middle left/right), one filled Clay Water Bucket or vanilla Water Bucket (middle), and three Tannin (bottom row) make one Hardwood. Only the water is used; the empty bucket remains.
- Weak Dynamite reaches ordinary Iron/Copper/Coal Ore up to **3 blocks** away and can destroy up to **four** ore blocks per charge.
- Weak Dynamite reaches ordinary Stone/Cobblestone/Andesite/Diorite/Granite up to **2.25 blocks** away and can destroy up to **two** rock blocks per charge. Rock targets retain their 65% chance to break.
- The fuse is now 3 seconds; explosion damage remains 12, and each independent Basin material roll now uses 1.25× its normal probability, including guaranteed-plus-bonus drops above 100%.
- Deepslate, machines, high-tier geology, and other blocks remain protected from Dynamite. The original personal Hardwood recipe is unchanged.

## Validation and release notes
- Verify both versions of the Hardwood Table water-bucket ingredient return an empty container, including shift-click crafting.
- Confirm Dynamite caps (four ores, two rocks), permitted block allowlist, distances, random targeting, independent yields, and no changes to entity damage radius.
- Static source, recipe JSON and ZIP tests are complete for this patch. A full Gradle build and live Fabric gameplay test have not been performed here.
