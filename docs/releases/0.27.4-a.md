# Project Flint v0.27.4-a

Targeted bugfix and food-information update following v0.27.3.1-a.

The release fixes advanced tool-piece world rendering, removes the stray inventory-cover border lines, hardens Drowned trident removal at spawn-equipment assignment time, fixes completed-rest regeneration, rebalances steak and cooked porkchop, exposes hunger/saturation values on all food tooltips, documents the Leather Backpack's 1.05x hunger-drain tax in-game, and increases raw-meat sickness penalties.
