# Project Flint v0.31.53-b — Fat-Burning Torch Wall Orientation Hotfix

## Player-facing changes
Fat-Burning Torches mounted on a wall now lean away from the supporting wall with the same orientation as vanilla and Flint Torches. This applies to all four directions, both unlit and lit forms, including existing placed torches. Flames/smoke appear at the torch tip, and the selection outline follows the wall mount.

## Technical cause
The custom wall model uses `minecraft:block/template_torch_wall`, which is based on the east-facing model. Project Flint previously treated north as the unrotated model, causing a 90-degree rotation mismatch on every wall direction.

## Exact fix
East = 0°, south = 90°, west = 180°, north = 270°. Both `lit=true` and `lit=false` share the mapping. The standing model remains unchanged. The block also now reuses Minecraft's vanilla Wall Torch selection shape for wall positions and offsets the flame particles along the mounting direction. Rotation/mirroring preserves the FACING property when transformed by commands or structures.

## Behavior preservation
Placement and support survival, Fat addition, ignition, fuel consumption, crafting, light output and prior balance are unchanged. No asset images or textures have been replaced.

## Validation and limitation
JSON parsed successfully; all ten state mappings (2 standing + 8 wall) checked against the native vanilla/Flint Torch mapping; and the ZIP layout was validated. Full Gradle build and in-game smoke test are still required.

## Intent
Correct the broken Fat-Burning Torch orientation without changing progression.
