# Project Flint 0.1.0-alpha.21.2 — Kiln Fuel Visibility, Clay Grinder Visual Pass, Advancement Coverage, and GUI Repair

## Intent

Alpha.21.2 is a fidelity/polish repair pass on top of alpha.21.1. It addresses the misleading always-fueled kiln visuals, the Clay Grinder screen immediately closing, the missing advancement coverage for the newest kiln/clay/grinder content, and the obvious placeholder-food visuals for Scrambled Egg and Plant Seeds.

A secondary goal is asset discipline: when a usable source existed in the user-provided packs, this patch should use or derive from those inputs rather than continuing to lean on throwaway placeholder art.

## Player-facing behavior

- Empty baked kilns no longer show branch fuel.
- Baked kilns with stored branches now show a clearer twig/branch bundle.
- The Clay Grinding Base and Clay Grinder now read as more coherent primitive grinding stations.
- The Clay Grinder UI now stays open correctly.
- New advancements now cover Super Heated Clay, Clay Grinding Base, Clay Grinder, Scrambled Egg, and Plant Seeds.
- Scrambled Egg and Plant Seeds now use dedicated Project Flint item textures.

## Architecture

The grinder fix adds a small `ClayGrinderMenu` class that subclasses `StonecutterMenu`. It keeps vanilla stonecutter behavior but overrides `stillValid(...)` so the container validates against `projectflint:clay_grinder` rather than immediately closing because the backing block is not `minecraft:stonecutter`.

The baked kiln presentation is now split between a persistent body model and a conditional fuel overlay. The blockstate always applies the kiln body and only applies the fuel overlay for `branches=1..8`.

Advancement coverage was extended through new JSON resources plus targeted awards in the relevant interaction code for the impossible-trigger milestones.

## Design reasoning

The previous kiln/grinder implementation was functionally close to the requested chain, but its presentation quality and UX reliability were still below the rest of the early progression. This patch therefore prioritizes trustworthiness and readability:

- visuals should match state,
- the grinder screen should not fake-open and collapse,
- new systems should have advancement guidance,
- and texture work should prefer the user-supplied packs before inventing more placeholder art.

## Tuning snapshot

No numeric progression or balance values changed in this patch.

## Assets and licenses

This patch preferentially reuses or derives from the user-provided packs:

- branch/twig visuals derive from the supplied LegendsRPG twig assets,
- grinder/base stoneworking visuals derive from the supplied texture pack's stonecutter / grindstone assets,
- plant-seed visuals derive from the supplied texture pack's seed assets with a Project Flint-specific edit pass.

No additional web-sourced external art was required for this patch.

## Advancement coverage

Added advancement coverage for:

- `projectflint:super_heated_clay`
- `projectflint:clay_grinding_base`
- `projectflint:clay_grinder`
- `projectflint:scrambled_egg`
- `projectflint:plant_seeds`

## Validation

The static Project Flint release validator passes after the alpha.21.2 version/resource update.

Changed JSON resources were checked for parse validity, model/blockstate references were updated to existing assets, and the Clay Grinder container path was refactored to a custom Stonecutter-backed menu shell so the server-side open/validity path no longer depends on the vanilla `minecraft:stonecutter` block check.

## Known limitations

The Clay Grinding Base still does not visually show partial stone insertion progress; only the final Clay Grinder state is visually distinct. This is acceptable for the current concept pass but should be improved later.

This patch does not attempt a full replacement sweep for every remaining placeholder clay/kiln art in the project; it focuses on the specific regressions and low-fidelity assets identified in this report.

## Next release pressure

- Give the Clay Grinder its first real recipe/output set beyond the UI shell.
- Add visible progress feedback to the Clay Grinding Base as stones are inserted.
- Continue replacing any remaining obvious placeholder textures in the clay/kiln chain with sourced or hand-authored pixel art.
