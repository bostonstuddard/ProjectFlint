# Project Flint v0.28.7.1-a — Kiln Animation Hotfix

## Scope
This is a small visual follow-up adding the supplied active/lit kiln animation sheets.

## Advanced Kiln
- `active=false` keeps the existing static front/top textures.
- `active=true` now uses animated front textures on both front columns.
- Top-layer casing blocks use the animated top texture while active, including the rear top blocks so the entire exposed 2×2 top surface animates consistently.
- Side, back, and bottom faces remain unchanged.

## Mortar Kiln
- `lit=false` keeps the existing static model.
- `lit=true` now selects `mortar_kiln_active`, which uses the animated front and animated top textures.
- Branch count does not affect the active-face routing.

## Asset handling
The two user-provided animation sheets were copied byte-for-byte:

- `advanced_kiln_front active.png` → `assets/projectflint/textures/block/advanced_kiln_front_active.png`
- `advanced kiln top active.png` → `assets/projectflint/textures/block/advanced_kiln_top_active.png`

No texture pixels were modified. Each strip uses standard Minecraft `.png.mcmeta` animation metadata with a 2-tick frame time.

## Version/build workflow
- Project version advanced to `0.28.7.1-a`.
- Added `APPLY_PROJECTFLINT_0_28_7_1_A.bat`.
- `build.bat` calls the new cleanup/apply script and expects `projectflint-0.28.7.1-a.jar`.
