# Project Flint v0.31.60-b — Glass transparency, PMI Sheets and build distribution

**Base:** v0.31.59-b source. **Platform:** Minecraft 1.21.11 Fabric, Mojang mappings, Java 21. **Output:** patch-only ZIP, no nested folder.

## Player-facing changes

- Pure Mica Insulated Glass now acts like regular transparent Glass, transmitting sunlight and block light. It keeps a translucent blue-gray appearance and remains vest-only to recover intact without Silk Touch.
- New non-placeable PMI Sheets: 1 Pure Mica Insulated Glass + 1 Bone Knife = 2 PMI Sheets in personal 2×2 or the Hardwood 3×3 Crafting Table. Bone Knife loses one durability per craft.
- G Field Guide and K crafting guide entries now match these recipes and light behavior.

## Build developer improvements

- Both Gradle wrapper/bootstrap invocations in `build.bat` use `--no-daemon`. `gradle.properties` disables persistent daemons for direct builds too.
- Only on success and after the existing nested PF-EMI audit, copy `build/libs/projectflint-0.31.60-b.jar` to `dist/projectflint-0.31.60-b.jar`, remove older Project Flint release JARs from `dist`, and select the produced JAR in Explorer. Source/dev JARs are not distributed.
- Build failure retains error exit, does not publish an artifact, and does not invoke broad Java process termination.

## Technical details

- `TintedGlassBlock` → `GlassBlock` with `Blocks.GLASS` properties. Translucent render layer unchanged. Visual textures derived from existing approved glass palette.
- Added `PMI_SHEET` regular item, Creative listing, item definition, generated item model, translation and texture; two durable craft recipes, G/K guide entries.
- See ADR 0019 and `docs/CURRENT_SYSTEMS.md` for the current contract. Historical v0.31.58-b tinted-glass details remain historical, not authoritative.

## Verification

Run `python tools/validate_03160.py` for static/resource checks and ZIP integrity; full Gradle build and Minecraft runtime tests cannot be confirmed in this environment. Manual playtest requirements: light transmission/glass appearance, vest recovery, 2×2 / 3×3 craft and tool wear, no placeable sheet, clean dist and nonpersistent Gradle processes on Windows.
