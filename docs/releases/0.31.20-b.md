# Project Flint 0.31.20-b

## Intent
Retire the old advancement progression layer in favor of Flint Quests, close the Grinder twig/branch duplication path, extend backpack carrying progression, and make dropped Crude Plant Torches obey their intended finite lifetime.

## Player-facing behavior
- Clay Grinder: 4 Twigs -> 1 Branch; 1 Branch -> 2 Twigs.
- Minecraft advancements are no longer available in Project Flint.
- 1 Leather Backpack + 2 Wooden Chests in the Wooden Grinder creates a Leather Backpack with a Chest.
- The chest-backed backpack grants +4 armor, unlocks the complete top inventory row, and applies 1.10x hunger/exhaustion drain while worn.
- V no longer places Crude Plant Torches as permanent item displays. Dropped Crude Plant Torches become real placed torches on valid replaceable supported terrain; invalid drops extinguish.

## Architecture
- `ServerAdvancementManagerMixin` replaces the loaded advancement map with an empty map.
- Legacy `ModAdvancements` call sites remain binary/source-safe no-ops while Flint Quests hooks take over progression events.
- `PrimitiveInventorySystem` now has a third carrying tier with 18 usable player inventory indices.
- `PlacedItemSystem` owns dropped Crude Plant Torch settling so V-placement and dropped-item behavior cannot diverge.

## Design reasoning
The old advancement tree is being superseded by Flint Quests and retaining two progression systems would duplicate authoring and produce conflicting guidance. The new backpack tier gives a clear carrying-capacity milestone with a survival cost. Dropped torches are converted into actual torch blocks so the already-established block burn timer remains the single source of truth.

## Tuning snapshot
- Twig -> Branch: 4:1.
- Branch -> Twig: 1:2.
- Leather Backpack with a Chest armor: +4.
- Usable inventory slots with chest-backed backpack: 18.
- Food exhaustion multiplier: 1.10x.
- Dropped torch settlement scan: every 10 server ticks.

## Assets and licenses
No new texture pixels were added. Leather Backpack with a Chest intentionally reuses the existing Project Flint Leather Backpack item and worn models.

## Advancement coverage
Minecraft advancements are intentionally disabled and Project Flint advancement resources are removed. Future progression coverage belongs in Flint Quests.

## Known limitations
Legacy Java call sites still invoke `ModAdvancements`, but the bridge is intentionally a no-op so those calls have no gameplay effect. They can be removed gradually as equivalent Flint Quests hooks are authored.

## Validation
Release validation checks the zero-advancement policy, exact Grinder ratios, backpack recipe/armor/inventory/exhaustion values, shared backpack rendering, and Crude Plant Torch drop/V behavior.

## Next release pressure
Continue replacing legacy advancement-specific event calls with explicit Flint Quests custom events as the new quest graph is authored.
