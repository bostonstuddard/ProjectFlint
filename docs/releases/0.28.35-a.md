# Project Flint v0.28.35-a — Sanding Station Interface Rebuild

## Intent
Replace the cramped Sanding Station durability presentation with a clean workstation UI that is immediately readable and visually consistent with the rest of Project Flint.

## Player-facing behavior
The Sanding Station now has a properly spaced processing row, a dedicated Sanding Reserve readout, and a segmented reserve meter instead of drawing durability text directly across the bar. The player inventory is also spaced correctly beneath the workstation panel.

## Architecture
`SandingStationScreen` now uses the same 176x182 workstation proportions as the grinder interfaces. `SandingStationMenu` moves its workstation slots and standard player inventory coordinates to match the new screen geometry. The reserve meter is divided into eight cells because each Sanding Paper contributes exactly 32 of the station's 256 maximum reserve.

## Design reasoning
Sanding durability is an important resource, but the previous layout rendered the text and bar on top of one another and made the entire workstation look unfinished. The new presentation makes the refill scale visible without adding another menu or changing the underlying mechanic.

## Tuning snapshot
- Maximum reserve: 256.
- One Sanding Paper: +32 reserve.
- One completed sanding recipe: -1 reserve.
- Reserve meter: 8 cells x 32 reserve.
- Recipe-guide button remains available from the workstation header.

## Assets and licenses
No texture or model assets changed. The interface remains code-rendered using existing Project Flint UI colors.

## Advancement coverage
No advancement changes. Existing Sanding Station progression remains intact.

## Known limitations
This is a layout/presentation release only. It does not add sanding animation or new recipes.

## Validation
Release validation checks the 182-pixel workstation layout, separated reserve label/bar, eight-cell reserve representation, aligned player inventory coordinates, and current v0.28.35-a build/cleanup wiring.

## Next release pressure
Continue Wood -> Water progression after the Sanding Station presentation is stable.
