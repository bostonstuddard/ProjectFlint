# Project Flint v0.31.7-b — Flax, recipe research, and Primitive Oven food progression

## Intent
Extend the late Wood/early Water settlement loop into repeatable food production and recipe research, while making placed Crushed Stone recoverable without weakening naturally created Crushed Stone progression.

## Player-facing behavior
- Crushed Stone now stores a persistent `player_placed` blockstate value. Crushed Stone placed from the inventory can be re-mined intact with an Advanced Flint Multitool; natural/hammer-created Crushed Stone keeps `player_placed=false` and remains non-recoverable.
- Primitive Oven speed is now 1.45x the shared kiln baseline. Its existing four stripped-log/stripped-wood fuel cost and 30-minute burn duration are unchanged.
- Bound Recipe Parchment displays its recipe output and a data-driven ingredient list in item lore. Blank parchment remains stack size 1 and can only be bound once.
- A full 4/4 Bookshelf can bind blank parchment using the requested research materials. Sweet Berries and Pumpkin Slices intentionally expose two selectable recipe results in the Bookshelf prompt row.
- Wooden Grinder adds Loose Mud Bricks, mud-brick slabs/reassembly, Bricks stabilization, Primitive Oven construction, Bone Knife, Wooden Cup, and Pumpkin Cake slicing.
- Wooden Cups stack to 16 and can milk Cows into `Wooden Cup with Raw Milk`; raw-milk cups stack to 16, are drinkable, return an empty cup, and use the same sickness profile as raw food.
- Mature Flax always drops 1 String and 1 Flax Seed, with a 10% chance for a second seed. The supplied eight-stage crop art is used. String is stripped from loot-table drops so Flax is the progression source.
- Primitive Oven adds parchment-gated Sugar, Sweet Berry Jam, Sweet Berry Pie, Pumpkin Pie, Melon Pie, Mutton Pie, Butter, Pumpkin Cake, and Apples n Pie recipes. Vanilla Sugar and Pumpkin Pie crafting bypasses are disabled.
- Primitive Oven now has a Project Flint recipe-guide page.

## Architecture
`CrushedStoneBlock` uses a Boolean blockstate property rather than a block entity for the placement marker, so the state is serialized by chunks and carried by falling-block state with minimal storage overhead. Placement sets the flag true; all non-placement creation paths inherit the false default.

`PrimitiveStoveRecipeRegistry` is the authoritative data source for parchment-bound Oven definitions. The Bookshelf stores only the recipe id in Recipe Parchment custom data; `RecipeParchmentItem` resolves that id back through the registry for its name/lore, and the Primitive Oven guide reads the same definitions. Ingredient text therefore cannot drift from the processing recipe unless the registry itself changes.

Bookshelf matching now returns all valid recipe choices instead of only the first one. Its six prompt slots are selectable results, allowing the same research input to produce either Sweet Berry Jam/Pie parchment or Pumpkin Cake/Pie parchment without inventing separate stations or hidden controls.

## Design reasoning
Player-placed Crushed Stone needs to be recoverable for building mistakes, but making every Crushed Stone recoverable would bypass its intended early-game transformation role. A persisted placement flag preserves both behaviors.

Recipe research uses immutable parchment because the parchment is intended to be a portable recipe record, not a generic selector. Showing ingredients directly on the parchment makes the record useful away from the Bookshelf/Oven and avoids forcing players to memorize a recipe after research.

Flax replaces passive String acquisition so textile progression becomes agricultural and settlement-oriented. The Primitive Oven then turns that same settlement phase toward longer-lived fuel, recipe knowledge, and prepared food.

## Tuning snapshot
- Primitive Oven: **1.45x baseline** process speed, 4 stripped logs/wood per ignition, 30-minute burn.
- Bone Knife: 64 durability.
- Wooden Cup / Raw Milk Cup: stack 16.
- Mature Flax: 1 String guaranteed; 1 Flax Seed guaranteed; 10% second Flax Seed.
- Custom Oven foods: stack 16 unless Pumpkin Cake (1) or Pumpkin Cake Slice (8).
- Minecraft's hunger storage is integer half-shank based. Requested hunger values that are not representable in 0.5-shank steps use the nearest representable amount; requested saturation values are preserved by the food-component calculation.

## Assets and licenses
The Bone Knife, Wooden Cup, raw-milk cup, Butter, Melon Pie, Mutton Pie artwork, Pumpkin Cake, Pumpkin Cake Slice, Apples n Pie, and all eight Flax growth-stage textures are copied from the owner-supplied `cb0cc5b9-64c2-4780-92f7-f464601f4607.zip`. No generated replacement pixels were introduced. The supplied `melon_pie_slice.png` is retained outside the patch because no Melon Pie Slice item was requested.

## Advancement coverage
The unified Project Flint progression page now teaches mature Flax/String harvesting, Loose Mud Bricks, Bone Knife, Wooden Cup, raw milk, Primitive Oven construction, and the first full-Bookshelf recipe-research action. The existing Flax Seeds advancement is updated to explain planting and mature drops.

## Known limitations
Vanilla hunger itself cannot store arbitrary decimal hunger values such as 0.2, 4.2, or 4.3 shanks; those values are rounded to Minecraft's nearest 0.5-shank unit while saturation remains separately tunable. The internal registry id remains `projectflint:primitive_stove` for save compatibility, while all player-facing text calls the block **Primitive Oven**.

## Validation
The release validator checks version/build wiring, persistent Crushed Stone state, Advanced Flint Multitool recovery gates, Oven 1.45x tuning, bound-parchment lore wiring, Bookshelf research choices, all requested Oven recipes, vanilla Sugar/Pumpkin Pie bypass removal, Flax drop/String exclusivity, raw-milk sickness, new grinder recipes, recipe-guide integration, JSON validity, and owner-supplied asset hashes. A full Gradle build cannot be completed in the offline tool environment because Fabric Loom 1.14.10 is not available in its plugin cache; configuration fails before Java compilation begins.

## Next release pressure
Playtest Flax seed multiplication, 30-minute Oven fuel economy, and the ingredient costs of the first prepared-food recipes. Future recipe research should add new `PrimitiveStoveRecipeRegistry` definitions and Bookshelf research inputs rather than creating independent hardcoded tooltip/guide data. The cabinet should continue rejecting blank parchment so it remains a library of completed recipe records rather than generic storage.
