# Project Flint 0.1.0-alpha.21.1 — Minecraft 1.21.11 Block Entity Compile Hotfix

## Intent

Alpha.21.1 fixes the compile failure introduced by alpha.21's baked-kiln block entity. The feature logic remains unchanged; only API compatibility and version-reporting code are touched.

## Player-facing behavior

There are no intended gameplay changes from alpha.21. The baked kiln, Super Heated Clay processing, timed meat cooking, Clay Grinding Base, and Clay Grinder behavior remain as designed in alpha.21.

## Architecture

`BakedClayKilnBlockEntity` now uses Minecraft 1.21.11's `ValueInput` / `ValueOutput` persistence layer. ItemStack fields are encoded with `ItemStack.CODEC`, and integer fields use `getIntOr` / `putInt`.

`ModBlockEntities` now uses Fabric API's `FabricBlockEntityTypeBuilder`, because the older `BlockEntityType.Builder` path used in the first alpha.21 implementation does not exist in the current 1.21.11 mapped API.

## Design reasoning

The compile log showed every failure concentrated in the new block-entity persistence and registration code. The hotfix therefore changes those API boundaries only instead of restructuring the kiln system or altering gameplay.

## Tuning snapshot

No tuning values changed.

## Assets and licenses

No assets changed.

## Advancement coverage

No advancement changes.

## Validation

The corrected methods were checked against the cached Minecraft 1.21.11 mapped classes and Fabric API 0.141.6+1.21.11 classes. A targeted Java 21 compile check of the corrected block entity and registration code passes against those APIs.

The standard Project Flint static release validator also passes after the hotfix version update.

## Known limitations

The unrelated `SuperHeatedClayItem` deprecation message remains a warning only; it was not responsible for the failed build and is intentionally not changed in this compile-only hotfix.

## Next release pressure

Resume alpha.21 gameplay testing once the local Gradle build succeeds. Any further compiler errors should be treated as separate compatibility fixes rather than bundled gameplay changes.
