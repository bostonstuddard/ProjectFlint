# Project Flint 0.1.0-alpha.2 — Interaction Readability

## Intent

Turn the alpha.1 proof-of-concept into a testable primitive opening where the player can immediately tell which physical actions are possible, while correcting worldgen and pacing problems discovered during the first launch.

## Player-facing behavior

- Project Flint now owns a dedicated Creative Mode tab for all currently testable items and active forage bushes.
- Impossible survival block breaking is stopped at the interaction/progress level instead of merely cancelling the final block break.
- Bare-hand grass stripping is now a hold-to-break operation. It takes about 2.6 seconds and converts a grass block to dirt instead of dropping it.
- Short grass and other free vegetation cannot be punched for resources. A later sharp cutting-tool capability will own that interaction.
- Forage bushes require a Refined Rock and use visible hold-to-break progression before yielding 2–4 twigs.
- Stone working no longer spams action-bar text; a compact icon-and-meter HUD reports progress and input state.
- Looking at impossible blocks produces a small blocked-state crosshair marker; contextual interactions use mouse/item icons rather than instruction text.
- Hunger exhaustion is multiplied by 0.72 to compensate for the intentionally food-poor primitive opening.
- Retaliating animals pursue faster, stay hostile longer, attack more frequently, and deal more damage.
- Beach, snowy-beach and stony-shore bushes no longer enter active world generation. Their old block IDs remain registered only so alpha.1 test worlds do not lose existing blocks.
- Bush and loose-rock placement now rejects surface water by using the same zero-water-depth/OCEAN_FLOOR placement pattern used by vanilla surface vegetation.
- Temporary original placeholder textures make every alpha mechanic readable until final art is supplied.

## Architecture introduced

- `ModCreativeTabs` centralizes development/creative visibility.
- `PrimitiveProgressPayload` provides server-authoritative primitive-action HUD progress.
- `ProjectFlintClient` and `PrimitiveHud` establish the first client-only presentation layer.
- `BlockStateBaseMixin` makes primitive block capabilities affect actual mining progress rather than only server-side completion.
- `ServerPlayerGameModeMixin` replaces completed primitive operations before vanilla destruction/loot occurs.
- `FoodDataMixin` provides one centralized primitive hunger pacing multiplier.
- `TEMPORARY_ASSETS.md` tracks every disposable development texture.
- Shore-bush registry IDs are retained as explicit legacy compatibility entries while being excluded from active tags/items/worldgen.

## Design reasoning

### Denied means physically impossible

If the player cannot alter a block, the client should not show normal mining progress. Alpha.1 allowed the visual language of vanilla mining and only rejected the result, which falsely implied the player had the capability.

### Progress should live in the world/UI, not chat

Repeated action-bar messages were implementation feedback masquerading as game design. Grass and bush operations now use block crack progression; repeated stone work uses a dedicated HUD meter, and contextual requirements are shown with item/input icons rather than instruction text.

### Short grass is future cutting material

Punching short grass would trivialize early fiber. Ground stripping provides the desperate earliest fibers; intact vegetation becomes meaningful once the player has acquired a sharp cutting capability.

### Placeholders are explicit debt

Readable temporary assets are useful during rapid iteration. They are now project-owned procedural placeholders and are tracked in one ledger so none can accidentally become permanent or lose provenance.

## Tuning snapshot

- Grass strip: `1 / 52` block progress per tick (~2.6 s).
- Grass fiber chance: `45%`.
- Bush cut: `1 / 34` block progress per tick (~1.7 s).
- Bush yield: `2–4 twigs`.
- Stone attempt: `8 strikes`, `55%` success.
- Hunger exhaustion multiplier: `0.72`.
- Animal retaliation: `30 s`, `30 block` pursuit range, `1.58` navigation speed, `3 damage`, `14 tick` attack cooldown.

## Assets and licensing

No third-party textures are redistributed in this release. Six temporary textures were created procedurally for Project Flint and are listed in `docs/TEMPORARY_ASSETS.md`. Existing external asset research remains informational only in `docs/ASSET_SOURCES.md`.

## Validation performed

- JSON parse/link validation.
- Active-biome worldgen audit.
- Temporary-asset ledger audit.
- Source-level API verification against current Fabric 1.21.11 documentation and Mojang mappings.

A full Gradle compile could not be executed in the artifact environment because external Gradle dependency resolution is unavailable there; the local build remains the final API/mixin verification gate.

## Known limitations

- Animal retaliation is still generic rather than species-specific.
- Forage bushes currently share one temporary visual instead of biome-specific art.
- Primitive action HUD styling is intentionally minimal and will evolve with the resource pack.
- Existing chunks generated by alpha.1 keep already-placed beach/water bushes; worldgen fixes affect newly generated terrain.

## Next pressure

- Move primitive tuning/content rules into reloadable data files.
- Establish the first true sharp-edge/tool capability and vegetation harvesting rules.
