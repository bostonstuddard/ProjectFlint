# Project Flint v0.31.2-b

## Intent

Repair the Wood/Water workstation and item-polish regressions found during v0.31.1-b playtesting without changing the stage's core progression. This release focuses on Wooden Chest lifecycle/UI behavior, Bookshelf crafting and presentation, missing item assets/names, recipe corrections, Lumber Processor dismantling, and Sanding Station state preservation.

## Player-facing behavior

- Wooden Chests now close correctly after players stop using them, and their Inventory label no longer overlaps the chest slots.
- Wooden Boards use the supplied Wooden Board item texture instead of the pending/missing model.
- Wooden Chest, Bookshelf, Sawmill, and every Wooden Beam variant have proper item display names.
- A full Water Bearing Pot displays as **Water Bearing Pot (Filled)**.
- Black Bear and Brown Bear spawn eggs now use their supplied custom item textures.
- Leather Boots now require **4 Leather + 4 Woven Wool** in the Wooden Grinder.
- Torch Holder now requires **8 Mortar Bricks + 16 Mud Piles**.
- Unlit Flint Torch now requires **12 Flint + 1 Woven Wood**.
- Bookshelf Book crafting is restored at **8 Sugarcane Rolls + 2 Leather -> 1 Book**.
- The Bookshelf now uses the Wooden Grinder-style workstation layout and has its own recipe-guide page.
- Formed Lumber Processors can be dismantled from any base part with a Flint Axe, including the linked Water Pot.
- Lumber Processor, Bookshelf, Wooden Grinder, and Sanding Station survival dismantling is restricted to the Flint Axe.
- Sanding Stations retain their stored sanding reserve when dismantled and placed again.
- Sawmill rendering is marked non-occluding to match its partial-block body/exposed-saw model and avoid face/render artifacts.

## Architecture

Wooden Chest menus now extend vanilla `ChestMenu`. This is required because vanilla `ChestBlockEntity` opener tracking recognizes active chest viewers through `ChestMenu`; the previous parallel `AbstractContainerMenu` implementation could leave the opener count/lid state stranded after the first use.

Bookshelf crafting now uses `BookshelfRecipeRegistry` as a single source of truth shared by the Bookshelf menu and recipe guide. The Bookshelf screen and slot arrangement mirror the Wooden Grinder's two-input/output/preview layout.

Sanding Station reserve persistence is implemented through `SandingStationItem`, which stores `ProjectFlintSandingDurability` in `DataComponents.CUSTOM_DATA` on the dropped item and restores it into `SandingStationBlockEntity` when placed.

Dismantling authority is enforced across interaction gating, destroy-progress gating, and server-side block completion. `LumberProcessorSystem.isProcessorPart(...)` is used so the controller, linked Water Pot, and end Crushed Stone all follow the same formed-machine rule.

## Design reasoning

The Wooden Chest should behave like a smaller vanilla chest, so reusing vanilla chest menu lifecycle semantics is safer than maintaining a nearly identical custom viewer-tracking path. The Bookshelf likewise benefits from sharing the already-established Wooden Grinder visual language rather than maintaining a sparse one-off interface.

Workstations in this tier are intentionally recovered as machines rather than casually punched apart. Using the Flint Axe as the exact dismantling tool gives the Wood progression tool a clear utility role and prevents a linked Lumber Processor part from entering a misleading partial-mining state with an invalid tool.

Sanding reserve is machine state rather than disposable fuel-on-break, so dismantling and relocation should preserve it just as Water Pots and filled Bookshelves preserve their stored state.

## Tuning snapshot

- Leather Boots: **4 Leather + 4 Woven Wool**.
- Torch Holder: **8 Mortar Bricks + 16 Mud Piles**.
- Unlit Flint Torch: **12 Flint + 1 Woven Wood**.
- Bookshelf Book: **8 Sugarcane Rolls + 2 Leather -> 1 Book**.
- Bookshelf capacity: **4 inserted Books**.
- Wooden Chest capacity remains **9 slots single / 18 slots double**.
- Sanding Station reserve remains **256 maximum**, with **32 reserve per Sanding Paper**.
- Flint Axe dismantling cost remains **1 durability per successful workstation recovery**.

## Assets and licenses

The Wooden Board item model is wired to the owner-supplied `wooden_board.png` included in the current update archive. Its bytes match the already-catalogued owner-supplied Wooden Board texture from the v0.31 asset batch, so no provenance change is required.

Existing owner-supplied Black Bear and Brown Bear spawn-egg textures are now actually referenced by their item models. No AI-generated or newly sourced external artwork is introduced by this release.

## Advancement coverage

The unified detailed ProjectFlint advancement tree remains unchanged. Existing Bookshelf, Bookshelf Book, Filled Bookshelf, Wooden Chest, Sanding Station, Lumber Processor, and related Wood/Water advancement nodes remain authoritative; this release repairs the underlying gameplay paths rather than adding duplicate progression nodes.

## Known limitations

The Sawmill remains a staged Creative-only block and is not promoted into survival progression by this patch. Its rendering fix is limited to the current partial-block model/texture presentation.

Flint Axe-only workstation recovery is a survival rule; Creative mode retains normal development/admin breaking behavior.

## Validation

Release validation checks the exact v0.31.2-b version/build wiring, JSON syntax, Wooden Chest `ChestMenu` inheritance, fixed chest label spacing, the corrected Wooden Grinder recipe counts, Bookshelf registry/menu/guide integration, item translation keys, Wooden Board and bear spawn-egg model wiring, Sawmill non-occluding registration, exact Flint Axe workstation gates, formed Lumber Processor recovery, and Sanding Station reserve serialization/restoration.

The previous v0.31.1-b single-handler Sugar Cane regression guard remains active.

## Next release pressure

Playtest every Wood/Water workstation through a full place -> use -> close -> dismantle -> replace cycle, especially double Wooden Chests and stateful machines. Continue checking owner-supplied texture batches for assets that exist on disk but were never wired into their item/model definitions.
