# Project Flint 0.1.0-alpha.21.6 — Kiln/Campfire Timing, Grinder Identity, and Placement Fixes

## Intent

Alpha.21.6 is a focused bug-fix/update pass on top of alpha.21.5.1. It fixes the remaining kiln rotation/geometry problems, restores consistent timed one-item cooking for both the baked kiln and permanent campfire, repairs Super Heated Clay placement, and makes the Clay Grinder a custom empty-recipe workstation rather than a functional vanilla stonecutter.

## Player-facing behavior

- Baked clay kilns rotate with player-facing placement.
- A crude kiln preserves its facing when it bakes into a baked kiln.
- The baked kiln top inherits the same facing so both halves stay aligned.
- The baked kiln body reaches the top edge, removing the visible seam/gap between the lower and upper kiln blocks.
- Super Heated Clay can correctly place the Clay Grinding Base on valid supported ground, consuming 8 only after a valid placement succeeds.
- The placed Branch asset now uses a valid block-atlas texture path.
- The Clay Grinder model is no longer a literal stonecutter copy.
- The Clay Grinder GUI keeps the stonecutter-style layout but exposes zero vanilla stonecutter recipes or outputs.
- Permanent campfires and baked kilns both cook one queued item at a time instead of performing instant conversions.

## Architecture

- `PrimitiveCooking` is the shared primitive heat-processing recipe/timing resolver.
- `PrimitiveCampfireBlockEntity` stores the permanent campfire's single-item timed queue.
- `BakedClayKilnBlockEntity` uses the same shared queue rules.
- `ClayGrinderMenu` intentionally reports an empty recipe set until Project Flint-specific grinder recipes are introduced.
- Facing is stored as a horizontal block-state property on the baked kiln and propagated to the kiln top.

## Design reasoning

The permanent campfire and kiln are both primitive heat processors, so they should obey the same interaction rule: one inserted item, a visible delay, then an output. The grinder UI is currently only a UI pattern; exposing vanilla stonecutter recipes would incorrectly turn it into a real stonecutter instead of leaving space for a future clay-processing recipe set.

## Tuning snapshot

- Unfired Clay Ball → Super Heated Clay: 4 seconds.
- Other primitive heat-processing outputs: 15 seconds.
- Maximum queued items per permanent campfire/kiln: 1.
- Clay Grinding Base cost: 8 Super Heated Clay.

## Assets and licenses

No new generated or edited art is introduced by this release. The new block-atlas Branch texture is byte-identical to the already-approved human-made Branch source from `textures.zip` (`textures/item/stick.png`).

## Advancement coverage

Existing heat-processing advancements remain part of the progression. Inventory-based criteria are used where timed block-entity cooking no longer has a direct player callback at the exact completion tick.

## Validation

- `build.bat`, `gradle.properties`, and the mod initialization log all identify the release as `0.1.0-alpha.21.6`.
- The release validator is updated to expect alpha.21.6 and the shared `PrimitiveCooking` architecture.
- JSON/resource validation is run before packaging.
- The patch ZIP is packaged from its contents directly, with no extra wrapper directory.

## Known limitations

The Clay Grinder intentionally has no usable recipes yet. Its GUI is only the future Project Flint grinder interface shell.

- Consider visible inserted-item rendering for the campfire/kiln queues.
