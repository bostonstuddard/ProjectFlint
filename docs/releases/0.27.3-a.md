# Project Flint v0.27.3-a

Targeted follow-up bugfix patch.

## Fixes included
- Woven chest now uses a proper 3x3 dispenser-style layout and alignment.
- Hidden personal crafting region in the inventory now keeps a clean vanilla-looking frame.
- Sleeping through the night now correctly grants Regeneration I for 4 seconds.
- Water movement hunger drain now applies while swimming and while pushing upward in water.
- Wild wolves now aggro from roughly 8 blocks.
- Drowned no longer spawn holding tridents and now use a shorter follow/aggro range.
- Land passive mobs and wolves take sharply reduced player damage while they are in water.
- Falling top slabs now drop as bottom slabs instead of staying top-half after landing.
- Advanced Kiln casing blocks now all open the shared kiln menu.
- Clay grinder and wooden grinder now support horizontal rotation when placed.
- Loose rock / placed flint / leather backpack worn texture hookups were refreshed.
- Included the user-provided fired clay multitool mold and fired clay brick mold textures.
