# Project Flint 0.1.0-alpha.20 — Clay/Kiln Repair Pass and Primitive Cooking

## Intent

Alpha.20 is a repair pass on the Flint/clay progression added in alpha.19. It focuses on playtest complaints rather than new broad progression: the kiln should look like a kiln, the fired-clay placement should render correctly, the Flint Multitool should cover the obvious Loose Dirt interaction, and the primitive HUD should stop spamming a break-progress overlay during ordinary block breaking.

It also adds the first simple food-processing outputs for long-lived heat sources.

## Player-facing behavior

### Visual/presentation repairs

- Reworked the **Crude Clay Kiln** block model into a squat firebox with a rising rear throat.
- Reworked the **Kiln Top Form** and **Baked Kiln Top** into a narrower chimney piece so the full two-block kiln reads as a chute/chimney instead of two duplicated stacked blocks.
- Switched the **Crude Clay Kiln item** to a flatter generated icon for cleaner inventory presentation.
- Rebuilt the placed **Fired Clay** pile models so the item no longer looks broken when placed into the world.
- Cleaned up the **Primitive Campfire** multipart geometry so its stones form a clearer ring and its fuel bundle sits more centrally.

### HUD cleanup

- Removed the primitive **block-breaking progress meter** from normal break actions.
- The **hand-working meter** remains for deliberate working actions such as stone working, campfire-stone working, reed cutting, burnt-twig splitting, and Flint-chip knapping.

### Harvest/output fixes

- **Flint Multitool** can now break placed **Loose Dirt** blocks normally.
- Breaking **Tall Grass** with cutter-like tools now yields **2×** the corresponding Short Grass output.
  - Cutters / Crude Multitool: 2 Crude Plant String from Tall Grass.
  - Flint Multitool: 4 Crude Plant String from Tall Grass.
- **Flint Multitool** leaf harvesting now yields **2 Branches** instead of 1 while keeping the existing Twig payout.

### Primitive cooking additions

Both **lit permanent campfires** and **lit baked kilns** can now process:

- **1 Egg → 2 Scrambled Egg**;
- **1 Plant Fiber → 1 Plant Seeds**.

Food values are:

- **Scrambled Egg**: 1 hunger and 2.5 saturation each;
- **Plant Seeds**: 0.5 hunger and 1.5 saturation each.

## Architecture

- `PrimitiveHud` still accepts shared progress payloads, but alpha.20 only renders the hand-working meter and no longer renders the general break-progress overlay.
- `ServerPlayerGameModeMixin` remains the authoritative completion/output layer for custom survival breaking and now covers Tall Grass scaling, Flint leaf Branch yield, and Flint Multitool Loose Dirt recovery.
- `PrimitiveCampfireBlock` and `BakedClayKilnBlock` now share the same simple hot-food transaction pattern for Eggs and Plant Fiber.
- The kiln/campfire visual fixes are implemented as block-model updates only; no new block IDs or state properties were added.

## Design reasoning

The kiln/chimney complaint was fundamentally about silhouette clarity. The earlier stacked look technically represented a two-block structure, but it failed to communicate “kiln” visually. Alpha.20 therefore focuses on block-model readability rather than inventing extra progression rules.

The HUD cleanup intentionally preserves feedback for actual hand-working/knapping actions, where multi-step progress is important, while removing it from routine block breaking, where it had started to feel noisy and overbearing.

The new cooking outputs stay deliberately simple. Eggs become a slightly more efficient cooked food, while Plant Fiber gains a low-value emergency food outlet through Plant Seeds. This fits the primitive-survival tone without opening a full recipe tree yet.

## Assets and licenses

Alpha.20 does not import new external art. It reuses existing Project Flint textures and vanilla texture references for temporary food icons.

- `projectflint:block/crude_clay_kiln`, `projectflint:block/baked_clay_kiln`, and `projectflint:block/kiln_top_form` continue to provide the kiln visuals.
- `projectflint:item/fired_clay` continues to provide the placed Fired Clay pile texture.
- `minecraft:item/egg` and `minecraft:item/wheat_seeds` are used as temporary vanilla-derived icon references for Scrambled Egg and Plant Seeds.

## Advancement coverage

Alpha.20 does not introduce a new advancement branch. Existing progression coverage remains valid because this patch is primarily a repair/presentation pass.

The new Scrambled Egg and Plant Seeds outputs are intentionally left without dedicated advancements for now.

## Validation

The modified source/resource tree remains in the standard Project Flint layout and includes the required item definitions, models, lang keys, and release-document entry for the new custom food items.

No full Fabric Loom build was available in this artifact environment, so final jar packaging and in-client verification remain local follow-up steps.

## Known limitations

- Scrambled Egg and Plant Seeds currently use temporary vanilla-derived icons rather than bespoke Project Flint sprites.
- The campfire and kiln model pass improves readability, but it is still low-tech block-model work and may receive another art pass later.
- This patch does not add broader kiln recipe processing beyond the two simple food conversions and the earlier clay-related states.

## Next release pressure

- If the revised kiln silhouette still feels too crude in-game, it may need a texture pass in addition to the geometry pass.
- The new Scrambled Egg / Plant Seeds outputs may want dedicated art, advancement coverage, and clearer guidebook text.
- The next kiln-facing step after this repair pass is likely actual long-burn production use, not just construction and reheating.
