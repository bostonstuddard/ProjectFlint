# Project Flint 0.1.0-alpha.22.4.1

## Intent

Repair the Java compilation failures reported by the local Windows build of alpha.22.4 without changing the release's gameplay, progression, assets, or balance.

## Player-facing behavior

- Alpha.22.4's filing, Bone Firestarter, Bone Club, Sleeping Bag, masonry, Place in World, survival-condition, Chicken-health, and Cow-drop behavior remains unchanged.
- Completed-night Regeneration I still requires a fully rested wake into daytime.
- Sleeping Bag and Mortar Bricks break authorization remains unchanged.

## Architecture

Two accidentally duplicated block-breaking guards were removed from `PrimitiveInteractionSystem.onUseBlock`, where they referenced an unavailable local `state` and returned booleans from an `InteractionResult` method. Their correct copies remain in the block-breaking authorization paths. `ServerPlayerSleepMixin` now uses the mapped Minecraft 1.21.11 `Level.isBrightOutside()` method instead of the unavailable `ServerLevel.isDay()` call.

## Design reasoning

This hotfix changes only the invalid call sites identified by Java compilation. It does not reconstruct the interaction system, alter centralized capabilities, or change the sleep reward's existing fully-rested/daytime requirements.

## Tuning snapshot

All alpha.22.4 values are preserved, including 40 ticks of Regeneration I after a completed night. No constants changed.

## Assets and licenses

No asset files, provenance records, licenses, models, or texture pixels changed.

## Advancement coverage

No advancement files or triggers changed.

## Validation

The release validator checks the alpha.22.4.1 version/document set, rejects the unavailable `isDay()` call, requires the mapped daytime predicate, and verifies that only the two intended Sleeping Bag break-gate checks remain. Static validation passes. A Gradle compile was attempted but stopped before Java compilation because Fabric Loom 1.14.10 could not be resolved in this environment, so no full build pass is claimed; run `build.bat` locally with Java 21.

## Known limitations

- A local Java 21 Gradle build and first-client-launch smoke test remain required before publishing.

## Next release pressure

Run `build.bat` locally. If compilation succeeds, verify a full-night Sleeping Bag wake grants Regeneration I for 2 seconds while leaving the bag early at night does not.
