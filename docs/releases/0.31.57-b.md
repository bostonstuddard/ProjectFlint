# Project Flint v0.31.57-b — Basin, hardwood recipes and insulated glass

## Gameplay changes

- Each valid Basin stomp consumes **one hunger point**. All supported inputs complete in **two or three** stomps; no material requires four or five. Hunger checks run before any stomp progress is granted. Creative is exempt.
- Basin item/inventory/dropped display uses dedicated transforms for the original user-authored Basin block mesh. Placed Basin and interior item rendering remain separate.
- Added Tin, Rare Earth, Lithium, Aluminum, Gallium, Glass, Borosilicate, BSIG, BSSIG, MBSSIG dust items and Pure Mica Insulated Glass; artwork for new *dusts* is pixel-preserving color treatment of Flint's existing Wood Dust texture, not generated art.
- Basin accepts Cobblestone and Clay Blocks and Rare Earth Dust. Added precise independent rolls for iron, copper, stone/cobblestone, clay, sand, granite, and andesite; all existing outputs and independent roll semantics retained. Full odds: `docs/BASIN_MATERIAL_YIELDS.md`.
- Fixed the **Hardwood Crafting Table bootstrap deadlock**: the four-component Table craft (2 Alloy, Cobblestone, Bound Wood Processor) is now ordinary personal **2x2** shapeless crafting, not a Hardwood-only recipe. It can still be made in the Hardwood Table.
- In personal crafting, 1 Leather Sheet + Bone Knife yields 3 Straps, and 1 Strap + 2 String yields 2 Repair Kits.
- Added Hardwood Table recipes for Clay Block, Tanned Leather, Leather Sheets/Straps/Kits, eight Wattle & Daub Windows, Bone Hoe/Club, Woven Fans, Torch Holders, Unlit Flint Torch and Flint Torch Holder, Brick Shingles, Flint Plant Cutters, Advanced Flint Multitool, Flint Axe, Bound Wood Processor, double-output Fat-Burning Torches, Wattle & Daub floor tiles, Sheets and Boards using **any** Planks, and Glass Dust.
- Added Rare Earth Dust + Clay Water Bucket → 3 Aluminum Dust, and the entire Borosilicate → BSIG → BSSIG → MBSSIG Dust line. All crafting-container return/knife/file wear use existing return logic and durability-aware recipes.
- Fireclay Forge now accepts MBSSIG Dust as its second processing input. 1 MBSSIG Dust plus a complete 5-minute Charcoal fire yields 1 Pure Mica Insulated Glass. Existing Hardwood Alloy recipe and separate Charcoal-byproduct output are retained. Input swapping cancels progress.
- Added a Hardwood Table category to the K-key recipe reference generated from recipe JSON. Updated the K-key Basin and Forge recipes and current player-focused G-key Field Guide chapters.

## Technical decisions

See `docs/decisions/0016-basin-stomp-economy-and-mica-glass-chain.md`. The dedicated Hardwood recipe type is retained for Hardwood Table-only recipes. Only the bootstrap recipe uses `minecraft:crafting_shapeless` to fit the pre-Table 2x2 grid. Avoid making the 160 Hardwood-only recipes globally available through vanilla crafting.

## Visual assets

No AI-generated textures. New dusts are recolors of the approved existing Wood Dust sprite; `Pure Mica Insulated Glass` uses an existing approved source texture (glass art in a future pass). Basin held/GUI appearance is adjusted through model display transforms only.

## Known gaps / validation

Full Gradle compilation was attempted offline but Fabric Loom 1.14.10 was not present in the available plugin cache. Structural/registration/asset and release ZIP checks were completed. In-game GUI/recipe/book behavior and multiplayer sync still need testing. PF-EMI may need a separately developed recipe-category integration to list Hardwood-specific recipes outside the Project Flint K guide.

1. Place/remove Basin input with no hunger change; land twice/three times with enough food and observe exactly one food point lost per landing; no food prevents next stomp. Test block reload and both held GUI and ground model.
2. Verify independent rare rolls, especially zero Stone Dust outputs, three Stone Dust outputs, combined Sand products and Copper bonus Slag.
3. Craft first Hardwood Table in **personal** 2x2; open table, craft with 60-tick timer, repeat and shift-click. Ensure durable Knife/File remainders and filled Clay Water Bucket return the empty Bucket.
4. Verify every new shaped output, materials and quantity, particularly Flint Torch Holder, Wattle & Daub Window x8, MBSSIG chain, and 2x Fat Torch.
5. Run Fireclay Forge MBSSIG processing with exactly one Charcoal for a full 6000 ticks; no wood fuel conversion, no completion from partial firing or input swapping; verify Hardwood Alloy retains its processing.
6. Open G and K guides in a small GUI scale; ensure new items and recipes appear with accurate names, no double-blur crash.
