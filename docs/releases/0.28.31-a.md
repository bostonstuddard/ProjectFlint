# Project Flint v0.28.31-a — Lumber Processor Interaction Hotfix

## Intent
Make the new Lumber Processor reliably accept Flint Plant Cutter work on a staged stripped log without changing the intended 7.5/10/7.5-second production loop.

## Player-facing behavior
A stripped Overworld log staged above the Chopping Block can now be worked immediately with Flint Plant Cutters whenever the processor is valid and its Water Pot contains 1.0 bucket. The output can also be switched between 2 Wooden Boards and 1 Wooden Beam after the log is staged, up until washing actually begins.

If the log cannot be processed, the player now gets a short action-bar explanation for the common causes: wrong tool, incomplete/unsupported processor, or an underfilled Water Pot.

## Architecture
`LumberProcessorSystem.canChop(...)` now checks the real stripped-log block above the controller instead of requiring the controller block entity's cached `inputArmed` flag to have been set by a later tick. `startWash(...)` synchronizes the cached state immediately before entering the wash stage.

`LumberChoppingBlockEntity.cycleOutput()` now locks only while washing or while finished output is waiting, rather than locking merely because a log is staged.

## Design reasoning
The physical block in the world should be authoritative. A player-visible log should not become temporarily unusable because an internal block-entity flag has not caught up yet. This also restores the intended order where the player may place the log and then choose the desired lumber output.

## Tuning snapshot
- Flint Plant Cutter chop: **7.5 seconds**
- Water requirement before chopping: **1.0 bucket**
- Wash: **10 seconds**
- Finished workpiece: **7.5 seconds**
- Outputs: **2 Wooden Boards** or **1 Wooden Beam**

## Assets and licenses
No textures or other art assets are changed in this hotfix.

## Advancement coverage
Existing v0.28.30-a Wood Era Lumber Processor advancements remain unchanged.

## Known limitations
The new Wood → Water visual assets are still intentionally null until owner-supplied textures are available. The future Well remains outside this patch.

## Validation
The release validator is run against the updated source tree. The hotfix also adds deterministic source checks for staged-log authority, late output selection, and the Water Pot readiness feedback.

## Next release pressure
Continue Wood → Water progression once the Lumber Processor has been playtested with both board and beam outputs.
