# Project Flint 0.1.0-alpha.21 — Kiln Render Repair, Clay Heatwork, and Clay Grinder Concept

## Intent

Alpha.21 is the follow-up repair pass to alpha.20. The main goal is to fix the clay/kiln presentation problems that were still breaking immersion — especially the kiln silhouette, missing/blank clay-related item/block textures, weak campfire twig presentation, and the dirt-pile growth readability.

This patch also begins the next clay-processing step by adding **Super Heated Clay**, basic **kiln meat firing**, and the first-pass **Clay Grinder** concept with a stonecutter-style UI shell.

## Player-facing behavior

### Visual and model repairs

- Reworked the **crude / baked kiln** geometry again so the structure reads more like a body plus chimney.
- Reworked the **kiln top** to better match the intended “open chute / chimney” silhouette.
- Added visible **twig fuel geometry inside the lower kiln chamber**.
- Rebuilt the **campfire twig presentation** again to make the fuel bundle read more clearly.
- Repaired the **Crude Clay Kiln held/item texture** so it no longer renders as a blank icon.
- Repaired the **Fired Clay placed model texture path** so placed Fired Clay no longer appears texture-broken.
- Shifted clay-facing visual assets toward the same warmer fired-clay / brick-like palette.

### Terrain/material behavior

- **Crude Clay Block** now behaves like a falling material, similar to gravel / loose dirt.
- **Dirt Piles** now grow in more visible 2-pixel vertical steps per placed layer instead of barely changing.

### Kiln processing

A **lit baked clay kiln** can now process additional items while burning:

- **Unfired Clay Ball → Super Heated Clay** (4 seconds)
- Raw animal products / meats into their cooked forms (15 seconds each)
  - Beef → Cooked Beef
  - Porkchop → Cooked Porkchop
  - Chicken → Cooked Chicken
  - Mutton → Cooked Mutton
  - Rabbit → Cooked Rabbit
  - Cod → Cooked Cod
  - Salmon → Cooked Salmon

The kiln currently processes one inserted item at a time and ejects the finished result back into the world above the kiln.

### Clay grinder concept

- Added **Super Heated Clay** as the next primitive clay-processing material.
- **8 Super Heated Clay** can now be used to place a **Clay Grinding Base**.
- A Clay Grinding Base accepts up to **12 Very Refined Stone**.
- When fully fitted, it becomes a movable **Clay Grinder**.
- The Clay Grinder opens a **stonecutter-style UI shell** as the first concept pass for future clay processing.

## Architecture

- Added a **BakedClayKilnBlockEntity** to support timed kiln processing without changing the broader primitive interaction architecture.
- `BakedClayKilnBlock` now acts as both a long-burn structure and a timed single-slot heat processor.
- Added `ClayGrindingBaseBlock`, `ClayGrinderBlock`, and `SuperHeatedClayItem` for the first-pass grinder progression.
- `ClayGrinderBlock` currently uses a stonecutter-style menu shell rather than a dedicated custom recipe network.

## Tuning snapshot

| Mechanic | Alpha.21 value |
|---|---:|
| Dirt pile vertical growth per layer | 2 px |
| Super Heated Clay per Clay Grinding Base | 8 |
| Very Refined Stone required for Clay Grinder | 12 |
| Kiln time: Unfired Clay Ball → Super Heated Clay | 4 s |
| Kiln time: raw meat/fish → cooked output | 15 s |
| Kiln simultaneous processing slots | 1 |

## Known limitations

- The Clay Grinder UI is intentionally a **concept shell** right now; it opens like a stonecutter, but no dedicated Project Flint clay recipe tree has been authored yet.
- The kiln timed-processing pass is deliberately simple and currently handles one inserted item at a time.
- Campfire visuals and kiln visuals may still want a later dedicated texture polish pass.

## Design reasoning

This release keeps the clay/kiln system readable and functional before expanding it further. The kiln silhouette needed to communicate a primitive firebox and chimney instead of reading as two duplicated blocks, while the grinder needed to exist early enough to anchor future clay-processing work even if its recipe set is not authored yet.

The timed kiln-processing path deliberately stays minimal: one inserted item at a time, no broad inventory UI, and direct world ejection of finished results. That keeps the implementation small while still giving the kiln its first true production role.

## Assets and licenses

Alpha.21 reuses Project Flint clay/twig textures and adds lightweight derived textures for the repaired kiln icon, Super Heated Clay, Clay Grinding Base, Clay Grinder, and fired-clay block-facing presentation. No new third-party external art is imported in this patch.

## Advancement coverage

Alpha.21 does not add a dedicated new advancement branch for Super Heated Clay or the Clay Grinder yet. Existing clay/kiln advancement flow remains intact.

## Validation

The modified source/resource layout includes the required new items, blocks, models, lang entries, block entity registration, and release-note documents for the alpha.21 changes.

Static release validation is expected to pass after the alpha.21 release document update. In-client verification and final packaging remain local follow-up steps.
