# Project Flint 0.1.0-alpha.8 — First Fire

## Intent
Add the first persistent in-world use for Twigs while tightening only the spawn/ecology, falling-attack, and movement-exhaustion rules requested in the alpha.7 playtest follow-up.

This release does not retune previously accepted grass, bush-harvest, animal, inventory, stone-working, or Hardcore behavior.

## Player-facing behavior
- Twigs are now placeable by right-click as a `Twig Pile` block.
- Right-clicking an unlit Twig Pile with additional Twigs increases its stored count one at a time, up to 12.
- A 12-Twig pile accepts an ignition attempt when the interacting hand contains a full 4-Twig stack and the other hand contains a Refined Rock.
- Each ignition attempt has a 50% success chance.
- On a failed attempt, the four held Twigs are consumed. The 12 ground Twigs and Refined Rock remain unchanged.
- On a successful attempt, the pile enters its lit state for 10 seconds. The four held Twigs and Refined Rock remain unchanged.
- During those 10 seconds, right-clicking the lit pile with a Twig consumes one Twig and produces one Lightly Burnt Twig.
- After 10 seconds, the burning 12-Twig pile is consumed and disappears.
- Starter world spawn is now restricted to Forest, Flower Forest, or Meadow. Plains is no longer a starter-spawn biome.
- Snowy and swamp forage-bush variants no longer generate and are no longer exposed as active forage content.
- A survival player cannot complete a melee attack while actually descending through the air. Creative remains exempt for development.
- Normal ground sprint movement uses 0.5x vanilla exhaustion.
- Sprint-jump exhaustion uses 2.0x vanilla exhaustion.
- Other exhaustion continues using the accepted 0.72x vanilla alpha multiplier.

## Architecture introduced
`TwigPileBlock` is the first Project Flint block whose state represents an in-world primitive process rather than a static resource. It owns two block-state properties:

- `count`: 1 through 12 placed Twigs;
- `lit`: whether the completed pile is in its temporary 10-second lit phase.

The existing `Twig` item is now a `BlockItem` backed by `TwigPileBlock`, while keeping the existing item ID and four-item stack limit. Existing inventory/reward code therefore continues to treat Twigs as the same progression item.

Movement exhaustion now uses `PrimitiveExhaustionContext`. Focused `ServerPlayerMovementMixin` hooks identify ground sprint movement and sprint jumps, while the existing `FoodDataMixin` performs the final multiplier. This avoids globally changing unrelated food-exhaustion sources.

`PlayerAttackMixin` rejects the vanilla `Player.attack` call only while a noncreative player is descending and airborne.

## Design reasoning
The first fire step is represented as persistent world state instead of a crafting recipe. Twigs become something the player physically accumulates in the world, and the lit phase creates a short processing window for another material state without introducing a crafting table or GUI.

The newly inactive snowy/swamp bushes retain their registry IDs and resources as compatibility-only content. Removing registry IDs would make existing alpha test worlds unnecessarily fragile; excluding them from the active definition list removes them from new generation and the Project Flint creative tab without breaking old block states.

Movement tuning is scoped by source. The established 0.72x global primitive exhaustion remains the default; only requested ground sprint and sprint-jump cases override it.

## Tuning snapshot
- Twig pile capacity: 12.
- Ignition input stack: exactly 4 Twigs in the interacting hand plus a Refined Rock in the other hand.
- Ignition success: 50%.
- Failed ignition Twig loss: 4.
- Successful ignition hand-item loss: 0.
- Lit duration: 200 ticks / 10 seconds.
- Lit-pile Twig processing: 1 Twig -> 1 Lightly Burnt Twig per right-click.
- Lightly Burnt Twig stack limit: 4 for the current primitive placeholder item.
- Starter spawn biomes: Forest, Flower Forest, Meadow.
- Active forage bushes: 21.
- Ground sprint exhaustion: 0.5x vanilla.
- Sprint-jump exhaustion: 2.0x vanilla.
- Other exhaustion: 0.72x vanilla.
- Grass strip time: unchanged from alpha.7 (`1 / 156` progress/tick).
- Bush harvest time: unchanged from alpha.7 (`1 / 60` progress/tick).

## Assets and licensing
No third-party art is added.

The Twig Pile uses Project Flint-authored temporary geometry with Minecraft's currently loaded stripped-oak-log texture, allowing resource packs to supply the temporary pixels. Lightly Burnt Twig uses a temporary darkened derivative of Project Flint's own temporary Twig sprite. Both are recorded in `docs/TEMPORARY_ASSETS.md` and remain replacement targets.

## Validation performed
- Parsed all JSON resources.
- Verified the 21 active forage definitions exactly match `projectflint:forage_bushes`.
- Verified the nine newly retired snowy/swamp IDs moved to the compatibility-only registry list rather than being deleted.
- Verified starter-spawn source contains Forest, Flower Forest, and Meadow and excludes Plains.
- Verified Twig remains stack size 4 and is now backed by `ModBlocks.TWIG_PILE`.
- Verified all 12 Twig Pile count models and both `lit` states are represented in the blockstate resource.
- Verified Lightly Burnt Twig has item definition, model, texture, translation, and temporary-asset ledger entry.
- Verified ignition constants are 12 / 4 / 50% / 200 ticks.
- Verified failed ignition consumes the four hand Twigs while successful ignition leaves the hand stack and Refined Rock unchanged.
- Verified falling-melee prevention is isolated to `Player.attack` and leaves Creative exempt.
- Verified sprint/sprint-jump multipliers are scoped through `PrimitiveExhaustionContext` while the 0.72 default remains intact.
- Verified accepted grass and bush break rates remain unchanged.

## Known limitations
The artifact environment cannot launch the Fabric client, so the local `build.bat` remains the final compile/mixin-application test. The Twig Pile art and Lightly Burnt Twig sprite are temporary. The fire state is deliberately isolated to this pile and does not yet participate in a general heat, fuel, or cooking system.

Existing generated chunks keep their old bush placements. Existing worlds also keep their physical terrain; only the stored world-spawn point may be relocated if it is no longer in an allowed starter biome.

## Next pressure
Continue from the next explicit playtest notes only. The lit Twig Pile can later become the first input to a proper heat/material-processing architecture when that system is explicitly requested.
