# Project Flint v0.28.18-a — Wattle & Daub Art Pass

## Intent
Finish the visual side of the v0.28.17-a Wattle-and-Daub shelter tier using the owner's finalized artwork, while also replacing the temporary Crude Plant Torch presentation and refreshing the active kiln front animation without changing gameplay logic.

## Player-facing behavior
- Wattle, Tied Wattle, Mud Pile, Daub Pile, Wet Daub Pile, Unfired Wattle and Daub, and Wattled Daub Bricks now render with their finalized owner-supplied art instead of null/missing visuals.
- Wattled Daub Bricks now render correctly both as a placed structural block and as an inventory item.
- Crude Plant Torches now use their own Project Flint texture in-hand and when placed instead of vanilla torch artwork.
- Active Advanced Kilns and Mortar Kilns use the newly supplied reworked front animation.
- The active kiln front retains the previously requested slower 4-tick frame time.
- All recipes, structural support, gravity, recovery, roof-span, and four-block height rules from v0.28.17-a remain unchanged.

## Architecture
The existing v0.28.17-a gameplay IDs remain authoritative. This release adds only the missing resource layer around them: 1.21.11 item-definition JSONs, generated inventory models for intermediate Wattle/Daub stages, a cube-all model/blockstate for Wattled Daub Bricks, and dedicated Crude Plant Torch texture references. The active Advanced/Mortar Kiln models already share `projectflint:block/advanced_kiln_front_active`, so replacing that one animation strip updates both machines without duplicating model logic.

## Design reasoning
The previous release intentionally separated logic from art so the construction system could be implemented without inventing placeholder pixels. v0.28.18-a closes that temporary gap using only the finalized textures supplied by the project owner. No gameplay behavior was reinterpreted during the art pass.

## Tuning snapshot
- Wattle/Daub structural height: unchanged at 4 blocks.
- Supported ceiling reach: unchanged at 2 blocks from a valid four-high load-bearing column.
- Wattled Daub crumble/intact recovery: unchanged.
- Active Advanced/Mortar Kiln front animation: 4 ticks per frame.
- No stack sizes, cooking speeds, recipes, or processing durations changed in this release.

## Assets and licenses
All PNGs introduced or replaced in this release were supplied directly by the Project Flint owner in `new update stuff(1).zip` and copied byte-for-byte.

Imported owner assets:

No texture was generated, recolored, resized, cropped, composited, or otherwise pixel-edited by the assistant. The Crude Plant Torch PNG is duplicated byte-for-byte into the item and block atlases because Minecraft resolves those render domains separately.

## Advancement coverage
No advancement logic changed. The Wattle/Daub advancement chain added in v0.28.17-a remains intact; this release only makes the corresponding icons/items render with finalized resources.

## Known limitations
- The Wattled Daub Brick currently uses a standard cube-all visual model; any later owner-supplied shaped geometry can replace the model without changing structural gameplay.
- The active Advanced and Mortar Kilns intentionally continue sharing the same front animation resource.
- This release does not add new Wattle/Daub building variants such as corners, beams, slabs, doors, or framed walls.

## Validation
- All new/modified JSON resources parse successfully.
- `tools/validate_release.py` checks the finalized texture/model hookups, current version wiring, four-block structural rules, and 4-tick kiln animation metadata.
- Every imported PNG was hash-compared against the corresponding owner-supplied source file; copies are byte-identical.
- A full Gradle build was attempted both offline and with repository access, but this environment could not resolve Fabric Loom `1.14.10`; therefore a successful JAR build is not claimed.

## Next release pressure
With the first Wattle-and-Daub shelter tier now visually complete, the construction branch can expand into the next housing technologies: framed openings, doors, roof materials, shelter/insulation behavior, drying, timber reinforcement, plaster, or later wattle-and-daub upgrades tied into carpentry and woodworking machinery.
