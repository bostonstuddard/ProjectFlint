# Project Flint 0.1.0-alpha.18 — Forage Break Reliability and Campfire Stone Rendering

## Intent

Alpha.18 is a narrow regression-fix release on top of alpha.17. It fixes Refined Rock forage-bush harvesting failing to complete and fixes the bare Campfire Stone frame appearing effectively textureless/invisible before Lightly Burnt Twigs are added. It intentionally does not rebalance forage yields or change the campfire recipe/state machine.

## Player-facing behavior

### Refined Rock forage bushes

Forage bushes can once again be fully broken with a **Refined Rock**. Completing the existing slow break produces **3–4 Twigs**, exactly as alpha.16/alpha.17 intended. **Crude Stone Cutters** still produce **exactly 4 Twigs** and consume their existing durability cost.

The fix also keeps the primitive world deny-by-default: unrelated survival blocks do not become normally mineable. Only operations Project Flint already supports are admitted through the survival block-break gate.

### Campfire Stone rendering

A newly placed Campfire Stone now has visible stone geometry immediately, including before any Lightly Burnt Twigs are added. Each additional Campfire Stone continues to add another piece to the existing multipart ring. The permanent campfire's component counts, recipe, ignition requirements, 30-second fire duration, relighting, cooking behavior, and component recovery are unchanged.

## Architecture

`PrimitiveInteractionSystem.beforeBlockBreak` now acts as an explicit capability allowlist instead of returning `false` for every non-Creative player. It permits only the already-supported primitive break targets/tool combinations and leaves all unrelated survival breaking denied. Custom outputs and durability still remain in `ServerPlayerGameModeMixin`; the event gate only decides whether the supported operation may reach that completion path.

The campfire blockstate/multipart layout is unchanged. The twelve Campfire Stone geometry models now sample `projectflint:block/campfire_stone_block`, a dedicated opaque block-atlas texture derived from the existing approved Campfire Stone art. The Campfire Stone item sprite is unchanged.

## Design reasoning

The forage reward handler itself was already correct. The failure was at a broader permission boundary: the Fabric `PlayerBlockBreakEvents.BEFORE` callback blanket-denied survival breaks and relied on custom mixin execution happening before that denial. Explicitly allowing only valid primitive operations removes that callback-order dependency without weakening Project Flint's core terrain lock.

The Campfire Stone issue was not a missing state or missing model. The tiny cuboids sampled a sprite with a large transparent background, so most of each visible face could be transparent. Converting that already-approved stone art into an opaque block texture is smaller and safer than replacing the campfire block/state system.

## Tuning snapshot

| Mechanic | Alpha.18 value |
|---|---:|
| Refined Rock forage-bush yield | 3–4 Twigs (unchanged) |
| Cutters forage-bush yield | 4 Twigs guaranteed (unchanged) |
| Bush break progress | existing 1/60 progress per tick (unchanged) |
| Campfire Stone frame capacity | 12 stones (unchanged) |
| Permanent frame twig capacity | 12 Lightly Burnt Twigs (unchanged) |
| Permanent fire duration | 30 seconds (unchanged) |

## Assets and licenses

Alpha.18 adds `textures/block/campfire_stone_block.png`, a project-local rendering derivative of the Campfire Stone art already imported from the user-approved LegendsRPG resource pack in alpha.16. No new external source or license is introduced. `docs/ASSET_SOURCES.md` and `docs/TEMPORARY_ASSETS.md` are updated to record the derivative and its status.

## Advancement coverage

No advancement criteria or descriptions change. This release restores behavior that the existing `first_twigs`/campfire progression already describes; it does not add a new capability or milestone.

## Known limitations

The campfire remains a handcrafted multipart model with twelve individual stone pieces and twelve twig pieces. Alpha.18 fixes the invisible stone-face presentation but does not perform a final campfire art/model pass.

The primitive break allowlist remains code-defined rather than data-driven. That is appropriate for this repair but will become maintenance pressure as many more tools and target families are added.

## Validation

- Parsed the full JSON/resource tree after the model texture-path change.
- Validator checks now require the explicit Refined Rock/Cutters forage-bush permission in the survival block-break gate.
- Validator checks require all twelve Campfire Stone multipart models to use the new block-atlas texture and require that PNG to exist; the generated 16×16 texture was separately inspected to confirm every alpha pixel is fully opaque.
- The modified Java source is compile/type-checked using the same cached Minecraft/Fabric Java 21 validation path used for the preceding releases.
- Patch contents are compared against alpha.17 so only actually modified/new files are packaged.

## Next release pressure

Playtest several active biome forage-bush variants with both Refined Rock and Cutters, and assemble a permanent campfire from one through twelve stones before adding Lightly Burnt Twigs. If those paths are stable, future batches can return to progression work rather than adding more special-case repair logic.
