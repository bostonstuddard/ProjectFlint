# Project Flint 0.1.0-alpha.22.2

## Intent
Correct the Clay Grinder visual model so it actually uses the vanilla grindstone silhouette while retaining Project Flint's clay material identity.

## Player-facing behavior
The placed Clay Grinder now has the vanilla grindstone geometry. Its wheel face and rim use the user-created clay texture. Gameplay behavior is unchanged.

## Architecture
`assets/projectflint/models/block/clay_grinder.json` now inherits `minecraft:block/grindstone` and overrides the relevant texture variables rather than defining a separate element list.

## Design reasoning
Direct model inheritance prevents Project Flint from drifting away from the requested vanilla grindstone silhouette and avoids maintaining a duplicate geometry definition.

## Tuning snapshot
No gameplay tuning changed.

## Assets and licenses
The clay wheel PNG is the user's supplied human-made texture and is copied byte-for-byte. No texture pixels were generated or edited. Vanilla Minecraft's grindstone model is referenced as a model parent rather than copied into Project Flint.

## Advancement coverage
No advancement changes.

## Validation
JSON/resource validation is run for the release.

## Known limitations
The Clay Grinder remains floor-mounted in Project Flint; this release changes visual geometry only and does not add vanilla grindstone wall/ceiling placement behavior.

## Next release pressure
Continue alpha.22 consolidation and add grinder-specific recipes when their progression role is finalized.
