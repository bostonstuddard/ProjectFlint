# Project Flint v0.28.7-a

## Intent
Repair the v0.28.6-a world-entry crash, keep grinder recipe choices stable across repeated crafting, remove obsolete source artifacts, and make the Windows build workflow finish cleanly.

## Player-facing behavior
- Entering a world no longer crashes when Project Flint true darkness updates the lightmap.
- True zero-light darkness remains part of the Project Flint presentation.
- Clay Grinder and Wooden Grinder keep the player's selected single-input recipe after completing that recipe, provided the remaining input still satisfies it.
- If the selected recipe is no longer valid after consumption, the menu falls back to the first valid recipe; if none remain, selection clears.

## Architecture
Minecraft 1.21.11 generates the lightmap with the `LIGHTMAP` render pipeline and a uniform buffer. Project Flint now supplies a compatible fragment-shader resource override and no longer performs a post-render `writeToTexture` operation. The obsolete `ProjectFlintHardcoreDarkness` and `LightTextureMixin` classes are removed.

Grinder refreshes preserve the selected `RecipeHolder` identity across input-count changes. The Clay Grinder also suppresses the intermediate container refresh while consuming its completed recipe, matching the Wooden Grinder's atomic-consumption pattern.

## Design reasoning
The crash log identifies `ProjectFlintHardcoreDarkness.apply` as writing to a GPU color texture that lacks destination-copy usage. Retrying or swallowing that write would leave an invalid rendering design in place, so the implementation moved to the rendering stage Minecraft 1.21.11 actually uses.

Recipe selection is preserved by recipe identity rather than blindly preserving a numeric index, avoiding accidental selection changes if the valid recipe list changes.

## Tuning snapshot
No gameplay balance constants changed. Darkness still targets genuine black at zero block/sky light while allowing real light sources and Night Vision/Conduit visibility to work.

## Assets and licenses
No external textures, models, sounds, or third-party assets were added. The new lightmap shader is Project Flint source written for Minecraft 1.21.11's exposed lightmap uniform interface.

## Advancement coverage
No advancement changes are required: this release repairs rendering, menu state persistence, source hygiene, and build tooling without adding a new progression capability.

## Known limitations
Shader/resource overrides are tied to Minecraft 1.21.11's current lightmap interface and should be revalidated before changing Minecraft versions. Shader packs may provide their own lighting pipeline and can supersede vanilla/Project Flint lightmap presentation.

## Validation
- The modified Clay Grinder and Wooden Grinder menu classes compile successfully against the uploaded source tree's Minecraft 1.21.11 mappings and cached Fabric API classes.
- The release validator checks JSON validity, version/document consistency, removal of retired source files, inactive legacy mixins, lightmap shader presence, and grinder-selection persistence code.
- The supplied crash log was traced to Project Flint's retired GPU texture upload path.
- Full Gradle assembly could not be completed in the sandbox because the Loom plugin artifact could not be externally resolved; this was a dependency-resolution limitation, not a reported Java compile error.
- A full interactive Minecraft client world-entry test is not available in the build container; the invalid `writeToTexture` path itself has been removed from runtime.

## Next release pressure
Playtest darkness with and without Iris shader packs, and repeatedly craft alternate Clay/Wooden Grinder recipes to confirm selection stays stable across all recipe-count boundaries.
