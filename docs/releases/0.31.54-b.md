# Project Flint v0.31.54-b — Consistent Rock Mining & Documentation

## Intent
Stop instant stone cracking / server-canceled ghost breaks caused by generic Utility Vest placement recovery; restore Minecraft's tool-based terrain progression and maintain accurate project records.

## Player-facing behavior
Hand/food/vest attempts to break Stone, Cobblestone, Granite, Diorite, Andesite and other ordinary pickaxe rocks no longer start break progress. Wooden and Hardwood Pickaxes work at 13.5 seconds; the Hardwood Hammer now takes 12 seconds on stone/rock. Coal yields 1 (2 with Hammer). Ordinary Iron/Copper Ore needs Hammer or appropriate vanilla Pickaxe. Vegetation remains harvestable under the Utility Vest's explicit plant rules; the vest alone no longer dismantles Well beams/pulleys or other placed blocks.

## Architecture
`OreMiningRules` now controls vanilla rock-family checks and mining tiers centrally. Client progress, `AttackBlockCallback`, `PlayerBlockBreakEvents.BEFORE` and server loot/destruction use the same permission path. The old hardness/placement-based Vest shortcuts are removed; legacy placement saved-data class is retained for world compatibility, but its recording Mixin is disabled. See ADR 0010 and `docs/CURRENT_SYSTEMS.md`.

## Design reasoning
Player equipment cannot be a substitute for a held mining tool. The bug previously made the client predict fast breaking (~7 ticks) while the server rejected it; early-world editing must be legible and progressive.

## Tuning snapshot
Vanilla rock targets: 270 ticks for Wooden/Hardwood Pickaxe, 240 for Hardwood Hammer. Iron/Copper stone ore uses Hammer 270 ticks. Inaccessible ore takes 900 ticks without drops. Invalid stone tool: no progress. Vanilla Pickaxes remain subject to vanilla mining-tier tags.

## Assets and licenses
No new image/texture assets or external licenses. No changes to torch models or the user-supplied asset provenance.

## Advancement coverage
No new tracked progression stage: this release corrects mining permissions. Flint Quests is still the authoritative quest integration; no Project Flint advancement/EMI plugin is added.

## Known limitations
A full Gradle build and in-world singleplayer/multiplayer testing must still be performed. Vanilla pickaxe-tag stone family is intentionally broader than specific listed rocks; unusual vanilla mechanics should be verified in a smoke test. No K-key machine recipes changed.

## Validation
Source/static regression checks and resource JSON parsing performed. Actual compilation/runtime result must be reported separately; do not infer it from static validation.

## Next release pressure
Playtest with and without vest using hand, food, Wooden Pickaxe, Hardwood Pickaxe, Hammer, vanilla higher-tier pickaxes; compare naturally generated and placed stone, cobble, diorite, granite, andesite and ores. Verify Well recovery and all vegetation permissions after removing the generic Vest shortcut.
