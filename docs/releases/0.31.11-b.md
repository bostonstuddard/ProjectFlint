# Project Flint v0.31.11-b — Crude Stone Cutters Assembly Hotfix

## Intent
Restore the intended nerfed Crude Stone Cutters assembly recipe on the current main development line.

## Player-facing behavior
Players can complete Crude Stone Cutters from 1 Plant Tool Binding, 2 Very Refined Stone, and 1 Lightly Burnt Twig by striking the finished assembly with a Crude Stone Hammer or another hammer-like Project Flint tool.

## Architecture
The physical assembly block already treated one binding as sufficient. This patch synchronizes the earlier interaction-layer completion gate with that block-level rule by accepting any valid assembly state with at least one binding.

## Design reasoning
The recipe had previously been reduced from two bindings to one, but a stale pre-check still required the old count and intercepted the hammer action before the assembly block could validate the new recipe.

## Tuning snapshot
- Plant Tool Binding: 1
- Very Refined Stone: 2
- Lightly Burnt Twig: 1
- Finishing action: hammer strike
- Output: 1 Crude Stone Cutters

## Assets and licenses
No assets were added or changed in this hotfix.

## Advancement coverage
The existing Crude Stone Cutters advancement remains unchanged and is still awarded when the assembly successfully completes.

## Known limitations
Legacy assemblies containing the retired second binding remain supported; the assembly block returns the unnecessary extra binding when such an old assembly is completed.

## Validation
The release validator checks that the interaction-layer completion gate accepts one binding and no longer requires exactly two bindings.

## Next release pressure
Continue progression/content work on top of the corrected cutters assembly without changing its one-binding cost unless intentionally rebalanced.
