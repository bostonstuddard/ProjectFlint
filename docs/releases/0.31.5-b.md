# Project Flint v0.31.5-b

## Intent

Open the next construction/cooking tier with a shoreline Limestone material chain, reusable Recipe Parchment infrastructure, parchment-only cabinet storage, and the long-burning Primitive Stove while preserving the existing Wood/Water progression systems.

## Player-facing behavior

- Limestone now generates as occasional submerged disks in Rivers, Frozen Rivers, Beaches, Snowy Beaches, and Stony Shores, using ocean-floor placement so deposits appear in riverbeds and shallow water off shorelines.
- Natural Limestone requires the Advanced Flint Multitool and drops Cobbled Limestone.
- **8 Cobbled Limestone -> 1 Smooth Limestone** in the Sanding Station. Cobbled and Smooth Limestone both have gravity.
- Smooth Limestone can be fired by kiln-class processing into stable Limestone.
- Wooden Grinder + Flint File: **4 Limestone -> 4 Limestone Bricks** and **4 Limestone Bricks -> 4 Chiseled Limestone**. Each filing action costs one Flint File durability.
- Sanding Station: **1 Limestone Brick -> 1 Polished Limestone**.
- Limestone, Limestone Bricks, Chiseled Limestone, and Polished Limestone do not fall. The processed building blocks are directly recoverable with an Advanced Flint Multitool.
- Throwing **16 Limestone Bricks + 1 White Dye + 1 Black Dye** above a full, unlinked Water Pot consumes the full bucket and outputs **16 Checkered Tiles**.
- Checkered Tile and Glazed Checkered Tile have gravity and are directly recoverable with an Advanced Flint Multitool.
- Sanding Station cycles **Checkered Tile -> Glazed Checkered Tile -> Checkered Tile** at 1:1.
- Sanding Station: **1 Book and Quill -> 1 Recipe Parchment**. Recipe Parchment stacks to one and permanently retains the first recipe id assigned to it.
- Wooden Grinder: **1 Wooden Beam + 1 Crushed Stone -> 1 Wooden Cabinet**. The cabinet has 27 slots and rejects every item except Recipe Parchment.
- The Wooden Cabinet uses the supplied oak-cabinet body with the supplied stone countertop appearance, including a separate open-front state.
- Primitive Stove is registered with the supplied kiln/stove artwork and a GUI. It consumes **4 stripped overworld logs** to ignite for **30 minutes**.
- Primitive Stove can be lit with Project Flint firestarters, Flint and Steel, or Fire Charges.
- Unbound/no-parchment stove use is restricted to food-like kiln recipes. A bound Recipe Parchment can resolve its stored Project Flint kiln recipe and process the supplied materials.
- Primitive Stove runs **30% faster than the Mortar Kiln**, not merely 30% faster than the base kiln.

## Architecture

`RecipeParchmentItem` stores an immutable `ProjectFlintRecipe` id in `DataComponents.CUSTOM_DATA`. `bindRecipe` refuses to overwrite a parchment that already carries any recipe id, giving later Bookshelf research a stable one-recipe-per-parchment contract.

`WoodenCabinetBlockEntity` is a 27-slot `RandomizableContainerBlockEntity` with hard placement and shift-click filters for Recipe Parchment only. Its open state is synchronized into the block model so the supplied open-front cabinet asset is visible while used.

`PrimitiveStoveBlockEntity` owns fuel, parchment, four material slots, output, burn time, and recipe progress. `PrimitiveStoveRecipeRegistry` bridges stable parchment ids to the existing `PrimitiveProcessingRegistry` kiln definitions so cooking behavior does not fork into a duplicate recipe list.

The Water Pot tile-washing ritual is server-side block-entity behavior and is disabled whenever the pot is linked into a Lumber Processor.

## Design reasoning

Limestone introduces a building material whose early forms remain physically unstable while later fired/filed forms become reliable construction blocks. Requiring the Advanced Flint Multitool keeps deposits from short-circuiting earlier stone progression.

Checkered tiles deliberately use a world interaction rather than another workstation slot: the full Water Pot acts as a one-bucket wash bath, makes both dyes meaningful, and consumes the water resource.

Recipe Parchment is implemented as immutable metadata now so later Bookshelf unlocks can write a recipe once without changing the Primitive Stove format. The cabinet exists specifically to keep those one-stack research items organized without becoming another general-purpose chest.

## Tuning snapshot

- Limestone disk placement: eligible river/beach biomes, **1-in-4 placement chance**, radius **2-4**, submerged ocean-floor placement.
- Limestone harvest tool: **Advanced Flint Multitool**.
- Cobbled Limestone sanding: **8 -> 1 Smooth Limestone**.
- Limestone filing: **4 -> 4 Bricks**, 1 Flint File durability.
- Chiseling: **4 Bricks -> 4 Chiseled**, 1 Flint File durability.
- Polishing: **1 Brick -> 1 Polished**.
- Tile wash: **16 Bricks + White Dye + Black Dye + 1 full Water Pot -> 16 Checkered Tiles**.
- Recipe Parchment stack size: **1**.
- Wooden Cabinet storage: **27 Recipe-Parchment-only slots**.
- Wooden Cabinet recipe: **1 Wooden Beam + 1 Crushed Stone**.
- Primitive Stove ignition fuel: **4 stripped logs**.
- Primitive Stove burn duration: **30 minutes**.
- Primitive Stove processing speed: **1.30x Mortar Kiln speed**.

## Assets and licenses

This release uses only the requested subset of the user-supplied update archive: six Limestone textures, Checkered/Glazed Checkered Tile textures, Recipe Parchment, the supplied animated stove front plus side/top textures, and the supplied oak-cabinet/stone-counter texture/model family. Unrelated files from the large source archive are not imported.

The supplied cabinet source models were namespace-adapted for Project Flint without redrawing their textures. The active stove front preserves the supplied three-frame animation and `.mcmeta` timing.

## Advancement coverage

The unified ProjectFlint advancement page gains ten progression steps covering discovery/harvest of Limestone, smoothing and firing, Limestone Bricks, Chiseled and Polished finishes, Checkered and Glazed tiles, Recipe Parchment, and the Recipe Cabinet. The existing detailed single-page progression structure remains intact.

## Known limitations

No Primitive Stove survival construction recipe was specified in this design pass, so this release does not invent one. The block is registered and available in the Project Flint creative inventory for testing until a progression cost is defined.

Recipe Parchment has the immutable recipe-metadata format and Primitive Stove resolver, but this release does not invent a Bookshelf inscription/selection interaction. Blank parchment is craftable now; later Bookshelf recipe-unlock work can bind it through `RecipeParchmentItem.bindRecipe(...)` without changing saved-item format.

## Validation

Release validation covers v0.31.5-b build/cleanup wiring, JSON parsing, all new item/block registrations and translations, gravity/stability classes, Advanced Flint Multitool mining gates and drops, both Flint File Limestone recipes, Sanding Station progression and tile loop, Water Pot wash quantities/water consumption, Limestone river/shore worldgen, parchment immutability, cabinet slot restrictions, Primitive Stove fuel/duration/speed/recipe bridge, supplied asset presence, and the 168-entry unified advancement tree.

A full Gradle compile was attempted with the bundled Gradle 9.2.1 bootstrap. Gradle stops during plugin resolution because Fabric Loom `1.14.10` is not present in the available offline cache, before Java compilation begins.

## Next release pressure

Define the Primitive Stove's survival construction recipe and the first Bookshelf interaction that binds a concrete recipe id onto blank Recipe Parchment. Playtest Limestone frequency in Rivers versus shallow Beaches, verify falling tiles do not become tedious to build with, and tune the 1-in-4 disk rarity if shoreline deposits are too common or too scarce.
