# Project Flint v0.31.15-b

## Intent
Remove Minecraft Realms from Project Flint's title-screen experience and prevent its background title-screen availability/data polling.

## Player-facing behavior
- The Minecraft Realms button no longer appears on the title screen.
- The remaining title-screen buttons close the gap automatically; Mod Menu's Mods button is shifted with the rest of the menu when present.
- Realms notification/news/trial/invite icons no longer appear or update on the title screen.
- Project Flint no longer performs the title-screen Realms availability check or starts Realms notification data subscriptions.

## Architecture
Three client mixins implement the change: `MinecraftRealmsMixin` forces the client Realms permission gate off, `RealmsAvailabilityMixin` resolves availability locally without making the normal service request, and `TitleScreenMixin` removes/reflows the Realms widget and detaches the notification screen.

## Design reasoning
This is implemented directly in Project Flint so players do not need a separate client utility mod just to remove a service Project Flint does not use.

## Tuning snapshot
The removed title-screen row uses Minecraft's existing 24-pixel vertical button spacing, so widgets below the Realms row are moved upward by exactly 24 pixels.

## Assets and licenses
No external code or assets were imported. The behavior was independently implemented from Project Flint's Minecraft 1.21.11 mapped client classes.

## Advancement coverage
No advancement changes are required because this is client UI/network cleanup rather than gameplay progression.

## Known limitations
This intentionally removes Project Flint's normal title-screen path into Realms. It does not delete Mojang's Realms classes from the Minecraft JAR.

## Validation
The three new mixin classes compile against the Minecraft 1.21.11 mapped client API in an isolated javac signature check. Full Gradle configuration remains unavailable in the current offline environment because Fabric Loom 1.14.10 is not present in the plugin cache.

## Next release pressure
Watch for title-screen layout conflicts from future menu mods that add widgets at unusual vertical positions.
