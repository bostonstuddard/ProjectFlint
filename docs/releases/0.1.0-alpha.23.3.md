# Project Flint 0.1.0-alpha.23.3

## Interface and asset corrections

- Restored the dedicated Flint Firestarter texture from the Project Flint texture source instead of reusing the Bone Firestarter image.
- Rebuilt the Advanced Kiln screen as a Project Flint-owned interface. Its five machine slots and all 36 player inventory slots now share the exact same coordinates between the menu and rendered background.
- Restored visible inventory slot wells to the Clay Grinder screen.
- Rebuilt the Mortar Chest interface around exactly seven storage slots, with a matching custom Project Flint chest screen rather than the vanilla nine-slot row artwork.
- Rebuilt the Mortar Chest block model into a chest-shaped body/lid/latch using only `projectflint:block/mortar_bricks`; the temporary full-width base plate was removed and the lower body includes its own bottom face.
- Removed the unintended Burnt Log item, processing recipe, advancement, creative-tab entry, models, texture, and documentation references. Advanced cast-tool assembly now consumes two existing Burnt Branches instead.

## Compatibility note

The advanced tool assembly blockstate property changed from `logs` to `branches`. Existing development-world assembly blocks may reset their temporary assembly progress after updating.
