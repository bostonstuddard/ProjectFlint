# Project Flint 0.1.0-alpha.23

## Scope
This release completes the requested post-alpha.22 primitive progression expansion while preserving the supplied alpha.22.6.1 behavior that was not explicitly changed.

## Asset and presentation repairs
- Placed ground Flint no longer references a missing vanilla item-model path; the assembly uses `projectflint:item/ground_flint`.
- Bone Firestarter uses the uploaded 16×16 PNG byte-for-byte.
- Sleeping Bag inventory item uses the second uploaded 16×16 PNG byte-for-byte.
- Early durability bars only appear after actual durability loss.
- Reed Backpack keeps its chest-slot behavior and now renders a dedicated item layer on the player's back.
- Mortar Chest is directional, chest-shaped, and stores 7 slots through a dedicated menu.

## Brushing and woven gear
- Bone Brush: Sand/Red Sand retains the existing 3.5-second Sand Flake → Clay behavior. Gravel now takes the same time, disappears, and yields exactly 1 vanilla Flint.
- Reed Backpack: 8 Woven Fans + 2 Plant Tool Bindings + 2 Woven Wool.

## Glass, molds, and Advanced Kiln
- Clay Grinder: 4 Glass Shards → 1 Unfired Kiln Glass.
- Baked Clay Kiln: Unfired Kiln Glass → Advanced Kiln Glass.
- Baked Clay Kiln: Crude Clay Block → Unfired Clay Mold Base.
- Clay Grinder: one mold base can be shaped into Unfired Axe / Brick / Cutters / Multitool molds.
- Baked Clay Kiln: each unfired mold → corresponding fired mold.
- Clicking the front of a valid 2×2×2 Mortar Brick cube with Advanced Kiln Glass consumes one glass and replaces the cube with the Advanced Kiln multiblock.
- Advanced Kiln load: 8 Burnt Branches + 8 vanilla Flint + 4 Fired Clay + 1 Fired Clay mold. Processing starts when full and lasts 200 ticks / 10 seconds. Branches, Flint, and Fired Clay are consumed; the mold remains installed until shift-empty-hand retrieval.
- Fired Axe Mold → Flint Axe Pieces.
- Fired Brick Mold → 6 Mortar Bricks.
- Fired Cutters Mold → Flint Cutter Piece.
- Fired Multitool Mold → Refined Flint Multitool Piece.

## Advanced tools
- A cast piece is started as a physical ground assembly; adding 2 Burnt Branches completes the corresponding tool. Components can be removed before completion.
- Flint Axe: 256 durability, 5.75 attack damage, 0.60 attack speed. Supported logs take 200 ticks / 10 seconds and return their matching stripped log. A stripped log held with the axe in the offhand can be hand-worked into 2 matching slabs.
- Flint Plant Cutters: 256 durability, 4.25 attack damage, 1.40 attack speed. Their special harvesting is intentionally limited to Sugar Cane → 1 Reed Roll per harvested column and Short Grass → 1 Plant Tool Binding.
- Advanced Flint Multitool: 512 durability, 4.85 attack damage, 1.25 attack speed. It inherits the primitive Hammer/Cutter/Multitool capability family with higher process speed. Gravel → 1 Flint + 1 Flint Chip; Dirt/Grass → 3 Flint Chips; leaves → 3 Branches with 5% Apple chance; it retrieves a placed Sleeping Bag intact.

## Advancement reliability
- New item/action advancements cover all alpha.23 glass, mold, kiln, cast-piece, assembly, harvesting, and final-tool milestones.
- A low-frequency server inventory reconciliation pass awards already-earned item milestones even if their original process callback was missed.

## Validation
- All JSON resources parse successfully.
- Every Project Flint advancement parent resolves to an existing advancement file.
- All changed Java sources compile against the cached 1.21.11 Minecraft/Fabric API surface in the validation harness; temporary dependency stubs were used only for third-party library types unavailable in this isolated runtime.
- Exact SHA-256 equality was verified between both uploaded PNGs and the copies shipped under `assets/projectflint/textures/item/`.
- A normal Java 21 `build.bat` build and first client launch should still be run on the target development machine as the final runtime gate.
