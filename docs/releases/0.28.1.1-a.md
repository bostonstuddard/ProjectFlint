# Project Flint v0.28.1.1-a

Small follow-up hotfix release.

## Included
- `mortar_bricks` stack size increased back to **32**.
- Wooden Grinder leather recipes now resolve reliably regardless of slot order, and the leather ingredient is consumed correctly.
- Black Bear and Brown Bear textures were updated to fully cover their mapped UV regions so the bear bodies do not render with transparent gaps.
