# Project Flint 0.1.0-alpha.22.3

## Intent
Continue the alpha.22 consolidation work with a focused gameplay/regression batch: bring the Clay Grinding Base into parity with the completed Grinder, correct animal reaction behavior, establish the first real grinder recipe chain, apply the project-owner texture refresh, and tighten Flint Multitool interactions.

## Player-facing behavior
- Clay Grinding Bases are Flint-Multitool dismantle targets like completed Clay Grinders. They salvage 4 Super Heated Clay; manual dismantling also returns any Very Refined Stone already inserted.
- Squids no longer use their vanilla flee-on-damage goal, so damaged squids remain compatible with Project Flint's territorial water aggression.
- Horses are excluded from Project Flint retaliation and therefore retain panic/flee behavior when struck.
- Plant Seeds display as **Roasted Seeds**.
- Unfired Woven Bowl displays as **Unfired Clay Bowl**.
- Unfired Clay Ball displays as **Unfired Clay**. Existing registry IDs are retained for save compatibility.
- Sheep wool output is converted to custom Project Flint Wool.
- Chickens, Cows, Horses, Pigs, Wolves, and Ocelots add one custom Animal Bones drop on death.
- Four Crude Reeds can be hand-worked with either Multitool into a Reed Roll. Right-clicking water with a Reed Roll produces a Sugarcane Roll. Four Sugarcane Rolls in the Clay Grinder produce one Sanding Paper.
- The Clay Grinding Base visually matches the grindstone-style Clay Grinder, the single Very Refined Stone pile is visible, and the Clay Grinder inventory definition now points directly at its block model.
- The supplied Project Flint icon is used by Fabric metadata/Mod Menu.
- Flint Multitool total attack damage is 3.5. Direct flowers and Project Flint forage bushes break immediately with it, and held flowers can be hand-worked with either Multitool for that tier's normal petal output.

## Architecture
- `PrimitiveAnimalDropSystem` owns the new wool replacement and Animal Bones loot behavior through Fabric's loot-drop event.
- `AnimalRetaliationSystem` explicitly excludes Horses; `SquidMixin` suppresses only the vanilla priority-1 flee goal while retaining Project Flint's squid pursuit logic.
- `ClayGrinderRecipe` now carries an explicit `input_count`, allowing the custom grinder architecture to consume multi-item inputs without inheriting vanilla stonecutter behavior.
- `PrimitiveInteractionSystem` and `StoneWorkingSystem` own Reed Roll hand-working, flower hand-working, and water washing.
- Existing registry IDs for the three renamed clay/seed items are intentionally preserved; only localization/player-facing names change.

## Design reasoning
This release avoids replacing stable registry IDs for cosmetic renames, which protects existing test worlds. Animal behavior changes are isolated to the existing Project Flint AI/loot systems instead of replacing whole vanilla entities. The first grinder recipe exercises the custom alpha.22 recipe architecture with a real multi-count input, while keeping the Grinder independent from vanilla stonecutting.

## Tuning snapshot
- Flint Multitool: 256 durability, 3.5 total attack damage, cutter attack speed.
- Reed Roll: 4 Crude Reeds per roll; standard 8-strike hand-working; one Multitool durability on completion.
- Water washing: 1 Reed Roll → 1 Sugarcane Roll.
- Clay Grinder: 4 Sugarcane Rolls → 1 Sanding Paper.
- Clay Grinding Base salvage: 4 Super Heated Clay; manually inserted Very Refined Stone is additionally returned on Flint-Multitool dismantle.
- Supported Animal Bones death drop: 1 per Chicken/Cow/Horse/Pig/Wolf/Ocelot.

## Assets and licenses
All texture-fill PNGs supplied for this release are project-owner-provided human-made assets and are copied byte-for-byte with no pixel edits. Exact target/source/hash records are in `docs/texture_provenance.json` and `docs/TEXTURE_PROVENANCE.md`. The Project Flint icon is likewise copied exactly from the direct upload and referenced in `fabric.mod.json`. Animal Bones uses an exact unmodified copy of the human-made vanilla-style bone texture already present in the approved `textures.zip` asset source.

## Advancement coverage
No new advancement nodes are added in this focused repair/content pass. Existing grinder, clay, tool, and processing advancement coverage is preserved. The Reed Roll/Sanding Paper chain should receive dedicated advancement placement when the next progression slice establishes what Sanding Paper unlocks.

## Validation
- All Project Flint JSON resources are parsed by `tools/validate_release.py`.
- Texture provenance is checked one-to-one against every PNG under `assets/projectflint/textures/`, including SHA-256 equality and approved source classes.
- Static release checks cover the new grinder recipe/input count, Clay Grinding Base salvage, animal behavior/drop hooks, renamed localization, Mod Menu icon metadata, and Flint interaction/damage markers.
- A full Gradle compile cannot currently complete in this artifact environment because Fabric Loom 1.14.10 cannot be resolved by the local Gradle plugin repositories; this occurs before Java compilation.

## Known limitations
- Project Flint Wool is currently a material item, not a family of placeable colored wool blocks.
- Animal Bones currently has one generic variant for all supported species.
- Sanding Paper has no downstream use yet; this release establishes its acquisition route only.
- The Clay Grinding Base uses a partial grindstone-style visual but remains its existing assembly block mechanically.

## Next release pressure
Define the first actual Sanding Paper use and the next woodworking/material-finishing unlock, then add advancement coverage for Reed Roll → Sugarcane Roll → Sanding Paper. Continue consolidating animal/resource drops into explicit progression rules before adding broader content tiers.
