# Project Flint v0.28.24-a — Recipe Guide Polish

## Intent
Make Project Flint's recipe reference feel like a deliberate part of the mod rather than a temporary UI bolted onto workstation screens, while fixing Clay Grinder recipe discovery and keeping the clean survival inventory untouched.

## Player-facing behavior
Clay Grinder, Wooden Grinder, and Advanced Kiln screens now use a compact book-shaped Project Flint button in the upper-right corner instead of the large `Recipes` label. The guide has a corrected footer layout, hover names for every ingredient/output icon, and a global **K** keybind. Permanent Campfire is no longer shown as a guide station. Clay Grinder recipes now populate correctly.

## Architecture
`RecipeGuideButton` owns the small code-rendered workstation book icon. `ProjectFlintRecipeGuideScreen` remains an in-game UI and never touches vanilla recipe-book state. `ClayGrinderRecipeGuideRegistry` is a client-safe mirror of the data-driven `projectflint:clay_grinding` JSONs because Minecraft 1.21.11's client recipe container only exposes its synchronized recipe-property/stonecutter data rather than arbitrary custom recipe types. The release validator checks the mirror against the JSON set.

## Design reasoning
Advancements answer "what should I do next?" while the custom recipe guide answers "what can this workstation make?". The survival inventory therefore stays visually clean. Permanent Campfire recipes were removed because that station is an early progression mechanic already taught by advancements and does not add recipe capability beyond the later kiln chain.

## Tuning snapshot
- Default recipe-guide key: **K**.
- Guide stations: **Baked Kiln, Mortar Kiln, Clay Grinder, Wooden Grinder, Advanced Kiln**.
- Five recipes per page.
- Ingredient and output stacks show normal item hover tooltips.

## Assets and licenses
No texture pixels, audio, models, or external assets were added. The workstation recipe-book icon is drawn directly by GUI code using the existing Project Flint interface palette.

## Advancement coverage
Tool Era, Clay Era, and Wood Era advancement tabs are unchanged from v0.28.22-a/v0.28.23-a.

## Known limitations
The Clay Grinder guide mirror must be updated whenever new `projectflint:clay_grinding` JSONs are added. `tools/validate_release.py` now treats any mismatch as a release validation failure so this cannot be forgotten silently.

## Validation
- All resource JSON files parse successfully.
- Clay Grinder guide entries are validated one-for-one against the current `clay_grinding` data recipes.
- Survival inventory recipe-book hiding remains active.
- Recipe guide remains marked as in-game UI, preserving the v0.28.23-a blur-crash fix.
- Full Gradle assembly may still require Fabric Loom dependencies unavailable in restricted/offline environments.

## Next release pressure
As station counts grow, consider adding station tabs/icons or filtering rather than increasing the number of global pages indefinitely.
