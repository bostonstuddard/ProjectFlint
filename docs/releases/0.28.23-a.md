# Project Flint v0.28.23-a — Workstation Recipe Guide Hotfix

## Intent
Restore the established clean survival inventory and make the v0.28.22-a recipe reference behave as the intended custom workstation UI.

## Player-facing behavior
- The survival inventory recipe-book button is hidden and disabled again.
- Project Flint recipes are **not** exposed through or substituted into Minecraft's survival recipe book.
- Clay Grinder, Wooden Grinder, and Advanced Kiln keep their dedicated **Recipes** buttons.
- Those buttons now open the custom Project Flint recipe screen without crashing.
- Tool Era, Clay Era, and Wood Era advancements are preserved unchanged.

## Architecture
`InventoryScreenMixin` once again forces the survival recipe book closed, moves its button offscreen, and cancels recipe-book activation. `ProjectFlintRecipeGuideScreen` remains a separate custom screen reached only from Project Flint workstation GUIs. The guide now overrides `isInGameUi()` so Minecraft 1.21.11 renders its normal transparent in-world backdrop instead of attempting a menu blur pass.

## Design reasoning
The primitive inventory is intentionally clean and does not use vanilla crafting discovery. Advancements answer “what should I try next?” while workstation-local recipe guides answer “what can this machine make?”. Keeping those systems separate preserves the established inventory design and makes recipe discovery contextual to the machine being used.

## Tuning snapshot
- Survival recipe book: hidden and disabled.
- Custom guide entry points: Clay Grinder, Wooden Grinder, Advanced Kiln.
- Recipe guide pagination/station browsing: unchanged from v0.28.22-a.
- Advancement count/era structure: unchanged from v0.28.22-a.

## Assets and licenses
No textures, models, sounds, or third-party assets are introduced or modified by this hotfix.

## Advancement coverage
No advancement JSON is changed. The Tool Era, Clay Era, and Wood Era split from v0.28.22-a remains intact.

## Known limitations
The recipe guide is still a reference screen rather than a recipe-unlock system. Entries remain visible regardless of whether the player has personally discovered each process.

## Validation
- `InventoryScreenMixin` contains no recipe-guide entry point.
- The survival recipe-book button is moved offscreen and activation is cancelled.
- All three workstation screens retain their custom **Recipes** button.
- `ProjectFlintRecipeGuideScreen.isInGameUi()` returns `true`, preventing the `Can only blur once per frame` crash path.
- Existing advancement/resource validation remains enabled.

## Next release pressure
Keep all future recipe-discovery UI local to Project Flint progression/workstations unless the survival inventory itself is deliberately redesigned later.
