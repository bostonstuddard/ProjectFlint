# Project Flint v0.31.61-b — Glass compilation and PMI Sheet workstation hotfix

## Player-facing changes

- Pure Mica Insulated Glass remains normal, transparent, light-passing glass. Its registration now resolves correctly against Minecraft 1.21.11.
- PMI Sheets are made **only** at the Hardwood Crafting Table: 1 Pure Mica Insulated Glass + 1 Bone Knife → 2 Sheets. The Knife loses one durability. Personal crafting no longer provides this recipe.

## Build fix

- Replace the invalid `GlassBlock` import/construction with Mojang-mapped `TransparentBlock`, using copied `Blocks.GLASS` properties. No other light, drop or vest mechanic changes.
- Update `build.bat`, Gradle mod version and new `APPLY_PROJECTFLINT_0_31_61_B.bat`. The apply script explicitly deletes the superseded `personal_pmi_sheets.json` left behind by v0.31.60-b; the build script calls it before compiling. Existing no-daemon Gradle behavior and `dist` JAR publishing are preserved.
- Update Field Guide, personal Recipe Guide registry and current developer documentation/ADR. Hardwood Table recipe JSON and guide remain.
