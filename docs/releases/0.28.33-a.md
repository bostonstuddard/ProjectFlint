# Project Flint v0.28.33-a — Flint Plant Cutters Foliage Parity

## Intent
Make the dedicated Flint Plant Cutters behave as a true upgrade for vegetation instead of inexplicably losing plant interactions already available to the Flint Multitool.

## Player-facing behavior
Flint Plant Cutters can now handle the same plant and foliage targets as the Flint Multitool: Tall/Short Grass, flowers, Dead Bushes, normal Bushes, Firefly Bushes, leaves, Sugar Cane, Leaf Litter, forage bushes, Sweet Berry propagation, and gourd flesh harvesting. Existing specialized outputs remain intact.

## Architecture
Plant functionality is kept separate from generic `CUTTER` capability inheritance. `ToolCapabilities.canDirectHarvestPlant(...)` and the new `canHarvestLeaves(...)` explicitly include Flint Plant Cutters, while foliage permission/speed paths use `ModItems.isPlantCutterLike(...)`. This prevents the specialized plant tool from accidentally inheriting unrelated clay, workstation, or structural cutter interactions.

## Design reasoning
A dedicated plant cutter should never be worse than the Flint Multitool at vegetation. At the same time, granting it the entire generic Cutter capability would also unlock non-plant mechanics. The patch therefore extends only the plant-facing boundary.

## Tuning snapshot
- Flint Plant Cutters use the Flint Multitool's 2x cutter-speed multiplier.
- Flint foliage uses the existing 4x foliage multiplier.
- Grass yields match Flint Multitool tier: 2 Crude Plant String from Short Grass and 4 from Tall Grass.
- Leaf harvesting matches Flint Multitool tier: 4 Twigs + 2 Branches.
- Existing forage-bush yield remains 6 Twigs.

## Assets and licenses
No asset changes.

## Advancement coverage
No new advancement is required; the existing Flint Plant Cutters advancement already introduces the tool. Its practical functionality now matches that progression claim.

## Known limitations
This is plant/foliage parity only. Flint Plant Cutters intentionally do not inherit the Flint Multitool's stone, dirt, gravel, hammer, or workstation-dismantling abilities.

## Validation
The release validator checks that Flint Plant Cutters are recognized by plant-facing harvest/speed helpers, can directly harvest Flint-tier plants and leaves, receive Flint-tier grass yields, and are not added to the generic `CUTTER` capability table.

## Next release pressure
Continue Wood → Water progression after specialized tools have consistent capability inheritance.
