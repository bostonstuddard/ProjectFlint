# Project Flint v0.28.34-a — Flint Plant Cutter Progression Correction

## Intent
Correct v0.28.33-a so the dedicated Flint Plant Cutters are an actual plant-specialization upgrade rather than merely matching the older Flint Multitool.

## Player-facing behavior
Flint Plant Cutters now perform vegetation work at the Advanced Flint Multitool tier. Tall Grass, Leaf Litter, leaves, forage bushes, and other shared plant targets receive advanced-tier speed/yields, while the cutters retain their specialized Short Grass -> Plant Tool Binding progression output.

## Architecture
`ToolCapabilities.isAdvancedPlantTier(...)` defines the plant-only tier shared by Flint Plant Cutters and the Advanced Flint Multitool. `cutterSpeedMultiplier(...)` and `foliageCutterSpeedMultiplier(...)` use that helper, and plant-yield branches use the same authority. The global `CUTTER`, `MULTITOOL`, earth, hammer, and dismantling capability tables remain unchanged.

## Design reasoning
The Flint Plant Cutters are made later specifically to accelerate plant progression. Matching the normal Flint Multitool made the specialization a sidegrade. Plant Cutters should match Advanced Flint Multitool performance for vegetation while keeping their own specialized outputs and remaining intentionally narrow outside plant work.

## Tuning snapshot
- Plant Cutter general plant speed: Advanced Flint Multitool multiplier (3x base where the shared cutter multiplier applies).
- Plant Cutter foliage speed: advanced foliage tier (6x the base foliage rate through the existing doubled foliage rule).
- Tall Grass: advanced-tier Crude Plant String yield (6).
- Full 4-layer Leaf Litter: advanced-tier Plant Fiber yield (6), still scaled 25/50/75/100% by layers and rounded up.
- Leaves: advanced-tier output path (3 Branches plus the existing 5% Apple chance).
- Forage bushes: advanced-tier 8 Twigs.
- Short Grass: **1 Plant Tool Binding** remains the dedicated Plant Cutter output.

## Assets and licenses
No asset changes.

## Advancement coverage
No new advancement is required. The existing Flint Plant Cutters milestone already represents this specialization; its actual performance now matches that progression role.

## Known limitations
Advanced-tier inheritance is deliberately plant-only. Flint Plant Cutters do not gain the Advanced Flint Multitool's dirt/gravel/stone processing, hammer functions, or workstation recovery.

## Validation
The release validator checks the dedicated advanced-plant-tier helper, advanced speed/yield routing, preserved Short Grass Plant Tool Binding output, and continued exclusion from the global generic Cutter capability.

## Next release pressure
Continue Wood -> Water progression with specialized tools now respecting their intended upgrade tiers.
