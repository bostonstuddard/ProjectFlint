# Project Flint v0.28.7-a — Hardcore Darkness + Loose Rock Hotfix

## Scope
This follow-up hotfix applies only the two issues reported after the previous 0.28.7-a patch:

1. hardcore darkness was not behaving correctly;
2. the placed Loose Rock / Rock Stockpile visual had regressed into a flat single-color square.

## Changes

### Hardcore darkness
- Project Flint no longer depends on `LightTextureMixin` to overwrite the client lightmap texture after vanilla updates it.
- The mod now overrides Minecraft's `assets/minecraft/shaders/core/lightmap.fsh` instead.
- The shader keeps the intended Project Flint rule: vanilla brightness/gamma only lifts texels that already have real light, so zero-light areas stay black.
- Night Vision style visibility support remains preserved.

### Loose Rock rendering
- Rebuilt all `rock_pile_*.json` models.
- Each loose rock is now a small multi-cuboid rock shape instead of a thin flat square plane.
- The full loose-rock texture is mapped across the visible faces so the model no longer samples only a tiny patch of the texture.

## Notes
- No texture pixels were edited for this hotfix.
- This patch changes only rendering/model resources plus the mixin/shader hookup for darkness.

## Validation
- Confirmed `projectflint.mixins.json` no longer activates `LightTextureMixin`.
- Confirmed the custom shader override exists at `src/main/resources/assets/minecraft/shaders/core/lightmap.fsh`.
- Confirmed all twelve `rock_pile_*.json` models were rewritten successfully and parse as valid JSON.
