# Project Flint v0.31.55-b — Depth, Axles and Basin Material Processing

## Intent
Preserve primitive progression without making reclaimed decorations unrecoverable, introduce deeper cave hazards and a new resource-processing loop, and correct Hardwood Table recipes and mining drops.

## Player-facing behavior
- Fat/Flint/vanilla Torches, Chicken Nests and Axles can be recovered by hand; machine and stone restrictions remain. Nest returns stored eggs.
- Hardwood Hammer tooltip explains ordinary Iron/Copper Ore capability; Stone Ore yields exactly 1 Raw Iron or 1 Raw Copper; Coal yields 2 Coal. Deepslate (including ores) cannot be mined with available survival tools.
- Below Y=0 in darkness away from direct sunlight or strong artificial light, Speluncaphobia gradually stacks, increases food depletion while food exceeds 6 and slows natural healing. Below Y=-40, Claustrophobia additionally reduces movement and damage. Direct sunlight or block light level 13+ clears both.
- Craft a placeable orientation-aware Axle from 8 Hardwood Sticks surrounding 1 Rope; every Hardwood tool now uses Hardwood Sticks, which appear in the Creative tab.
- Basin accepts Raw Iron, Raw Copper, Andesite, Granite, Diorite, Stone, Stone Dust, Gravel, Sand and Slag, with independent chance rolls. Every wash costs 1 hunger point; the Wood Dust/Tannin chain remains.
- Brick Furnace: Cobblestone -> Stone. Hardwood Table: secondary Basin recipe, stone-group slabs/stairs, restored early Hinged Doors, correctly separated 2-plank slab and stick recipes.

## Architecture
- `OreMiningRules` defines locked Deepslate; no client-only bypass or server drop fallback.
- `PlayerPlacedBlockLedger.isHandRecoverableDecoration` is an explicit safe-recovery whitelist, not a mining permission for the Vest. `ServerPlayerGameModeMixin` ejects Nest inventory before removing block.
- `PrimitiveEnvironmentEffectSystem` applies two new server-side MobEffects. Existing `FoodDataMixin` reduces healing. Effects are removed outside thresholds or in bright conditions.
- `BasinMaterialProcessingSystem` provides independent random rolls, with `BasinBlockEntity` owning input storage, hunger cost and output spawning. `BrickFurnaceRecipeRegistry` owns Stone smelting.
- Axle is a `RotatedPillarBlock` with axis-oriented collision and a dedicated block model, not an active mechanical-power network.

## Design reasoning
- Hand pickup should be limited to small recoverable objects, never inferred from block hardness or wearing armor.
- Deep mining remains intentionally unavailable. Multiple independent Basin byproducts reward experimentation without guaranteeing high-tier metals.
- No early-game tool allows fast bulk excavation; maintain the v54 stone timing and vest scope.

## Tuning snapshot
| Mechanic | Value |
|---|---|
| Speluncaphobia | Below Y=0, stacks every 60s, four levels maximum; added exhaustion 0.06 × (level) per second; natural regen 80% at level I, further reduced at higher levels |
| Claustrophobia | Below Y=-40, movement -7%, attack damage -1 |
| Light exemptions | Bright daytime open sky (no rain) or block light >=13 |
| Hammer mining | Stone ~12s, Coal 2, Raw Iron/Copper 1 |
| Deepslate | All current survival tools disallowed |
| Hand-recoverable decoration | 5 client/server mining ticks |
| Basin | 1 hunger point per input; material probabilities documented in `docs/BASIN_MATERIAL_YIELDS.md` |
| Hardwood Sticks / Axle | 2 Hardwood -> 2 Sticks; 8 Hardwood Sticks + 1 Rope -> 1 placeable Axle |

## Assets and licenses
- Dust sprites are color variants of Project Flint's existing human-authored Wood Dust texture; no AI art generated.
- Hardwood Sticks use a dark recoloring of Minecraft's original vanilla Stick texture; this is derivative Mojang artwork, documented in `docs/TEXTURE_PROVENANCE.md`.
- Axle model uses existing Project Flint Wood Beam side/end textures. Its mechanic is intentionally infrastructure-only for now.

## Advancement coverage
This branch no longer provides Project Flint-owned advancement progression; Flint Quests owns tracked quest registration. G Field Guide and K recipe listing were updated; no duplicate EMI/advancement integration added.

## Known limitations
- Full Fabric/Gradle compilation and world playtests were not available within this packaging runtime. Static source and resource checks do not establish live correctness.
- The Axle can be placed/oriented and recovered but does not yet transmit mechanical power.
- No special wearable/potion exemptions to underground effects yet.
- The Basin K guide lists principal outputs and explains bonus chances in the output hover tooltip; it does not show several simultaneous outputs as separate stacks.

## Validation
Resource JSON parsed, base/patch file relationships and recipe shapes audited. Targeted Java 21 compilation of the changed underground effect classes, OreMiningRules, and Basin material-probability class succeeded against available 1.21.11 mapped classes and small temporary test stubs. Complete Gradle build and Minecraft runtime tests are not claimed.
