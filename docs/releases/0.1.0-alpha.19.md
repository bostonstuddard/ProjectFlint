# Project Flint 0.1.0-alpha.19 — Flint Tools, Clay Working, and the First Kiln

## Intent

Alpha.19 extends the primitive progression beyond the Crude Stone Multitool into the first Flint-tier tools and the first reusable clay-processing infrastructure. It also retunes several existing gathering outputs so the Crude Multitool is a genuine consolidation/upgrade of the Crude Stone Hammer and Crude Stone Cutters rather than a side-grade.

The release keeps Project Flint's physical-assembly language: the new tools, bowl, clay charges, clay blocks, and kiln are constructed or processed in-world instead of through a vanilla crafting grid.

## Player-facing behavior

### Flint Firestarter

Sneak-right-click supported ground with a **Branch** or vanilla **Flint** to begin the shared Flint-tool assembly. Exactly **8 Branches + 2 Flint** completes into one **Flint Firestarter**.

The Flint Firestarter has **32 durability/uses**. One use can ignite:

- a completed permanent primitive campfire;
- an Unfired Clay Ball surrounded by four Twigs;
- a fully fueled Crude Clay Kiln;
- the baked kiln while firing its shaped upper block;
- the completed two-block baked kiln.

The older Flower Petal + offhand Twig campfire ignition route remains available; the Firestarter is the reliable progression upgrade rather than a retroactive removal of the earlier fire method.

### Flint Multitool

A second recipe in the same physical assembly uses **2 vanilla Flint + 2 Burnt Branches** to produce the **Flint Multitool**.

Its current combat/tool tuning is:

- **3 total attack damage**;
- **same attack speed as Crude Stone Cutters** (1.2 attacks/second after the standard player base is applied);
- **256 durability** for this first playtest pass;
- roughly **2× the baseline crude-tool work speed** on most inherited primitive operations.

The user did not specify Flint Multitool durability. **256 is provisional tuning**, deliberately set to twice the newly increased 128-durability Crude Multitool so the tier can be playtested without introducing an arbitrary low-use bottleneck.

### Crude Stone Multitool rebalance

The Crude Stone Multitool now has:

- **128 durability**;
- **2 total attack damage**;
- **the same attack speed as Crude Stone Cutters**;
- approximately **1.25×** the base crude Hammer/Cutters work speed on inherited operations;
- all supported Crude Stone Hammer and Crude Stone Cutters capability routes, in addition to its existing leaves/earth/gravel jobs.

This includes Stone crushing, flower/grass/leaf-litter cutting, Sugar Cane harvesting, berry harvesting, hammer-driven physical assemblies, Dirt Pile compaction, Fired Clay compaction, Burnt Twig splitting, and Flint Chip knapping. The Hammer's intentionally retained pre-Cutters Sugar Cane bootstrap remains Hammer-specific; Multitools instead harvest Sugar Cane normally and use the superior hand-working outputs below.

### Gathering/output changes

- Ordinary flower + Cutters: **2 Flower Petals**.
- Ordinary flower + Crude Multitool: **3 Flower Petals**.
- Ordinary flower + Flint Multitool: **4 Flower Petals**.
- Any supported tall flower: **2× the relevant tool's petal output**, so 4 / 6 / 8 respectively.
- Tall flowers continue to suppress the vanilla duplicate flower drop.
- 1 Sugar Cane hand-worked with Cutters: **3 Crude Reeds**.
- 1 Sugar Cane hand-worked with Crude Multitool: **4 Crude Reeds**.
- 1 Sugar Cane hand-worked with Flint Multitool: **6 Crude Reeds**.
- Short Grass + Flint Multitool: **2 Crude Plant String**, twice the crude-tier output.
- Leaf Litter + Flint Multitool: **4 Plant Fiber**, twice the crude-tier output.
- Leaves + either Multitool: **4 Twigs + 1 Branch**; Flint improves speed rather than multiplying this already-guaranteed output.
- Dirt/Grass + Crude Multitool: **1 Dirt Pile**.
- Dirt/Grass + Flint Multitool: **2 Dirt Piles** with faster excavation.
- Gravel + Crude Multitool: **1 Flint Chip**.
- Gravel + Flint Multitool: **2 Flint Chips** with faster excavation.
- Dirt Pile compaction is changed from **9:1 to 4:1** for Loose Dirt.

The user's phrase “2 gravel piles instead of 1” is implemented as **2 Flint Chips instead of 1**, because alpha.18's established Gravel operation yields Flint Chips and no Gravel Pile material exists. This preserves the existing Gravel → Flint Chip → vanilla Flint progression instead of silently introducing a second, currently unused gravel resource.

### Woven bowl and clay collection

Sneak-right-click supported ground with a Dirt Pile and build the physical assembly to:

- **32 Dirt Piles**;
- **12 Burnt Twigs**.

Completing it produces a **Crudely Woven Bowl**.

Right-click a vanilla **Clay block** with that bowl to consume the Clay block and produce an **Unfired Woven Bowl**. Use the Unfired Woven Bowl on a **lit permanent campfire** to fire it into a reusable **Fired Clay Bowl**.

The Fired Clay Bowl then collects raw clay in four scoop stages:

- each consumed vanilla Clay block adds **2 fill**;
- at **8 fill**, the bowl resets to empty and produces **1 Unfired Clay Ball**.

### Open-firing clay

Place an Unfired Clay Ball on supported ground, add exactly **4 Twigs**, then ignite it with the Flint Firestarter. The small firing burns for **30 seconds**, then consumes the firing arrangement and produces **2 Fired Clay**.

The user did not specify this small firing duration. **30 seconds is provisional**, matching the other new one-stage bake operations so the timing is easy to compare in playtesting.

Fired Clay can be placed into a physical pile up to **4 pieces**. Strike a full four-piece pile with any hammer-like tool to compact it into **1 custom Crude Clay Block**.

### Crude and baked clay kiln

Right-click the custom Crude Clay Block with a cutter-like tool to shape it into a **Crude Clay Kiln**. Crude Clay Blocks and unlit Crude Clay Kilns are deliberately still movable: they can be broken by hand and recovered before the permanent firing step.

Load the Crude Clay Kiln with **8 Branches**, then ignite it with the Flint Firestarter. After **30 seconds** it becomes a **Baked Clay Kiln**. The baked base cannot currently be moved or broken by bare hands or any available Project Flint tool.

The user specified the completed kiln's 8-Branch fuel load but did not give an exact Branch count for the first base bake. **8 Branches is used provisionally for the base bake as well**, keeping one consistent kiln fuel capacity until playtesting establishes a reason to separate them.

To complete the kiln:

1. place **Loose Dirt** directly above the Baked Clay Kiln;
2. cut that Loose Dirt with Cutters or either Multitool, forming the shaped kiln top;
3. load the baked base with **8 Branches**;
4. ignite it with the Flint Firestarter;
5. after **30 seconds**, the upper form becomes the permanent baked upper kiln block.

The resulting **two-block kiln** can then be fueled with **8 Branches** and one Firestarter use. A completed firing remains lit for **5 minutes**.

Alpha.19 establishes the kiln structure, fuel state, ignition, and burn lifetime. It does not yet add later kiln recipes beyond the construction/firing progression itself.

## Architecture

### Capability inheritance

`ModItems` now exposes shared `isHammerLike`, `isCutterLike`, `isMultitool`, and Flint-tier checks. Existing hammer/cutter completion paths use these shared capability predicates rather than enumerating only the original tools. This is the first step toward making tool tiers inherit operations consistently.

`BlockStateBaseMixin` applies tier-sensitive work-rate multipliers while `ServerPlayerGameModeMixin` remains the authoritative completion/output boundary for custom block harvesting. This keeps speed and output tuning separate.

### Shared Flint physical assembly

`FlintToolAssemblyBlock` represents Branch, Burnt Branch, and Flint counts in-world and supports both Flint-tier tool recipes. Incomplete components can be recovered one at a time rather than being deleted when a player changes plans.

### Clay state chain

Clay working is represented by distinct stateful world objects instead of a crafting recipe:

`WovenBowlAssemblyBlock` → bowl item stages → `ClayFiringPileBlock` → `FiredClayPileBlock` → Crude Clay Block → `CrudeClayKilnBlock` → `BakedClayKilnBlock` + shaped/baked top.

The kiln base owns fuel/lit state and scheduled bake/burn transitions. The shaped top is a separate block because the finished kiln is intentionally a real two-block structure.

### Firestarter durability

The Firestarter uses native item durability rather than a custom counter. Every successful ignition costs exactly one durability, giving a visible standard Minecraft durability bar and 32 total successful uses.

## Design reasoning

The Crude Multitool is intended to consolidate the first crude tool tier, so its capability checks now deliberately include existing Hammer/Cutters operations. The Flint Multitool then upgrades the same operation family through speed and selected yields rather than introducing an unrelated set of special cases.

Clay progression is intentionally expensive and physical. The Fired Clay Bowl converts large vanilla Clay deposits into a smaller, staged resource chain, while the kiln becomes immovable only after firing. This creates a meaningful “choose the permanent workshop location” moment without punishing placement mistakes before baking.

The completed kiln currently burns without processing a recipe because the user's requested batch ends at establishing the five-minute kiln. Keeping the heat infrastructure separate from later kiln contents avoids inventing unrequested outputs.

## Known limitations

- Flint Multitool durability **256** is provisional because no durability value was supplied in this batch.
- The small Unfired Clay Ball firing time **30 seconds** is provisional because no duration was supplied.
- The Crude Clay Kiln's first bake currently takes **8 Branches**, matching the later kiln fuel load; the initial-bake fuel count was not explicitly specified.
- “2 gravel piles” is interpreted as **2 Flint Chips**, preserving the established alpha.18 Gravel operation and avoiding an unrequested dead-end Gravel Pile item.
- The complete kiln currently provides a persistent five-minute heat state but does not yet process additional kiln recipes.
- Tool operations are still code-defined. Shared Hammer/Cutter/Multitool predicates reduce duplication, but a fully data-driven operation registry remains future architectural pressure.
- Development art for the Flint Multitool and clay infrastructure is not final.

## Validation

- All Project Flint JSON resources are parsed after the new item/model/blockstate/advancement additions.
- The alpha.19 source changes are Java 21 compile/type-checked against the cached Minecraft 1.21.11 and remapped Fabric API classes. The artifact environment lacks the Fabric Loader/Mixin dependency jars, so compile-only annotation/interface stubs are used for those unavailable dependencies; the modified source itself reports no Java errors.
- Physical assembly state ranges and completion recipes are checked for the exact requested counts.
- Incomplete Flint-tool, Woven Bowl, clay-firing, Fired Clay, and kiln fuel states retain explicit recovery paths where the object is intended to remain movable.
- Advancement award IDs are checked against advancement resource criteria.
- The patch is diffed against alpha.18 and packaged with modified/new files only.
- The normal Gradle/Loom build remains unavailable in this environment because Fabric Loom 1.14.10 is not present in the local plugin cache; `build.bat` and a real client playtest remain release gates.

## Next release pressure

The next playtest should concentrate on the entire material chain without skipping stages: build both Flint tools, verify every inherited Crude Multitool operation, collect/fill/fire the bowl, open-fire multiple Clay Balls, move a Crude Kiln before baking, permanently bake it, shape/bake the Loose Dirt top, and verify that the complete kiln remains lit for the full five minutes. The biggest architectural pressure after that is defining actual kiln processing recipes without turning the new kiln into another growing chain of hard-coded item checks.
