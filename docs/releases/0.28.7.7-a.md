# Project Flint v0.28.7.7-a — True-Night Restoration + Pumpkin/Berry Rules

## Intent
Restore the intended pitch-black midnight world without bringing back the short-distance fog wall, add a primitive Flint Axe use for Pumpkins, and close the vanilla Sweet Berry planting bypass so Project Flint's custom Sweet Berry Seeds are the only propagation item.

## Player-facing behavior
- At full midnight, unlit Overworld terrain can once again fall to true black.
- Campfires, torches, lit kilns, and illuminated structures remain visible at range because no Project Flint night fog is reintroduced.
- Pumpkins can now be harvested with the Flint Axe.
- Flint Axe pumpkin harvesting yields four Pumpkin Seeds instead of the Pumpkin block.
- Vanilla Sweet Berries can no longer plant Sweet Berry Bushes.
- Project Flint Sweet Berry Seeds remain able to establish new Sweet Berry Bushes.
- Sweet Berries remain edible and the existing cutter-based berry harvest behavior is unchanged.

## Architecture
- `assets/minecraft/shaders/core/lightmap.fsh` remains the sole Project Flint night-darkness renderer and no longer clamps `hardened_sky_factor` to a positive 0.06 floor.
- `PrimitiveInteractionSystem` now admits Flint Axe attacks against Pumpkins and rejects only the vanilla Sweet Berry BlockItem placement case.
- `BlockStateBaseMixin` supplies the Flint Axe Pumpkin destroy-progress rule.
- `ServerPlayerGameModeMixin` owns the completed Pumpkin transformation into Pumpkin Seeds.
- The custom `SweetBerrySeedsItem` remains the only Project Flint-supported bush-establishment path.

## Design reasoning
The 0.06 moonlight floor introduced while trying to soften midnight visibility was the part that made the landscape readable again after the fog wall was removed. It is unnecessary for navigation: actual block lights already remain visible through the normal renderer. Project Flint therefore returns full-night sky contribution to zero while preserving block light independently.

Pumpkin harvesting is kept inside the same primitive permission/progress/completion pipeline used by other gated resources so the Flint Axe cannot be visually allowed but server-blocked, or vice versa. Sweet Berry planting is intercepted only when vanilla berries would actually place a bush, avoiding a blanket right-click ban that would interfere with eating them.

## Tuning snapshot
- Full-night minimum Project Flint sky-light floor: **0.00**.
- Project Flint night fog distance cutoff: **none**.
- Flint Axe Pumpkin break duration: approximately **65 ticks / 3.25 seconds** under uninterrupted full mining conditions.
- Pumpkin Seed output: **4** per Pumpkin.
- Flint Axe durability cost: **1** per harvested Pumpkin.
- Sweet Berry planting item: **Project Flint Sweet Berry Seeds only**.

## Assets and licenses
No texture, model, sound, or other asset pixels were added or edited in this release.

## Advancement coverage
No new advancement is added. Pumpkin harvesting is a small extension of the established Flint Axe capability rather than a new progression milestone.

## Known limitations
- Perceived black level still depends on display calibration, third-party shader packs, and rendering mods that replace or modify Minecraft's lightmap shader.
- Pumpkin harvesting currently covers the ordinary `minecraft:pumpkin` block only; Carved Pumpkins are intentionally unchanged.
- Sweet Berries are blocked from planting only when their vanilla BlockItem placement would produce a viable Sweet Berry Bush; they otherwise remain usable as food.

## Validation
- The release validator rejects any return of the `max(hardened_sky_factor, 0.06)` floor.
- No night fog mixin/environment is active.
- Pumpkin harvesting is checked across attack permission, destroy progress, pre-break permission, and completion/drop handling.
- Vanilla Sweet Berry bush placement interception and the custom seed path are both checked.

## Next release pressure
Field-test midnight beside a distant campfire or lit kiln: unlit landscape should be black while the light source itself remains visible. Also verify Pumpkin Seed output/durability and confirm Sweet Berries cannot establish bushes on any vanilla-valid support.
