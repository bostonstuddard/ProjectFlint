# Project Flint v0.31.4-b

## Intent

Repair the Bookshelf's actual crafting lifecycle after the v0.31.3-b UI cleanup, establish the first four-book-gated Bookshelf recipe, and push the new Wooden Sheet/Screw components deeper into Wood-age workstation and storage progression.

## Player-facing behavior

- The Bookshelf's six-slot recipe-prompt strip is visible again at the bottom of the workstation panel. Empty/invalid inputs leave that strip blank instead of showing a stale Book icon.
- Bookshelf inputs now refresh recipes immediately. **8 Sugarcane Rolls + 2 Leather -> 1 Book** works with an empty shelf and remains the bootstrap recipe used to fill the shelf.
- A Bookshelf containing all **4 Books** unlocks **1 Book + 2 Black Dye -> 1 Book and Quill**. The registry now has an explicit required-book tier so future advanced Bookshelf recipes can require all four books.
- Wooden Grinder: **4 Wooden Sheets + 2 Wooden Screws -> 1 Wooden Chest Frame**.
- Right-clicking a Woven Chest with a Wooden Chest Frame upgrades it to a Wooden Chest while preserving its stored contents. The old 16-Wooden-Board catalyst is removed.
- Bone Hoe: **2 vanilla Sticks + 3 Filed Bones** instead of 4 Wooden Beams + 3 Filed Bones.
- Project Flint Brush: **2 Wooden Screws + a completely undamaged Bone Brush** instead of the previous large wood component.
- Bookshelf: **8 Wooden Sheets + 2 Wooden Screws**.
- Wooden Grinder Base: **12 Woven Wood** instead of 16.
- Sanding Station now processes the complete existing Project Flint flower-dye set at **2x the corresponding vanilla dye yield**, including four dye from vanilla two-dye flowers.
- Sanding Station: **1 Ink Sac -> 2 Black Dye**.
- Sanding Station: **1 Branch -> 4 Twigs**.

## Architecture

The Bookshelf no longer uses its block entity itself as the live two-slot crafting input. Its menu now owns a responsive `SimpleContainer` whose `setChanged()` callback immediately refreshes the recipe/result state, matching the working pattern already used by the Wooden Grinder. The block entity remains responsible for the persistent four-book progression counter.

`BookshelfRecipeRegistry.Definition` now carries `requiredBooks`. The bootstrap Book recipe uses tier 0; Book and Quill uses tier 4. Recipe matching rejects recipes whose book tier has not been reached before checking either input orientation.

The Wooden Chest Frame is a normal Project Flint item and reuses the Wooden Chest's special chest presentation/entity texture instead of introducing duplicate pixel art. `WovenChestBlock` now consumes that item as its one-step upgrade catalyst.

## Design reasoning

The Bookshelf must be capable of crafting its own Books before it can require Books for advanced knowledge recipes, so Book remains ungated. Once four books are installed, the station has a clear upgrade state that can gate Book and Quill and later research-oriented recipes without adding separate workstation blocks.

Sheets and screws now matter beyond the door hinge. Moving the Bookshelf and Wooden Chest upgrade onto those components gives the Flint File progression a practical reason to exist and removes the abrupt 16-board chest tax.

Sanding Station dye recipes consolidate the earlier hand-sanding dye language into the dedicated workstation. Doubling the normal flower result rewards reaching the station without invalidating the earlier manual process.

## Tuning snapshot

- Bookshelf bootstrap: **8 Sugarcane Rolls + 2 Leather -> 1 Book**, required books: **0**.
- Full Bookshelf: **1 Book + 2 Black Dye -> 1 Book and Quill**, required books: **4**.
- Wooden Chest Frame: **4 Wooden Sheets + 2 Wooden Screws**.
- Bone Hoe: **2 Sticks + 3 Filed Bones**.
- Fine Brush: **2 Wooden Screws + full-durability Bone Brush**.
- Bookshelf: **8 Wooden Sheets + 2 Wooden Screws**.
- Wooden Grinder Base: **12 Woven Wood**.
- Sanding Station Branch yield: **4 Twigs**.
- Sanding Station Ink Sac yield: **2 Black Dye**.
- Sanding Station flower dye output: **2x the existing corresponding flower result**.

## Assets and licenses

No new external or generated texture artwork is introduced in this release. Wooden Chest Frame deliberately reuses Project Flint's existing owner-supplied Wooden Chest rendering assets. The v0.31.3-b Flint File, Sheet, Hinge, and reusable screw assets remain unchanged.

## Advancement coverage

The unified ProjectFlint progression page gains a Wooden Chest Frame step and a Book and Quill step. Existing descriptions are updated for the 12-Woven-Wood Grinder Base, 2-Stick Bone Hoe, 2-Screw Brush, Sheet/Screw Bookshelf, and Wooden Chest Frame upgrade path.

The Book advancement explicitly explains that the bootstrap recipe works before the shelf is full. The Filled Bookshelf advancement now identifies the four-book state as the requirement for Book and Quill and future advanced Bookshelf recipes.

## Known limitations

The Bookshelf recipe-prompt row currently uses its first prompt slot to mirror only the recipe that matches the inputs; it is not a browsable recipe selector like the Wooden Grinder. The dedicated recipe-guide button remains the complete recipe reference.

Manual flower/Ink Sac sanding from the earlier interaction system remains available; this release adds the improved workstation versions rather than deleting the earlier progression method.

## Validation

Release validation checks v0.31.4-b version/build/cleanup wiring, JSON syntax, responsive Bookshelf input callbacks, persistent blank recipe-prompt wells, tier-0 Book crafting, tier-4 Book and Quill crafting, Wooden Chest Frame registration/resources/upgrade use, all Wooden Grinder cost changes, the 12-Woven-Wood Grinder Base datapack and guide mirror, all Sanding Station dye mappings and doubled outputs, Branch -> 4 Twigs, advancement count/coverage, and preservation of prior v0.31.1-b through v0.31.3-b regression guards.

A Java 21 syntax parse passes for every modified Java source file. A full Gradle compile was attempted, but Gradle stops before Java compilation because Fabric Loom `1.14.10` is not present in the available offline plugin cache.

## Next release pressure

Playtest the Bookshelf from an entirely empty state through crafting four Books, installing them, and crafting Book and Quill. Verify Woven Chest inventory preservation through the new Wooden Chest Frame upgrade and compare Sanding Station dye throughput against the manual sanding path before adding more four-book research recipes.
