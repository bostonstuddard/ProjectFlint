# Project Flint v0.31.59-b — Basin, Field Guide, Mod Menu and Glass

## Intent

Repair hidden Basin contents, guide usability, blocked premium glass recovery, and missing project links/config entrypoint.

## Player-facing behavior

- Place up to four processable individual items into a Basin. All four appear inside. First in is first crushed; empty-hand retrieval removes the most recent unprocessed item. Every valid landing costs one hunger point; two or three landings per material. Intermediate crushing and completion have differing sounds and particles.
- Hovering the Basin exposes its four stored slots to inventory overlays through the vanilla `Container` interface. The rendered Jade HUD still requires runtime verification.
- Wearing a Tanned Utility Vest permits hand recovery of placed Pure Mica Insulated Glass intact, no Silk Touch. Stone, ore, and structure mining stay restricted.
- The 34-chapter G-key Field Guide follows progression, uses concise player-only explanations and automatically fills page space. The K-key Recipe Guide reflects Basin capacity and per-stomp cost.
- Mod Menu displays `imkas` ahead of `ProjectFlint Contributors`, and links to official GitHub issues. A placeholder config page provides Field Guide / Recipe Guide buttons. Modrinth project page used as website because its `Join Discord server` destination could not be independently verified here.

## Architecture

Separate one-item `Container` slots with saved NBT and a legacy oversized-stack migration buffer. Render state for each stored item. Dynamic measured-line pagination. Client-only optional Mod Menu integration via Terraformers repository and compile-only dependency.

## Design reasoning

A small physical queue shows the real material in the world without granting automated bulk capacity. Generic `Container` reduces integration dependencies. The vest's ability is kept narrowly targeted to glass. The player's handbook must not contain development or release commentary.

## Tuning snapshot

Capacity 4 slots × 1 item; 2–3 stomps; 1 hunger point per successful stomp. No Basin drop odds, crafting, mining, or lighting balance changes.

## Assets / licensing

No new external assets or AI-generated textures. The renderer reuses existing item models.

## Progression coverage

The Field Guide and K-key reference were updated; Project Flint's older advancement tree is retired. No new gameplay progression tier was added.
