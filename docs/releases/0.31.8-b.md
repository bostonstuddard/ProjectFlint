# Project Flint v0.31.8-b — Recipe Parchment Compile Hotfix

## Intent
Restore a clean Minecraft 1.21.11 Java build after the v0.31.7-b Recipe Parchment tooltip/name work introduced a Java generic-return mismatch.

## Player-facing behavior
No intended gameplay behavior changes. Bound Recipe Parchment still names itself after its stored recipe, blank parchment still uses the normal item name, and the data-driven ingredient lore remains unchanged.

## Architecture
`RecipeParchmentItem#getName` now resolves the optional bound recipe first and branches explicitly. This avoids forcing both return paths through an `Optional<MutableComponent>` inferred from `Component.literal(...).append(...)`.

## Design reasoning
Minecraft 1.21.11's `Component.literal(...)` expression is a `MutableComponent`, while `Item#getName(ItemStack)` returns the broader `Component`. `Optional.map` inferred the narrower type, making the `super.getName(stack)` fallback illegal. Explicit control flow keeps the public method typed as `Component` without casts or unnecessary component copying.

## Tuning snapshot
No balance, progression, recipe, food, durability, world-generation, or processing-speed values changed in this hotfix.

## Assets and licenses
No assets were added, removed, generated, recolored, or otherwise modified.

## Advancement coverage
No advancement definitions changed. The v0.31.7-b Flax, research, masonry, milk, and Primitive Oven advancement coverage is preserved.

## Known limitations
Full Gradle compilation cannot be completed in this execution environment because the Fabric Loom `1.14.10` plugin artifact is not available to its offline Gradle plugin resolver. The reported Java type error itself is removed at source level and guarded by release validation.

## Validation
The v0.31.8-b release validator checks version/build wiring, prior v0.31.7-b regression coverage, and the corrected Recipe Parchment name implementation. Resource validation remains inherited from the previous release.

## Next release pressure
Continue gameplay testing of the v0.31.7-b Flax, Recipe Parchment, cabinet, Primitive Oven, and prepared-food progression after the compile blocker is cleared.
