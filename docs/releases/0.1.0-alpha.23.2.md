# Project Flint 0.1.0-alpha.23.2

## Mortar Chest
- Keeps the requested seven real storage slots.
- Uses Minecraft's own generic-container GUI texture rather than a Project Flint-painted background. The seven slots are presented as one centered chest row.
- The placed model now references `projectflint:block/mortar_bricks` for all geometry instead of a separate Mortar Chest block texture.
- A full-width bottom plate closes the model and `noOcclusion()` prevents the inset chest geometry from culling the top face of the supporting block.

## Advanced Kiln
- Formation still begins from a complete 2×2×2 Mortar Bricks cube and one Advanced Kiln Glass used on the intended horizontal front face.
- Formation now writes one controller plus seven position-aware casing states. The four front positions use four coordinated kiln tiles; side, back, top, and bottom surfaces remain Mortar Bricks.
- The controller now owns a five-slot GUI: Burnt Branches / fired mold / vanilla Flint / Fired Clay / output. Required input counts remain 8 / 1 / 8 / 4.
- Processing remains 200 ticks (10 seconds). The fired mold remains in its slot; the other three material inputs are consumed.
- Breaking any controller/casing position with the existing `WORKSTATION_DISMANTLE` capability resolves the controller, drops the inventory, removes all eight kiln blocks, returns 8 Mortar Bricks + 1 Advanced Kiln Glass, and consumes one tool durability. Creative dismantling returns no structure materials.

## Reed Backpack
- The normal inventory item model is unchanged.
- While equipped in the chest slot, a dedicated `reed_backpack_worn` item-model definition is rendered against the avatar torso as a three-dimensional pack.
- The directly supplied 16×16 backpack PNG is copied byte-for-byte as the worn front/back texture; the existing human-made Reed Backpack wicker texture provides the side material.

## Human-made asset audit
The active alpha.23 art touched here was checked against the approved Project Flint asset master. This patch uses exact source PNG bytes rather than generated, recolored, resized, composited, or otherwise pixel-edited replacements.

- Advanced Kiln four-tile face: `06_Industrial_Steampunk/blocks/device_kiln*.png` family.
