# Project Flint 0.31.25-b — Brick Heat Workstations

## Intent
Replace the Advanced Kiln's old brick-heavy visual language with a mortar-built smoker design and stage the next two GUI heat-processing blocks without prematurely assigning construction recipes or metallurgy content.

## Player-facing behavior
- Advanced Kiln uses the supplied Brick Smoker design with its red brick masonry replaced by Project Flint Mortar Brick masonry.
- Brick Furnace is available in Creative for testing, but has no crafting/acquisition recipe yet.
- Brick Furnace accepts a stack of any existing `KILN` processing input, repeatedly processes one unit at a time, and distributes results across four output slots until the source stack is exhausted or outputs fill.
- Brick Furnace uses stripped logs/wood as fuel, requires four units to ignite, burns for 30 minutes per ignition and runs at 1.50x baseline speed. The Mortar Kiln remains 1.25x.
- Brick Blast Furnace is also Creative-only/no-recipe for now. It has its own supplied block art and GUI-backed inventory, while intentionally sharing the Brick Furnace processing backend until blast-specific metallurgy is designed.

## Architecture
`BrickFurnaceBlockEntity` is shared by the Brick Furnace and Brick Blast Furnace. It owns one fuel slot, one input slot, four output slots, persistent burn/progress state and repeated stack processing through `PrimitiveProcessingRegistry` with `PrimitiveProcessor.KILN`. Each block has its own facing/lit state and model set, while the menu carries a furnace/blast flag so both client menu types can use the same screen implementation.

The Advanced Kiln remains the existing multiblock. Only its texture masters are changed; its 2x2 face models continue sampling quadrants from those 16x16 masters, preserving the multiblock layout. Mortar Kiln models were decoupled onto preserved legacy texture copies so this visual replacement does not silently reskin the earlier station.

## Design reasoning
A one-stack input plus four-output buffer gives the Brick Furnace the furnace-like usability requested without turning it into the researched multi-ingredient Primitive Oven. Reusing the Kiln recipe registry keeps heat-processing rules in one source of truth and means future Kiln-compatible materials automatically work in this interface. The Blast Furnace is intentionally not given invented blast-only recipes or a speculative speed tier yet.

## Tuning snapshot
- Mortar Kiln: 1.25x baseline.
- Brick Furnace: 1.50x baseline.
- Brick Blast Furnace: currently 1.50x placeholder/shared backend.
- Fuel per ignition: 4 stripped log/wood items.
- Burn session: 36,000 ticks / 30 minutes.
- Brick Furnace inventory: 1 fuel + 1 input + 4 output slots.

## Assets and licenses
Owner-provided `7f801a0d-56c5-4825-a20c-48b5e1720a61.zip` supplies the Brick Furnace, Brick Blast Furnace and Brick Smoker art. Brick Furnace/Blast Furnace textures are imported unchanged. The Advanced Kiln textures are a deterministic derivative of the supplied Brick Smoker art using Project Flint's existing owner-controlled Mortar Bricks texture for the masonry regions. No generated AI art is used.

## Advancement coverage
None. Advancements remain retired in favor of Flint Quests. Brick Furnace and Brick Blast Furnace output extraction both report through the existing workstation quest bridge.

## Known limitations
- Brick Furnace and Brick Blast Furnace have no Survival acquisition/crafting recipes yet, by request.
- Brick Blast Furnace has no dedicated metallurgy recipe pool or separate speed tuning yet; it shares the Brick Furnace backend as a testable placeholder.
- The Brick Furnace does not execute multi-ingredient parchment recipes from the Primitive Oven; it processes the ordinary Kiln table.

## Validation
The release validator checks registration, GUI/block-entity wiring, 1.50x Brick Furnace tuning, four-output batch layout, KILN-registry processing, absence of Brick Furnace/Blast Furnace crafting recipes, supplied texture presence and Advanced Kiln mortar-smoker texture resources. All JSON resources are syntax-validated.

## Next release pressure
Define the Brick Blast Furnace's metallurgy-only processing rules and speed tier, then decide Survival construction recipes for both brick heat workstations.
