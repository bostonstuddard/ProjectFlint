# Project Flint v0.28.25-a

## Intent
Polish the workstation recipe reference so it only advertises valid station behavior and make two visibly awkward interfaces feel intentional.

## Player-facing behavior
- Advanced Kiln no longer lists or processes Wattled Daub Bricks.
- Clay Grinder, Wooden Grinder, and Advanced Kiln recipe buttons now use a real Book icon and sit inset in the top-right title bar.
- Woven Chest is slightly wider and its storage/player slots are re-centered for clean margins.

## Architecture
Recipe guide station definitions remain separate from vanilla Survival recipe-book UI. The Advanced Kiln guide stays aligned with the Advanced Kiln's actual process set, while Woven Chest slot coordinates are changed in both the menu and its code-rendered screen.

## Design reasoning
A reference UI is only useful if it is trustworthy. Recipes that do not belong to a station should never appear there, and utility buttons should visually read as part of the workstation rather than an appended debug control.

## Tuning snapshot
No balance values changed in this release. Woven Chest remains 9 storage slots.

## Assets and licenses
No new texture assets were added. The recipe button renders Minecraft's existing Book item sprite.

## Advancement coverage
No advancement changes. The Tool Era, Clay Era, and Wood Era tabs from v0.28.22-a remain intact.

## Known limitations
The guide remains a Project Flint-owned reference screen rather than a vanilla Recipe Book integration by design.

## Validation
Release validator checks versioning, recipe-guide controls, Advanced Kiln recipe removal, Woven Chest sizing/alignment, resource JSON syntax, and existing Project Flint invariants.

## Next release pressure
Continue migrating any hard-coded guide-only data toward shared workstation recipe definitions where the Minecraft recipe APIs make that practical.
