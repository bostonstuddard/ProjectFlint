# Project Flint v0.31.68-b — Weak Dynamite and Geology Balancing

**Baseline:** v0.31.67-b · **Target:** Fabric Minecraft 1.21.11 · **Output:** patch-only ZIP at source root.

## Player-facing changes
- Reduced Weak Dynamite's reach: it can affect up to **2** regular Iron, Copper or Coal Ores within 1.75 blocks of the charge.
- Stone, Cobblestone, Andesite, Diorite and Granite can break only within 1.25 blocks; each nearby block has a 50% break chance, with a cap of **1 stone block** destroyed per blast.
- Blast materials now use **20% better odds than Basin processing** (50% → 60%). Guaranteed-plus-bonus outcomes above 100% and independent material rolls remain.
- Dynamite now requires **3 Copper Dust across the bottom row**, with Black Powder in the top corners and middle sides, a Fuse top center and Red Dye center.
- Dripstone, Pointed Dripstone, Tuff, Calcite, Basalt, Blackstone and Amethyst cannot be harvested with existing wooden-tier tools. Crude Stone Hammer stone crushing and existing early stone permissions are unchanged.

## Developer verification
- Isolated Java 21 compilation of `DynamiteChargeBlockEntity`, `OreMiningRules`, and `BasinMaterialProcessingSystem` against the archived Minecraft 1.21.11 mapped JAR and Fabric API remapped libraries succeeded with minimal registry stubs.
- Recipe JSON and source rule checks run via `tools/validate_03168.py`; patch ZIP structure/hash audit pending packaging.
- Full Gradle build, Minecraft launch, and gameplay test not performed here. Verify blast damage and caps, drops, mining restrictions, and backward compatibility before deploying.
