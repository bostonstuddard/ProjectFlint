# Project Flint v0.32.2 — Actual Recipe-Duplication Fixes

**Base:** v0.32.1 · **Target:** Minecraft 1.21.11 Fabric · **Patch-only source ZIP**.

## Player-facing fixes

- **No more wood from slabs (#14):** Wood Slabs cannot be ground back into Stripped Logs. This is enforced in the actual recipe registry and in both Grinder menus, not only hidden in the recipe guide. Forward processing from Logs and the Hardwood Table's improved slab output still work.
- **Loose Dirt and Loose Mud Brick duplication fixed:** The reverse recipes turning two of these slabs into one full block have been removed, because the Hardwood Table makes six slabs from two blocks. The six-slab crafting recipes remain unchanged.
- **Sanded/Grinded Wood duplication fixed:** Removed the old Grinded Wood Slab -> two Sanded Wood Slabs reverse recipe. The approved Wooden Grinder recipe (three Sanded Slabs plus Flint File -> two Grinded Slabs) remains. Normal Clay Grinder 2 Sanded -> 1 Grinded remains.
- **No other block/slab recipe nerfs:** Balanced conversions such as two Fireclay Brick Slabs -> one Fireclay Brick Block remain available.

## Why this patch is different

A guide entry does not decide whether a recipe can be used. In v0.32.1, old `*_stripped_log_from_slabs.json` recipe files were supposed to be deleted by an apply script, but could remain in a source folder after ZIP extraction or appear in stale processed output. This patch uses all three mechanisms:

1. `APPLY_PROJECTFLINT_0_32_2.bat` deletes **15** retired recipe JSON IDs from both `src/main/resources` and old `build/resources/main`, and fails if any survives in source.
2. `RetiredRecipePolicy` rejects the obsolete IDs when `RecipeManagerMixin` builds the actual server recipe map, even if a stale JSON or datapack still supplies one.
3. Both `ClayGrinderMenu` and `WoodenGrinderMenu` skip those IDs when listing executable recipes, as an independent guard.

This policy also preserves prior removals of the Stripped Log -> Wooden Sheet personal shortcut and personal PMI Sheet recipe when obsolete resources are still present.

## Workstation regression testing

1. With two Oak Slabs, verify neither Clay nor Wooden Grinder offers `projectflint:oak_stripped_log_from_slabs`.
2. Verify 2 Oak Planks -> 6 Oak Slabs in the Hardwood Table still works, without an executable slab-to-log return route.
3. Verify two Loose Dirt Slabs and two Loose Mud Brick Slabs cannot be ground back into a full block. Verify each Hardwood Table 2-block -> 6-slab recipe still exists.
4. Verify 3 Sanded Wood Slabs plus an intact Flint File -> 2 Grinded Wood Slabs. Verify no Grinded -> Sanded grinder recipe appears.
5. Confirm balanced two-slab-to-block recipes (Fireclay, Mortar, Crude Clay) continue to work; verify normal hardwood tools, primitive Stone processing, and FlintQuests callbacks remain untouched.
6. Test both a fresh and existing world. The updated JAR, not the old 0.32.1 JAR, must be loaded.

**Verification status:** Source/resource checks and direct Java test of the exclusion policy are separate from a full Gradle build and in-game testing. Do not describe in-game behavior as proven until playtested.
