# Project Flint 0.1.0-alpha.4 — World Legibility

## Intent
Make the primitive opening visually coherent and geographically dependable before adding the next technology step.

## Player-facing behavior
- Corrects the locked hotbar overlay alignment.
- Replaces the alpha.3 crafting-area paint-over with a texture-pack-aware mask sampled from the active inventory GUI texture.
- Grass stripping is three times slower than alpha.3.
- Short grass/leaf litter hand-clearing no longer applies a real Mining Fatigue status effect; the slow hand motion is client-side visual feedback only.
- Hard difficulty is forced and locked. Non-creative play is treated as Hardcore. Adventure mode is unavailable; living players cannot enter Spectator.
- Initial Overworld spawn is relocated to Plains, Forest, or Flower Forest when necessary.
- Hot/arid forage bushes are removed from active ecology. Existing registry IDs remain inert for test-world compatibility.
- Forage bushes now require actual dirt-tagged ground below them and use MOTION_BLOCKING_NO_LEAVES placement, preventing tree-canopy spawns.
- Loose Rocks generate at three attempts per chunk; active bushes generate at two attempts per chunk.
- Stone-working success is raised from 62% to 68%.
- The advancement root is now titled ProjectFlint while Stone in Hand remains a real child advancement.
- Bush and loose-rock placeholders now reuse the player's active Minecraft leaf/stone textures with Project Flint geometry, making them cleaner and resource-pack-aware.

## Architecture introduced
- PrimitiveWorldSetupSystem owns global difficulty and initial-spawn policy.
- PrimaryLevelDataMixin provides the Hardcore runtime rule.
- ServerPlayerMixin restricts Adventure and living-player Spectator transitions.
- SlowHandSwingVisualMixin separates inadequate-tool animation feedback from potion/status mechanics.
- Worldgen placement now carries an explicit support-block predicate instead of checking only for air/water.

## Design reasoning
Project Flint should communicate restrictions through the world itself. A fake potion debuff, shrubs floating in trees, seed-dependent opening resources, and GUI-colored rectangles all undermine that goal. This release moves those rules closer to native Minecraft behavior while preserving the intentionally harsh primitive progression.

## Tuning snapshot
- Grass strip progress: 1 / 468 per mining tick.
- Hand-clear foliage progress: 1 / 150 per mining tick.
- Stone working success: 68%.
- Loose Rock placement attempts: 3/chunk.
- Forage bush placement attempts: 2/chunk in each active biome.

## Assets and licensing
No third-party pixels are redistributed in alpha.4. Better BushyLeaves and dronko's alternative Better Bushy Leaves were reviewed as permissively licensed visual references, but Project Flint uses its own geometry plus Minecraft's currently loaded vanilla/resource-pack textures. See TEMPORARY_ASSETS.md and ASSET_SOURCES.md.

## Validation performed
- JSON/resource graph validation.
- Active/inactive forage ecology consistency checks.
- Worldgen support-predicate checks.
- Advancement root/child consistency checks.
- Mixin/API signature review against Minecraft 1.21.11 mappings and Fabric 0.141.x documentation.

## Known limitations
- Existing generated chunks keep old bushes/rocks/structures. Use a fresh test world for worldgen validation.
- Hardcore is enforced by the mod at runtime; create-world screen simplification is not yet a custom Project Flint world-creation UI.
- The crafting-area mask relies on sampling the active inventory GUI texture; extremely unusual GUI packs with a patterned sample pixel may still need a dedicated compatibility path later.

## Next pressure
Begin the first genuine tool/cutting progression while continuing to replace generic alpha behavior with species/material-specific rules.
