# Project Flint v0.28.1.3-a

This hotfix corrects the shared two-input recipe path in the Wooden Grinder.

The root issue was `SimpleContainer.removeItem()` invoking `setChanged()` after the first ingredient was consumed. The menu then rebuilt its recipe state before the second ingredient was removed. Dual-input crafting now suppresses those intermediate refreshes, consumes both required inputs, and refreshes once after the craft is complete.

The active dual-input result is also mirrored into the first recipe-preview slot, so recipes such as Ground Leather and Leather Backpack visibly populate the bottom recipe row while both ingredients are present.
