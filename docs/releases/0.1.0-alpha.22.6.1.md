# Project Flint 0.1.0-alpha.22.6.1

## Intent

Repair the alpha.22.6 Mortar Chest compilation failure and add the requested Multitool shaping route from one full Loose Dirt block into two Loose Dirt Slabs without changing unrelated progression.

## Player-facing behavior

- Right-click placed Loose Dirt with a Crude Multitool or Flint Multitool.
- The original block becomes one bottom Loose Dirt Slab and one additional Loose Dirt Slab drops at the block.
- Shaping costs 1 Multitool durability, matching existing earth operations.
- Loose Dirt Slabs can be placed, waterlogged, combined into double slabs, and harvested with either Multitool. A double slab returns two slab items.

## Architecture

The Mortar Chest now supplies the `MapCodec` required by Minecraft 1.21.11's `BaseEntityBlock`. Loose Dirt shaping is handled by the server-authoritative `PrimitiveInteractionSystem` and queries `ToolCapabilities.Capability.MULTITOOL`; slab harvesting remains in the existing primitive block-breaking authorization and completion mixins.

## Design reasoning

One full block becomes two half blocks, so the conversion conserves material while giving the player an early partial-height building shape. Reusing the central Multitool capability automatically includes the Crude and Flint Multitools and leaves room for later higher-tier Multitools.

## Tuning snapshot

| Mechanic | Value |
|---|---:|
| Loose Dirt input | 1 placed block |
| Placed result | 1 bottom slab |
| Dropped result | 1 slab item |
| Tool durability | 1 |
| Slab item stack | 16 |

## Assets and licenses

No PNG was added or modified. Both slab block models reference the existing Project Flint Loose Dirt texture, whose human-made source and byte hash remain recorded in the texture provenance documents.

## Advancement coverage

No new advancement was added for this corrective shaping operation. Existing Loose Dirt progression remains the prerequisite.

## Validation

The validator checks the Mortar Chest codec contract and every Loose Dirt Slab registration, capability, conversion, durability, world-drop, harvesting, localization, model, item-definition, and loot-table marker. A Java 21 compile and in-game smoke test remain required if unavailable in the packaging environment.

## Known limitations

- Loose Dirt Slabs use vanilla slab physics and therefore do not fall like the full Loose Dirt block.

## Next release pressure

Smoke-test bottom/top placement, double-slab combination and recovery, waterlogging, conversion at chunk boundaries, and Mortar Chest inventory persistence.
