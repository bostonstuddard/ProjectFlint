# Project Flint v0.32.3 — Clay Grinder Build Hotfix

**Baseline:** v0.32.2 · **Minecraft:** 1.21.11 Fabric · **Scope:** compilation-only source patch.

## Fixed

- Removed an invalid trailing comma from the last `new Definition(...)` element of `ClayGrinderRecipeGuideRegistry.RECIPES` in `src/main/java/dev/projectflint/recipe/ClayGrinderRecipeGuideRegistry.java`.
- This resolves the `illegal start of expression` reported at line 76 during `:compileJava`.
- No recipe data, gameplay behavior, drop rates, grinder execution, or tool balance was changed.
- Retains v0.32.2 runtime recipe retirement policy, both Grinder menu guards and cleanup for 15 obsolete recipes.

## Install

Apply the patch ZIP at your Project Flint source root over v0.32.2; no containing folder is included. Run the included `build.bat`, which calls `APPLY_PROJECTFLINT_0_32_3.bat` before a clean build. Output on success: `dist/projectflint-0.32.3.jar`. Do not keep the old ProjectFlint JAR alongside it.

## Validation

- Parsed **266 Project Flint Java files** with the Java 21 compiler parser: zero syntax errors.
- Compiled `ClayGrinderRecipeGuideRegistry.java` with Java 21 against the actual Minecraft 1.21.11 mapped JAR and Fabric API modules (a minimal stub was used only for an otherwise unavailable `com.mojang.serialization.Keyable` interface in the isolated test environment).
- Full Gradle compile was attempted in offline mode but could not resolve the Fabric Loom build plugin from local caches. The user's build environment may have that dependency. Full successful Gradle build and runtime playtesting are not claimed.
