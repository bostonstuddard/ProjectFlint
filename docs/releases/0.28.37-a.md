# Project Flint v0.28.37-a — Wood -> Water Workstation Texture Pass

## Intent
Replace the temporary null/pending visuals introduced with the first Wood -> Water progression systems using the owner's finalized artwork.

## Player-facing behavior
The Sanding Station now has a finished sanding-board work surface, the Lumber Processor Chopping Block now has finished top/side/bottom artwork, and the Water Pot now has its finished top/side/front presentation. Water Pots rotate so the dedicated front face points coherently when placed.

## Architecture
`WaterPotBlock` now stores a horizontal facing property solely for model rotation. Normal placement faces the pot toward the player, while recovered Lumber Processor placement sets a deterministic orientation for the recreated pot. Existing Water Pot block-entity water/link data is unchanged.

## Design reasoning
The supplied Water Pot art contains a unique front face, so a fixed world-direction model would make the texture look wrong on three out of four placements. Adding a standard horizontal facing state keeps the supplied art intact without modifying its pixels.

## Tuning snapshot
No progression costs, machine speeds, water capacities, sanding durability, Lumber Processor timings, or output quantities changed in this release.

## Assets and licenses
All seven new PNGs are owner-provided Project Flint assets from `new update stuff(3).zip` and are copied byte-for-byte. Full hashes are recorded in `docs/TEXTURE_PROVENANCE.md`.

## Advancement coverage
No advancement logic changed. Existing Wood -> Water advancements remain intact.

## Known limitations
Water Bearing Pot, Bound Wood Processor, Wooden Board, Wooden Beam, and washed-workpiece visuals remain on their previous placeholder/null resources because no matching finalized artwork was included in this upload.

## Validation
All Project Flint JSON resources parse successfully, the supplied PNG hashes match the upload, and the release validator checks the three workstation model hookups plus Water Pot facing support.

## Next release pressure
Apply the remaining owner-finalized Wood -> Water item/workpiece art when those assets are supplied, then continue toward the Well/aquifer production chain.
