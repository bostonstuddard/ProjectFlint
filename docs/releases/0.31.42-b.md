# Project Flint v0.31.42-b

## Intent
Make the Well Pulley manageable before and during operation, and align Utility Vest recovery with the Well's specialized components.

## Player-facing behavior
- Opening the Pulley always displays its inventory, including while the Well is incomplete, unsupported or off an aquifer; the status shows Inactive rather than rejecting access. An incomplete Well produces nothing.
- Flint Axe/Plant Cutters or the Utility Vest can dismantle the Pulley even while running. The Pulley, all Rope and all stored output are returned exactly once.
- The obsolete “Rope boosts” label is removed; its progress bar sits higher. Rope still modifies speed by the existing nonlinear quality rule.
- Wearing the Vest allows all Wooden Beam variants to be dismantled regardless of the held item, returning the Beam plus its Wooden Screw. The Vest does not convert machine inventories into generic drops; generic salvage also retains both halves of double slabs when normal loot is absent.

## Architecture
- A single well-status refresh function runs on GUI open and periodically while ticking; invalid structure only resets Well processing data, not inventory accessibility.
- The server-side finished-break handler explicitly dismantles Well Pulleys and Wooden Beams. The client mining-progress mixin and both attack/completion permissions use the same Vest capability.
- Wooden Beams are deliberately excluded from generic player-placed block salvage to preserve Screw recovery. Block entities continue to be excluded from generic salvage: specialized machines keep their inventory-aware handling.
- No PF-EMI integration is added to ProjectFlint; existing gameplay recipes are unchanged.

## Design reasoning
The previous GUI refused incomplete Wells despite their inventory needing access. The active controller has no loot table and owns item storage, so dismantling it should not depend on vanilla incidental drop handling. The Vest's generic placed-block path can lose custom structural components, so Well frames use their own deterministic salvage.

## Tuning snapshot
- Rope quality, cycle work, aquifer gating, generated item quantities and storage sizes: unchanged.
- Beam/Pulley break speed: minimum 0.025 progress per tick (about two seconds); dedicated tools retain their rules.
- Utility Vest: no item durability cost when dismantling without a dedicated Well tool.

## Assets and licenses
No new or modified textures, models, sound files or external assets.

## Advancement coverage
No gameplay recipes or advancement changes. Guide coverage unchanged.

## Known limitations
This environment cannot run the full host Gradle/Fabric runtime test unless its Fabric Loom dependency is available. Source and simulated extraction checks are not a substitute for an in-game test.

## Validation
Validate pulley opening before and after completing the frame; dismantle a working Well with stored Rope/output; dismantle all eleven Beam variants while wearing the Vest, both empty-handed and while holding unrelated items. Check a non-Vest player still needs Flint Axe or Plant Cutters for frame parts.

## Next release pressure
