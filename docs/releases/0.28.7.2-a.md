# Project Flint v0.28.7.2-a

## Intent
Repair the remaining world-rendering regressions from the 0.28.7 darkness/Loose Rock changes, then apply the requested wet-weather, cooking-speed, Loose Soil, bear-dev-item, and Drenched-effect adjustments without changing unrelated progression.

## Player-facing behavior
- World-generated Loose Rocks are no longer the old flat square slab. Their actual worldgen model now uses an irregular low rock silhouette and the full existing Loose Rock texture.
- Full outdoor night is intended to be nearly pitch black beyond roughly 6–8 blocks. Project Flint now both suppresses night sky-light lift in the lightmap and caps full-night outdoor atmospheric visibility at 8 blocks. Night Vision bypasses the Project Flint night-fog cap.
- Terrified no longer creates blindness-style fog.
- Plant Fiber takes 375 base ticks to cook, 1.25x its previous 300-tick duration before workstation speed is applied.
- Exposed Twig Pile fires and Campfire Stone-frame fires extinguish in rain and cannot be relit while rain reaches them.
- Mortar Kiln cooking speed is 1.25x the Baked Kiln baseline. The permanent Campfire Stone frame is 0.90x the Baked Kiln baseline.
- Loose Soil is mined by multitools using the exact Dirt destroy-progress calculation and has a creative BlockItem.
- After 90 seconds of continuous wet exposure, Soaked is replaced by Drenched. Drenched retains Soaked movement/exhaustion behavior, deals Poison-I-equivalent periodic nonlethal damage, and prevents natural healing.
- Black Bear and Brown Bear spawn eggs are available in the Project Flint creative tab.
- Brown Bear muzzle/nose UVs are corrected with a dedicated model layer; the texture PNG is unchanged.

## Architecture
- `ProjectFlintNightFogEnvironment` is inserted ahead of vanilla atmospheric fog only for outdoor atmospheric fog during night. It is deliberately client-only presentation and does not alter server light levels.
- `assets/minecraft/shaders/core/lightmap.fsh` owns the Project Flint zero-light/night sky-light shaping. No GPU texture-write path is restored.
- Wet-state escalation remains server-authoritative in `PrimitiveEnvironmentEffectSystem`; `ModEffects.DRENCHED` owns Drenched penalties and poison-equivalent damage, while `FoodDataMixin` owns the natural-healing gate.
- Shared primitive processor duration is computed from recipe base ticks divided by a workstation speed multiplier. This keeps Baked Kiln as 1.0x while Mortar Kiln and Campfire adjust only their own effective duration.
- Brown Bear rendering uses its own baked model layer solely to fix UV coordinates while reusing vanilla Polar Bear geometry/animation behavior.

## Design reasoning
- Night darkness uses both lightmap and fog because removing minimum light alone still leaves distant outdoor terrain readable from moon/sky contribution. The 8-block fog target directly matches the requested gameplay visibility range.
- Rain checks use `Level.isRainingAt`, so shelter continues to matter: only fire actually exposed to precipitation is prevented/extinguished.
- Drenched uses poison-equivalent periodic damage inside the custom effect rather than adding a second vanilla Poison status icon.
- Workstation balance is expressed as speed multipliers instead of duplicating recipes with different hard-coded durations.
- Brown Bear texture pixels remain untouched in accordance with the Project Flint texture policy.

## Tuning snapshot
- Full-night outdoor fog end: **8.0 blocks**.
- Full-night outdoor fog start: **1.0 block**.
- Drenched threshold: **1800 ticks / 90 seconds**.
- Drenched poison-equivalent interval: **25 ticks**, nonlethal floor at 1 HP.
- Plant Fiber base cooking: **375 ticks**.
- Baked Kiln speed: **1.00x**.
- Mortar Kiln speed: **1.25x**.
- Campfire Stone frame speed: **0.90x**.

## Assets and licenses
- No supplied or existing texture pixels were redrawn, recolored, cropped, resized, filtered, or composited.
- `brown_bear.png` remains the canonical existing user-provided texture; only model UV coordinates changed.
- `drenched.png` is a byte-identical reuse of the existing Project Flint Soaked effect icon.
- Bear spawn-egg item models reuse Minecraft's existing Polar Bear spawn-egg model/texture resource rather than introducing generated art.

## Advancement coverage
No new progression advancement is introduced by this bug/balance hotfix. Spawn eggs are creative/development utilities; Drenched is an environmental consequence rather than a progression unlock.

## Known limitations
- The user message ended with “and remove the” after the Terrified blindness request. No additional Terrified behavior was removed because the intended target was not specified.
- The custom outdoor night-fog rule is deliberately skipped where no skylight reaches at all (for example deep underground) and with Night Vision; the lightmap true-darkness rule still applies normally.
- Full Gradle assembly could not be executed in this sandbox because the cached source does not contain the Fabric Loom 1.14.10 plugin artifact and external plugin resolution is unavailable here.

## Validation
- All modified/new JSON resources parse successfully.
- The changed Java gameplay/client classes compile directly against the uploaded Minecraft 1.21.11 mapped JAR, cached Fabric API classes, and minimal compile-only stubs for external compile-time APIs absent from the archive.
- The three changed mixins also pass direct Java compilation against the mapped Minecraft signatures.
- `FogRenderer.FOG_ENVIRONMENTS` was verified from the mapped 1.21.11 class to be a mutable `ArrayList`, so inserting the Project Flint night environment does not mutate an immutable list.
- `tools/validate_release.py` is updated for this release and checks the new darkness, Drenched, Loose Rock, cooking-speed, spawn-egg, cleanup, and grinder-persistence invariants.
