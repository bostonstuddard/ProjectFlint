# Project Flint v0.28.36-a — Sugar Cane Tool Identity Fix

## Intent
Restore the intended specialization split between Flint Plant Cutters and the Advanced Flint Multitool.

## Player-facing behavior
Flint Plant Cutters are the only tool that converts harvested Sugar Cane blocks into Sugarcane Rolls. Breaking the top, middle, or bottom of a cane column still yields one roll per removed segment. The Advanced Flint Multitool remains an advanced plant-tier tool, but harvesting Sugar Cane with it now returns ordinary Sugar Cane.

## Architecture
The dedicated Sugarcane Roll branch in `ServerPlayerGameModeMixin` now checks only `FLINT_PLANT_CUTTERS`. The following general plant-cutter cane branch continues to return vanilla Sugar Cane, so the Advanced Flint Multitool naturally falls through to the correct output without losing its plant-tier capabilities.

## Design reasoning
Sugarcane Rolls are a specialization reward for crafting Flint Plant Cutters. The Advanced Flint Multitool is broader and faster, but it should not erase the identity of the dedicated harvesting tool by producing its exclusive processed output.

## Tuning snapshot
- Flint Plant Cutters: one Sugarcane Roll per Sugar Cane segment removed.
- Advanced Flint Multitool: one normal Sugar Cane per Sugar Cane segment removed.
- Existing column harvesting, durability use, and advanced plant-tier speed remain unchanged.

## Assets and licenses
No textures, models, or other visual assets changed.

## Advancement coverage
No advancement changes were required. Existing Sugar Cane/Sugarcane Roll progression remains intact.

## Known limitations
This patch only corrects Sugar Cane output identity. It does not rebalance other Flint Plant Cutter or Advanced Flint Multitool plant yields.

## Validation
The release validator checks that the roll branch names only Flint Plant Cutters and that the general plant-cutter branch still returns normal Sugar Cane.

## Next release pressure
Continue Wood-to-Water progression while preserving dedicated-tool advantages over general-purpose multitools.
