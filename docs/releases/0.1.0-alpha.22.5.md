# Project Flint 0.1.0-alpha.22.5

## Intent

Repair the reported rest, Flint harvesting, placed-assembly rendering, filled-bowl art, grinder conversion, Squid resources, and raw-food consequences without retuning unrelated progression.

## Player-facing behavior

- The Crude Sleeping Bag is now a linked two-block foot/head structure and a vanilla bed-tagged sleep target, so a valid sleep advances the night. Dye and break actions affect the pair; salvage remains exactly 2 Woven Wool.
- The Clay Grinder converts 2 Twigs into 1 Branch.
- Direct Flint Multitool harvest returns the whole flower rather than petals. It also harvests Dead Bush, Bush, Firefly Bush, and Project Flint forage bushes. Held-flower hand-working remains the deliberate petal route.
- Squids add 1 Raw Calamari and 1 Animal Bones to death loot.
- Eating tagged raw meat or raw fish applies Poison I and Nausea I for 100 ticks and Hunger III for 60 ticks.
- Filled Fired Clay Bowl stages use the supplied Fired Clay Bowl sprite, and sneak-placed Burnt Branch/Flint assembly layers use block-atlas-safe copies of supplied art.

## Architecture

`SleepingBagBlock` owns vanilla-compatible `PART` and `OCCUPIED` state plus linked placement, dye, support, sleep, and salvage operations. `ToolCapabilities.canDirectHarvestPlant` centralizes Flint's whole-plant permission across progress, authorization, and completion. `projectflint:raw_meats` is the data boundary consumed by `RawMeatConsumptionMixin`. `PrimitiveAnimalDropSystem` remains the animal-resource loot boundary.

## Design reasoning

Bed-style state prevents each Sleeping Bag half from behaving as an unrelated block and lets Minecraft's sleep bookkeeping recognize occupancy. The raw-meat rule is tag-driven so later meats can opt in without another hard-coded branch. Direct Flint harvesting and held flower processing remain separate actions: one preserves the plant, the other produces petals.

## Assets and licenses

All changed PNGs are exact, byte-for-byte copies from project-owner-supplied human-made assets. Filled bowl stages use `fired clay bowl.png`; the ground Burnt Branch and Flint layers use `burnt branch.png` and `flint chip.png`; Raw Calamari uses the supplied `food_mysterymeat.png`. No pixels were generated, redrawn, resized, recolored, cropped, composited, or filtered. Both provenance ledgers record every target, source path, and SHA-256 hash.

## Advancement coverage

Existing Petal Harvest, Flint Multitool, and Sleeping Bag descriptions now distinguish direct whole-plant harvest, held petal processing, 3.5 total Flint damage, and the two-block night-rest behavior. No new progression milestone was needed for a corrective drop/food rule.

## Validation

The validator checks the four Grinder recipes, two-block Sleeping Bag state and beds tag, Flint whole-plant helper use in all three break boundaries, raw-meat item/tag/effect mixin, Squid drops, model texture domains, filled-bowl hash equality, all JSON links, mixin registration, and exact texture provenance; it passes. The Gradle compile attempt stopped before Java compilation because Fabric Loom 1.14.10 could not be resolved in this environment. No build pass is claimed; the local Java 21 `build.bat` path and first-client smoke test remain final release gates.

## Known limitations

- The two Sleeping Bag halves intentionally reuse the existing compact color models; this repair changes footprint/state behavior, not the art silhouette.
- Raw Calamari currently has no cooked result because only the requested raw Squid drop was added.
