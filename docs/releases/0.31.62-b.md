# Project Flint v0.31.62-b — Early Stone-working regression hotfix

## Intent
Restore the beginning of Stone processing after generalized mining restrictions accidentally blocked the Crude Stone Hammer.

## Player-facing changes
- Fixed the Crude Stone Hammer being unable to process natural Stone. Completing the action turns Stone into Crushed Stone and produces **4 Rocks**.
- Crude, Flint and Advanced Flint Multitools can perform that same operation at their established Hammer working speeds.
- Hands, food, the Utility Vest and unrelated tools do not mine Stone; the Crude Hammer does not gain permission to mine Cobblestone or ores.
- Wooden/Hardwood Pickaxes, Hardwood Hammer and higher vanilla pickaxes retain their existing ordinary stone-mining and ore tier behavior.

## Architecture and reasoning
`OreMiningRules.canPrimitiveStoneWork` is the single Stone-conversion predicate. The shared progress computation, attack callback, break permission and server destroy handler all honor it before general rock/ore denial. The original conversion logic (Crushed Stone, four Rocks, tool damage, sound, advancement) now executes before the generic pickaxe loot handler. This is **not** a broad new rock-mining tier; see ADR 0021.

## Tuning and assets
Crude Hammer Stone progress: `1/234` per tick (~11.7 seconds at 20 TPS), scaled by existing Multitool Hammer speed multipliers. One durability per completed Stone; 4 Rock drops and Crushed Stone in world. No asset/texture changes or new dependencies.

## Progression and guides
G-key Field Guide now explains the Stone Hammer result. K-key Recipe Guide is unchanged because Stone hammering is a world interaction, not a crafting recipe. The existing "crushed_stone" milestone trigger remains.

## Verification
- Inspected source across four interception paths and confirmed an earlier branch had shadowed the original operation.
- `tools/validate_03162.py` verifies tool whitelist, guard ordering, correct outputs, no extra mining permissions and JSON resource validity.
- `OreMiningRules.java` compiled against the locally supplied Mojang-mapped 1.21.11 Minecraft JAR and matching Fabric API classes using test stubs for mod registries.
- **A complete Gradle build and an in-game survival run have not been performed in this environment.** Windows `build.bat` and multiplayer must still be tested before deployment.

## Critical in-game acceptance steps
1. In Survival, obtain the first Rock and craft/assemble a Crude Stone Hammer.
2. Mine *natural Stone* with the Crude Hammer: cracks progress for about 11.7 s; completion places Crushed Stone and drops exactly 4 Rocks; the tool loses one durability.
3. Repeat with Crude/Flint/Advanced Flint Multitools and verify faster work does not allow ore harvesting.
4. Test a bare hand, bread and Utility Vest on Stone, Cobblestone, Andesite, Diorite, Granite and Deepslate. No unauthorized fast mining or drops.
5. Test a Wooden Pickaxe, Hardwood Pickaxe and Hardwood Hammer on Stone/Cobblestone; verify Cobblestone drops, ore restrictions and the Hammer's 2-Coal / 1-Raw-Iron-or-Copper rules remain.
6. Verify bush harvesting and the Crude Hammer's Sugar Cane/Crude Reed bootstrap behavior still work.
