# Project Flint 0.26-a — Advanced Primitive Infrastructure

## Balance and durability

- Flint Axe supported-log break time: **6.5 seconds**.
- Plant Tool Binding max stack: **32**.
- Burnt Branch max stack: **32**.
- Branch max stack: **16**.
- Twig max stack: **16**.
- Bone Brush durability: **160**, consumed on completed block brushing and sheep brushing.

## Advanced Kiln and compressed fuel

- Existing Advanced Kiln casting recipes now take **60 seconds**.
- Fired Clay Pot Mold is consumed when its Advanced Kiln recipe completes.
- Added Unfired/Fired Clay Block Mold progression using the same mold-base → kiln-firing steps as the other molds.
- Fired Clay Block Mold is reusable. Its special Advanced Kiln recipe uses **4 Branches + 4 Flint**, no Fired Clay and no Burnt Branches, and takes **15 seconds**.
- Output is one gravity-affected Burnt Branch Block.
- Grinder recipes: 1 Burnt Branch Block → 2 Burnt Branch Slabs; 1 Burnt Branch Slab → 8 Burnt Branches; 2 slabs → 1 block.

## Mortar Kiln

- **32 Mortar Bricks → 1 Mortar Kiln Base** in a Clay Grinder or better.
- The base is finished with **1 Advanced Kiln Glass** to create the Mortar Kiln. This uses the existing Advanced Kiln finishing material because the current project has no standalone `advanced_kiln_block` item.
- Mortar Kiln uses the completed Clay Kiln processing registry but burns for **15 minutes** per loaded fuel cycle.
- The finished Mortar Kiln can only be recovered intact with the Advanced Flint Multitool.

## Wooden Grinder

- **16 Woven Wood → Wooden Grinder Base** in a Clay Grinder or better.
- **8 Very Refined Stone → 1 Crushed Stone**; **8 Crushed Stone → 1 Stone Grindsaw**.
- Using the Stone Grindsaw on the Wooden Grinder Base creates the Wooden Grinder.
- The finished grinder requires the Advanced Flint Multitool for intact recovery.
- It has **two inputs**, keeps every one-input Clay Grinder recipe, and adds:
  - 2 Raw Hide + 1 Sanding Paper → Ground Hide
  - 8 Leather + 8 Woven Wood → Woven Chest Frame
  - 4 Leather + Reed Backpack → Leather Backpack
- Ground Hide can be washed against water into vanilla Leather.

## Storage and equipment

- Woven Chest Frame upgrades a Mortar Chest in-place into a **12-slot Woven Chest**, preserving the existing seven stored stacks.
- Woven Chest intact recovery requires a Flint Axe.
- Leather Backpack is an unbreakable Reed Backpack upgrade with **2 armor**, **four additional usable inventory slots beyond the Reed Backpack**, and **1.05× food exhaustion while equipped**.
