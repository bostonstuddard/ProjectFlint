# Project Flint v0.31.3-b

## Intent

Finish the first Flint File woodworking pass while correcting the remaining Bookshelf, Lumber Processor, leaf-harvesting, armor, and creative-access issues found during v0.31.2-b playtesting. This release intentionally keeps the existing Wood/Water progression structure and extends it with reusable woodworking components rather than introducing a new age.

## Player-facing behavior

- The Bookshelf no longer displays its lower recipe-preview strip or preview Book while both inputs are empty or invalid. The preview appears only when the current two inputs form a valid Bookshelf recipe.
- The washed Lumber Processor workpiece is now a full chopping-block-sized block and uses the Wooden Beam side/top artwork instead of the old half-height/pending presentation.
- Flint Multitool leaf harvesting changes from about **2.0s to 2.2s**.
- Advanced Flint Multitool leaf harvesting changes from about **1.5s to 1.875s**.
- Flint Plant Cutter leaf harvesting changes from about **1.5s to 2.025s**. With Plant Cutters, leaves now have a **25% corresponding sapling/propagule chance** and a separate **10% vanilla Stick chance**.
- Sanding Station: **1 Flint Cutter Piece -> 1 Flint File Head**.
- Wooden Grinder: **1 Flint File Head + 1 vanilla Stick -> 1 Flint File**. Flint Files have **128 durability**.
- Wooden Grinder: **1 Wooden Beam + Flint File -> 4 Wooden Sheets**. The file is retained and loses **1 durability**. Wooden Sheets stack to **64**.
- Wooden Grinder: **1 Wooden Board + Flint File -> 2 Wooden Screws**. The file is retained and loses **1 durability**. Wooden Screws stack to **32**.
- Wooden Grinder: **8 Wooden Sheets + 4 Wooden Screws -> 1 Wooden Door Hinge**. Hinges stack to **8**.
- Wooden Grinder: **16 Wattled Daub Bricks + 1 Wooden Door Hinge -> 1 Wattled Daub Door**.
- Bone Chestplate and Bone Leggings now provide **1.5 armor each**.
- Wooden Grinder: **8 Leather + 8 Woven Wool -> Leather Chestplate** and **7 Leather + 7 Woven Wool -> Leather Leggings**. Both use Project Flint's 512-max-durability leather armor format.
- Project Flint's **512-durability vanilla Brush variant** is now directly available from the Project Flint creative inventory.

## Architecture

`WoodenGrinderRecipeRegistry` now supports retained/damageable catalyst inputs in addition to normal two-input consumption. Each match carries slot-relative consume and damage actions, so recipes can consume the wood material while retaining a Flint File and applying exactly one point of wear. Swapped input order preserves the same behavior.

Flint Plant Cutter leaf completion now has a dedicated server-side branch rather than falling through to vanilla leaf loot. The branch maps each supported vanilla leaf block to its matching sapling, propagule, or azalea item, then rolls Project Flint's explicit 25% sapling and 10% Stick chances.

The Wooden Screw item definition uses one reusable two-layer `projectflint:item/screw` model. The primary screw layer receives a constant dark-brown material tint while the secondary detail layer remains untinted. Future metallurgy screws can therefore reuse the supplied screw geometry/pixels and change only their material tint/definition.

The Bone Chestplate/Leggings continue to use the existing bone equipment material for equipping/repair behavior, but their armor attribute component is overridden with an explicit 1.5-point `generic.armor` modifier for the appropriate equipment slot.

## Design reasoning

A Flint File should be a reusable workstation tool rather than a consumed recipe ingredient. Giving the registry first-class retained-tool semantics prevents future file-based recipes from reimplementing durability logic and makes it straightforward to add finer woodworking or metallurgy processing later.

The screw art is deliberately material-agnostic. Keeping material color in the item definition avoids duplicating otherwise identical screw textures when copper, bronze, iron, or other metallurgy variants enter progression.

Plant Cutters remain the best dedicated foliage tool, but the increased processing time keeps leaf clearing from becoming effectively instantaneous. Their explicit sapling/Stick loot also makes the intended tree-renewal benefit deterministic at the design level instead of depending on vanilla leaf-table behavior that can change independently of Flint.

- Advanced Flint Multitool leaves: **37.5 ticks / 1.875s**.
- Flint Plant Cutters leaves: **40.5 ticks / 2.025s**.

- Wooden Door Hinge stack size: **8**.

## Assets and licenses

This release imports the owner-supplied artwork from `new update stuff (2).zip`: `flint file head.png`, `flint file.png`, `screw.png`, `screw_secondary.png`, `wood sheet.png`, and `wooden door hinge.png`. The specifically marked `file_bottom for future use do not include.png` is not copied into Project Flint.

The supplied screw artwork is kept pixel-identical and split into its provided primary/secondary layers. Project Flint supplies only the item-definition tint metadata needed to render the wooden material as dark brown; no generated replacement artwork is introduced.

## Advancement coverage

The unified ProjectFlint advancement page gains six progression nodes covering Flint File Head, Flint File, Wooden Sheet, Wooden Screw, Wooden Door Hinge, and the Wattled Daub Door craft. They extend the existing Sanding Station/Wooden Grinder branch rather than creating another era tab.

The existing detailed progression tree and prior Bookshelf, Lumber Processor, armor, Brush, and Wattle-and-Daub guidance remain in place.

## Known limitations

Leaf timings are expressed as destroy-progress-per-tick targets, so the Advanced Flint Multitool and Plant Cutter values intentionally use fractional tick-equivalents (37.5 and 40.5) to preserve the requested percentage increases as closely as Minecraft's progress system permits.

Only the Wooden Screw material tint is introduced in this release. Metallurgy screw item registrations/recipes are intentionally deferred until metallurgy progression exists.

## Validation

Release validation checks v0.31.3-b version/build/cleanup wiring, JSON syntax, Bookshelf conditional preview behavior, full-block Wooden Beam workpiece presentation, exact leaf timing constants, Plant Cutter sapling/Stick probabilities, all five new item registrations/stack sizes, Flint File durability/catalyst wear, Sanding Station and Wooden Grinder recipes, Leather Chestplate/Leggings costs, Bone Chestplate/Leggings armor values, creative Brush exposure, owner-supplied asset hashes, the reusable tinted screw model, all six new advancement files, and absence of the explicitly excluded future file-bottom texture.

The v0.31.1-b single-handler Sugar Cane regression guard and v0.31.2-b workstation recovery/state-preservation guards remain active. Full Gradle compilation remains environment-dependent when Fabric Loom 1.14.10 is unavailable to Gradle's plugin resolver.

## Next release pressure

Playtest the Flint File through repeated Wooden Sheet/Screw crafts to confirm retained-tool wear and breakage feel correct, verify Plant Cutter leaf drops across every vanilla tree family, and confirm the tinted Screw presentation is legible in inventory. The new reusable screw model should be treated as the canonical screw art path when metallurgy begins.
