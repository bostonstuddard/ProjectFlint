# Project Flint v0.31.10-b — Rope Processing, Parchment Visuals, and Researched Meals

## Intent
Extend the new recipe-research layer without weakening its data-driven foundation: Recipe Parchments should remain useful before and after inscription, visibly communicate their state, and feed a repeatable research-to-Oven workflow. The same release establishes Rope as a deliberate multi-stage construction material for upcoming infrastructure.

## Player-facing behavior
Wooden Cabinets once again accept blank Recipe Parchments as well as inscribed ones. Blank parchment keeps its original texture; any parchment carrying a recipe ID uses the supplied filled parchment art. Sixteen String sand into one Project Flint Cobweb, then the Wooden Grinder advances that material through Rope (1/3), Rope (2/3), Rope (3/3), and finally placeable Rope. A full 4/4 Bookshelf can research Beef Stew and Bone Broth directly, while Bacon and Eggs deliberately takes two research passes: Cooked Porkchops create an unfinished parchment and Scrambled Eggs complete it. The Primitive Oven cooks all three completed recipes.

## Architecture
Recipe Parchment continues to store one immutable recipe ID in `minecraft:custom_data`. Its item definition now uses Minecraft 1.21.11's `minecraft:has_component` item-model condition so that the same item ID selects blank or filled art from the presence of that metadata. Bookshelf recipe definitions now support three parchment constraints per input: no parchment constraint, explicitly blank parchment, or an exact bound recipe ID. That makes multi-stage research possible without introducing disposable one-off research items. Rope uses three plain intermediate items and one final `BlockItem`; only the final registered Rope block is placeable.

## Design reasoning
Allowing blank parchment in the cabinet makes the cabinet useful as preparation/storage rather than only as an archive. Visual state is derived from the same metadata that drives Oven recipes, preventing art and recipe state from desynchronizing. Bacon and Eggs uses an exact intermediate recipe ID so an unrelated filled parchment cannot satisfy its second research stage. The Project Flint Cobweb is an item-only crafting material and therefore cannot bypass the intended Rope progression by being placed as a vanilla Cobweb.

## Tuning snapshot
Rope chain: 16 String -> 1 Cobweb in the Sanding Station; Cobweb + 4 Plant Tool Bindings -> Rope (1/3); Rope (1/3) + 4 Wooden Screws -> Rope (2/3); Rope (2/3) + 2 Wooden Sheets -> Rope (3/3); Rope (3/3) + Flint File -> Rope, retaining the file and costing 1 file durability. Beef Stew research costs 8 Steak and its Oven recipe is 2 Steak + 1 Butter + 1 Sugar + 3 Wooden Cups -> 3 Beef Stew (4.5 hunger, 5.2 saturation). Bacon and Eggs research costs 8 Cooked Porkchops, then 8 Scrambled Eggs; its Oven recipe is 1 Cooked Porkchop + 3 Scrambled Eggs + 1 Wooden Cup -> 3 Bacon and Eggs (3.5 hunger, 4.6 saturation). Bone Broth research costs 6 Filed Bone and its Oven recipe is 4 Filed Bone + 1 Butter + 2 Wooden Cups -> 4 Bone Broth (1 hunger, 0.8 saturation). New meals stack to 16.

## Advancement coverage
Added eight detailed milestones covering Project Flint Cobweb, all four Rope progression milestones, Beef Stew, Bacon and Eggs, and Bone Broth. Existing unified ProjectFlint advancement guidance remains intact.

## Known limitations
Minecraft 1.21.11 itself has no vanilla Cobweb crafting recipe, so there is no vanilla recipe JSON to override; this release simply adds the intended Project Flint item-only Cobweb craft. Rope currently has no attachment/tension simulation because those behaviors belong to the upcoming well/build systems. The intermediate Bacon parchment is research-only and intentionally cannot be used as a Primitive Oven recipe.

## Validation
Release validation checks cabinet acceptance, immutable parchment metadata, blank/filled model switching, exact intermediate Bacon research gating, all requested ingredient/output counts, Rope stage placeability separation, owner texture hashes, translations, item/block resources, advancement count, version/build cleanup wiring, and all inherited Project Flint regression checks. Every project JSON resource is parsed during validation.

## Next release pressure
Use final Rope as the stable dependency for the planned well and other suspended/structural builds. Continue expanding Bookshelf research through exact parchment IDs so future recipes can use multi-step discovery without hardcoded UI-specific recipe logic.
