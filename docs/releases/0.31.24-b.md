# Project Flint 0.31.24-b — Aquifer Well Infrastructure

## Intent
Introduce the first usable aquifer Well loop and its construction pieces, while moving the Dowsing Rod and Wooden Beams into normal Survival progression.

## Player-facing behavior
- Crude Clay Blocks now stack to 3.
- Wooden Grinder: 2 Sticks + Flint File -> Dowsing Rod; the File is retained and loses one durability. The Dowsing Rod has 16 durability.
- Wooden Beams can be placed in Survival only while a Wooden Screw is held in the off hand. A successful placement consumes one screw.
- Advanced-Kiln-era Flint tools can dismantle a placed Wooden Beam into the same Beam plus one Wooden Screw.
- Wooden Grinder: 1 Bricks + 1 Wooden Board -> 3 Brick Shingles.
- Incomplete staged Recipe Parchments now use the supplied incomplete parchment art; fully researched bound parchments keep the existing completed art.
- Added the first functional Well Pulley controller and Well interface.

## Architecture
The Well controller is a block entity/menu pair backed by an eight-slot output buffer plus one optional Rope slot. `WellMultiblock` validates the structure and calls the existing deterministic `AquiferSystem`, while `WellPulleyBlockEntity` owns production timing, pending outputs, quality calculations and persistent inventory state. Wooden Beam placement is handled by `ScrewedBeamBlockItem`; dismantling remains server-authoritative in `ServerPlayerGameModeMixin`.

The required Well geometry, relative to the center of the solid floor, is:
1. Y0: solid 3x3 vanilla Bricks.
2. Y1-Y3: three 3x3 Brick rings with an open center.
3. Y4-Y6: Wooden Beam posts on all four corners.
4. Y7: a 3x3 Brick Shingle roof, with the Well Pulley replacing the center shingle.
5. Two Rope blocks hang directly below the Well Pulley at Y6 and Y5.

The Well only validates when the floor center X/Z is the exact virtual-aquifer center column.

## Design reasoning
The Well is deliberately tied to the already seed-deterministic virtual aquifer system rather than physical underground water generation. This keeps renewable water location-dependent while avoiding worldgen migration. The eight-slot result buffer is large enough for unattended operation but finite so production cannot silently delete output. Pending results are atomic: if a complete roll cannot fit, the Well pauses until it can. Rope is an optional accelerator rather than a hard construction cost so a structurally valid Well always works.

## Tuning snapshot
- Base production cycle: 1,200 ticks / 60 seconds at 100 effective quality.
- Source quality points: Scarce 25, Normal 60, Good 85, Abundant 120.
- Rope bonus: +2 quality points per inserted Rope, max 16 Rope / +32. Rope is not consumed.
- Output buffer: 8 slots.
- Clay roll: 0-2 vanilla Clay Balls, scaled by effective quality.
- Flint roll: 2-4 Flint Chip units, scaled by effective quality; a 4-unit result becomes 1 vanilla Flint.
- Internal water: all three shaft-center blocks are refilled with source water at each completed cycle. Existing water does not stop item production.
- Dowsing Rod durability: 16.
- Crude Clay Block stack size: 3.

## Advancement coverage
None. Minecraft/Project Flint advancements remain disabled in favor of Flint Quests. Well output extraction emits the existing Project Flint workstation event for `well` so Flint Quests can observe collected Well products.

## Known limitations
- The Well Pulley has a temporary vanilla-texture placeholder and no Survival crafting recipe yet because neither was specified.
- The Well currently validates the exact prescribed 3x3 structure only; alternate decorative roof/post layouts do not count.
- `basin.png` and `basin_base.png` are intentionally not wired to any block yet.

## Validation
The release validator checks the exact owner-asset hashes, Crude Clay Block stack size, 16-durability Dowsing Rod and Grinder recipe, survival screw-gated Beam placement/recovery, exact aquifer-center validation, Well structure, Rope quality bonus, eight-slot buffer, output rules, water refill, parchment model states and Brick Shingle resources/loot. All JSON resources are syntax-validated.
