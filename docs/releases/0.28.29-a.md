# Project Flint v0.28.29-a

## Intent
Restore the advancement system as a detailed player guide without returning to duplicate or paragraph-length milestones.

## Player-facing behavior
Project Flint now exposes 128 concise advancement steps across Tool Era, Clay Era, and Wood Era. Tool Era is always the first advancement tab, and important upgrades such as Cutters, Multitools, Clay Kilns, the Clay Pot, Flint tools, and the Wooden Grinder are visually emphasized as goals.

## Architecture
The three era root IDs are now `00_tool_era/root`, `01_clay_era/root`, and `02_wood_era/root` so their resource ordering mirrors progression order while their visible titles remain unchanged. Existing child advancement IDs are preserved.

## Design reasoning
Advancements are treated as a step-by-step survival manual: almost every meaningful material transformation or technology unlock gets its own short sentence, while true duplicates are still avoided.

## Tuning snapshot
- 128 total Project Flint advancements.
- 32 advancements in Tool Era.
- 23 advancements in Clay Era.
- 73 advancements in Wood Era.
- Description target remains one compact sentence, maximum 170 characters.

## Assets and licenses
No texture or model pixels were changed in this release.

## Advancement coverage
Restored milestones include Place in World, Disturbed Earth, Kindling, permanent campfire relighting, stone stockpiles, Flower Petals, Loose Dirt, Crude Clay Slabs, primitive foods, dye filing, all advanced clay mold stages, Burnt Branch compression, and Mortar Brick Slabs.

## Known limitations
Wood Era is intentionally large because it currently contains all post-Clay-Grinder technology; a future fourth era can split it when the next civilization tier is defined.

## Validation
The release validator checks root ordering, backgrounds, parent integrity, granular advancement count, restored milestones, concise descriptions, and the v0.28.29-a cleanup/build wiring.

## Next release pressure
Continue adding new progression as explicit mini-guide milestones rather than collapsing several player actions into one advancement.
