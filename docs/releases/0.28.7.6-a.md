# Project Flint v0.28.7.6-a — Navigation-Preserving Hardcore Darkness

## Intent
Remove the artificial short-range nighttime fog after playtesting showed it hid distant campfires and structures, while preserving Project Flint's near-black unlit nighttime presentation.

## Player-facing behavior
- Midnight no longer applies Project Flint's 6–8 block atmospheric fog wall.
- Unlit terrain remains very dark through the existing hardcore lightmap shader.
- Campfires, torches, lit kilns, and other genuine block-light sources can once again be seen from beyond the player's immediate surroundings and used as navigation landmarks.
- The existing 45-second darkness-damage grace period and Crude Plant Torch behavior are unchanged.

## Architecture
- Removed `FogRendererMixin` from the active client mixin list.
- Retired `ProjectFlintNightFogEnvironment` and `FogRendererMixin` source files through the release cleanup BAT.
- Hardcore darkness remains implemented by the `assets/minecraft/shaders/core/lightmap.fsh` override, which suppresses nighttime sky contribution without clipping the rendered world by distance.

## Design reasoning
A distance fog wall is the wrong primitive for Project Flint's darkness goal because fog discards useful information regardless of whether a surface is actually illuminated. Darkness should make **unlit space** hard to read, not erase a distant fire or settlement light. Keeping the effect in the lightmap preserves that distinction.

## Tuning snapshot
- Project Flint artificial night fog: removed.
- Full-night sky-light floor: unchanged at 0.06.
- Block-light visibility: no Project Flint distance cutoff.
- Darkness damage grace: unchanged at 45 seconds.

## Assets and licenses
No textures, models, or other visual asset pixels were added or edited in this hotfix.

## Advancement coverage
No advancement changes are needed for this rendering-only correction.

## Known limitations
- Final perceived darkness still varies with monitor/display calibration, shader packs, and third-party rendering modifications.
- The 0.06 moonlight floor remains intentionally separate from block-light visibility and can be tuned later without reintroducing fog.

## Validation
- `projectflint.mixins.json` is checked to ensure `FogRendererMixin` is no longer active.
- The validator requires the old night-fog source classes to be absent from the cleaned source tree.
- The existing lightmap shader, Night Vision path, 0.06 night floor, torch mechanics, and 45-second darkness grace are retained.

## Next release pressure
Confirm in-game that a campfire or lit structure can be seen at useful navigation distance at midnight while the unlit terrain around it remains appropriately threatening.
