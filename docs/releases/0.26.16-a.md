# Project Flint v0.26.16-a

## Backpack rendering
- Leather Backpack now uses the exact Reed Backpack worn-model JSON geometry and display logic.
- Leather-specific material: `projectflint:item/ground_hide` on the same `worn` faces used by the Reed Backpack.
- Both backpack types render at `0.85x` scale.
- Both backpack types are translated downward from Y `0.19` to Y `0.40` (about 3.4 model pixels).
- No texture PNGs were altered.
