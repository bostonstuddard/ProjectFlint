# Project Flint 0.1.0-alpha.21.7 — World Drops, Kiln Salvage, Grinder UI, and Flint Foliage Speed

## Intent

Alpha.21.7 is a focused interaction-consistency patch on top of the corrected alpha.21.6 tree. It fixes the Clay Grinder container lifetime regression, restores normal world-drop behavior for custom block harvesting, makes the baked kiln/grinder recoverable through material salvage, improves kiln output directionality, and increases Flint Multitool speed on soft vegetation only.

## Player-facing behavior

### Clay Grinder UI

The Clay Grinder still uses the stonecutter-style screen shell, but its server menu once again validates against `projectflint:clay_grinder` rather than vanilla's Stonecutter block. The menu therefore stays open normally. Its visible recipe set remains intentionally empty; alpha.21.7 does not add grinder recipes.

### World drops from breaking

Project Flint's custom break-completion paths now spawn their output as ordinary world ItemEntities at the block position instead of inserting the result directly into the primitive inventory. This covers the custom break paths for primitive terrain/vegetation/tool harvesting, including Rock, Twig, Plant Fiber, Flower Petals, Dirt Piles, Flint Chips, Sugar Cane, Crude Reeds, and related custom block recovery.

Vanilla item-entity pickup behavior remains responsible for collecting these drops afterward.

### Kiln and grinder salvage

- **Baked Clay Kiln → 2 Fired Clay** when broken.
- **Clay Grinder → 4 Super Heated Clay** when broken.

The workstation block item itself is not returned by those break paths. Their fixed block loot tables are intentionally not explosion-decayed, so normal loot-generating destruction keeps the exact salvage amounts. The Project Flint Creeper no-loot redirect contains a narrow exception for these two blocks so this requested salvage is not discarded by Creeper destruction.

The baked kiln's old unbreakable strength/no-loot registration is removed; it now uses finite block strength and the salvage loot table.

### Kiln output direction

When a timed baked-kiln recipe completes, the result now spawns immediately outside the kiln's **front face**, using `BakedClayKilnBlock.FACING`. It receives a small outward/upward motion so the result visibly exits the kiln rather than appearing over the center of the block.

### Flint Multitool soft-vegetation speed

Flint Multitool destroy progress on the shared cutter foliage route is multiplied by an additional 2×. This means alpha.21.7 is **twice as fast as alpha.21.6** on:

- Short Grass;
- Tall Grass;
- Leaf Litter;
- flower-tag blocks.

This extra multiplier does **not** affect the Flint Multitool's Sugar Cane, leaf-block, dirt, Loose Dirt, gravel, stone, or forage-bush timings.

## Architecture

- `ClayGrinderMenu` retains the empty-recipe Stonecutter-backed shell but restores a custom `stillValid(...)` check for the Clay Grinder block.
- `ServerPlayerGameModeMixin` uses `Block.popResource(...)` for outputs produced by actual block-breaking operations.
- `baked_clay_kiln.json` and `clay_grinder.json` block loot tables define workstation salvage.
- `BakedClayKilnBlockEntity` derives the output spawn position and velocity from the kiln's horizontal facing.
- `BlockStateBaseMixin` makes the kiln/grinder breakable and applies the extra Flint foliage-speed multiplier only on cutter-style soft vegetation.

## Design reasoning

This patch deliberately restores vanilla-like expectations at subsystem boundaries instead of adding more special cases. Breaking a block should create a world drop, workstation salvage should be defined by the workstation block rather than by inventory insertion code, and kiln output should visibly leave from the kiln opening. The Flint speed change is intentionally scoped to the exact soft-vegetation targets requested so the rest of the Flint tier remains unchanged.

## Tuning snapshot

- Baked Clay Kiln salvage: **2 Fired Clay**.
- Clay Grinder salvage: **4 Super Heated Clay**.
- Flint Multitool grass / Tall Grass / Leaf Litter / flower break speed: **2× alpha.21.6 speed**.
- Kiln output ejection offset: **0.85 blocks forward**, with a small outward velocity.
- Clay Grinder recipe count: **0**.

## Assets and licenses

No texture, model, sound, or other art asset is changed in alpha.21.7. The strict human-made texture/provenance rules from alpha.21.4 remain unchanged.

## Advancement coverage

No new advancement is required for this bugfix batch. Existing Clay Grinder, kiln, Fired Clay, Super Heated Clay, and Flint Multitool advancement nodes remain valid because the patch changes interaction behavior rather than introducing a new progression step.

## Validation

The normal Gradle/Loom compile task cannot run in this artifact environment because the Fabric Loom 1.14.10 plugin artifact is not available to the local Gradle plugin cache. The release validator and direct Minecraft 1.21.11 signature checks are therefore used here; the patch should still be compiled through the project's normal `build.bat` on the user's machine.

## Known limitations

The Clay Grinder still intentionally uses the stonecutter-style screen shell as a UI prototype, but the recipe source is empty. A dedicated grinder recipe/menu implementation remains future work.

The full Gradle build still depends on Fabric Loom being available in the user's local build environment; Loom is not available in this artifact runner's plugin cache.
