# Project Flint v0.31.52-b — RecipeDisplay import hotfix

## Intent
Repair the compile failure introduced by v0.31.51-b's station-only Hardwood recipe type.

## Player-facing behavior
No changes to recipes, crafting timer, workstation access, tool durability, ore harvest rules, or gameplay. The mod should now get past the two missing-symbol compile diagnostics reported for `HardwoodCraftingRecipe`.

## Architecture
Use the Mojang-mapped `RecipeDisplay` interface in `net.minecraft.world.item.crafting.display`, consistent with `Recipe.display()` in Minecraft 1.21.11.

## Design reasoning
The previously imported package did not contain `RecipeDisplay`. Correct the import only, preserving the existing delegate-based wrapper and dedicated recipe serializers.

## Tuning snapshot
Unchanged from v0.31.51-b: Hardwood Crafting Table remains 60 server ticks per result; ore tiers and tool durability remain as shipped.

## Assets and licenses
No textures, models, sounds, or third-party assets changed.

## Advancement coverage
Unchanged; Flint Quests / progression rules are unaffected.

## Known limitations
No full Gradle build or in-game runtime test was available in this environment. The update addresses the two compiler diagnostics shown in the submitted build log, not any additional runtime issues.

## Validation
