# Project Flint v0.31.44-b

## Intent
Correct three regressions from the recent wooden-tool/Utility Vest and asset work without changing the intended early Wood progression.

## Player-facing behavior
- The Wooden Pickaxe cannot mine blocks tagged as requiring Stone, Iron, or Diamond tier. Iron Ore therefore remains completely unbreakable with the Wooden Pickaxe, including while the Tanned Utility Vest is equipped.
- The Tanned Utility Vest does not upgrade mining tier. Its vegetation clearing and eligible player-placed recovery remain unchanged.
- Fat-Burning Torches require a supported top face beneath them when placed. If that support is removed later, the torch removes itself and drops instead of floating in midair.
- The Wooden Sheet item once again uses the original Project Flint sprite that shipped before v0.31.43-b. The `woodsheet.png` supplied with the hardwood staging batch is no longer used for this item.

## Architecture
Wooden Pickaxe tier enforcement is applied consistently in mining-progress prediction, Fabric attack/break permission callbacks, and the authoritative server `destroyBlock` path. Fat-Burning Torch support uses the same center-support test used by Project Flint's existing standing torch logic and schedules removal when its supporting block disappears.

## Design reasoning
The Utility Vest is a convenience/progression item, not a mining-tier upgrade. A Wooden Pickaxe should never become capable of deleting Iron Ore simply because the Vest's player-placed recovery preview is active. Likewise, a torch should remain a supported fixture rather than an arbitrary floating block.

## Tuning snapshot
- Wooden Pickaxe Stone/Crushed Stone and existing approved masonry timings are unchanged.
- Fat-Burning Torch burn duration, charcoal capacity, ignition cost, rain behavior, and light level are unchanged.
- Utility Vest inventory, crafting-grid, vegetation, and placed-block recovery behavior are unchanged except that it cannot override higher pickaxe tiers.

## Assets and licenses
No new asset was introduced. `wooden_sheet.png` is restored byte-for-byte from the authoritative pre-v0.31.43 Project Flint source tree. The user-supplied hardwood staging assets remain otherwise unchanged.

## Advancement coverage
No advancement or Flint Quests changes.

## Known limitations
The Fat-Burning Torch remains a standing torch only; this patch does not add a separate wall-mounted variant.

## Validation
Check Iron Ore and other higher-tier ores with Wooden Pickaxe + Utility Vest; mining progress must remain zero and the block must not be removed. Check supported and unsupported Fat-Burning Torch placement, then remove the support beneath an existing torch. Confirm the Wooden Sheet inventory icon matches the pre-v0.31.43-b art.

## Next release pressure
Continue testing Utility Vest recovery against newly introduced block/tool tiers so convenience recovery never bypasses progression gating.
