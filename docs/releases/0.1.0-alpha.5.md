# Project Flint 0.1.0-alpha.5 — Focused Playtest Corrections

## Intent
Apply only the corrections requested from the alpha.4 playtest without re-tuning unrelated systems. This release explicitly restores behavior that alpha.4 changed beyond the user's request.

## Player-facing behavior
- The removed personal crafting area is still visually blank, but its cover now renders as part of the inventory background instead of over held/dragged items.
- Personal crafting slots are inactive and non-highlightable, preventing hover artifacts in the blank crafting area.
- Restores the alpha.3 Loose Rock visual model/texture and Rock inventory sprite presentation.
- Restores grass stripping to the alpha.3 speed: 156 active mining ticks rather than alpha.4's 468.
- Bush cutting is 1.75x slower than alpha.4, rounded from 59.5 to 60 active mining ticks.
- Runtime Adventure/Spectator restrictions and forced `isHardcore()` rewriting are removed. Spectator works normally again.
- World creation is constrained to Hardcore or Creative behavior, with Hard difficulty selected; Hard difficulty is still locked once the world starts.
- If a singleplayer world was created with commands/cheats disabled, its Open to LAN button is disabled rather than providing a route to enable them.
- Passive retaliation reach is reduced from 2.55 to 2.30 blocks.
- Generic passive retaliation damage is reduced from 3.0 to 2.5.
- Chicken retaliation damage is reduced from 3.0 to 2.0.
- Baby passive mobs do not join retaliation, except wolves.
- Wild wolf proactive aggro range is reduced from 36 to 24 blocks.

## Architecture introduced
- World-creation policy now lives in client world-creation UI mixins rather than rewriting runtime player game modes or the world's Hardcore flag.
- PauseScreenMixin owns the no-cheats Open-to-LAN restriction.
- Personal crafting slots are now explicitly inactive, separating hidden UI from the player's carried/dragged item rendering.

## Design reasoning
Alpha.4 overreached in two places: it changed grass timing a second time and enforced Hardcore semantics by overriding core runtime behavior. Alpha.5 corrects both. Project Flint's playtest loop should preserve working behavior unless a new note explicitly asks to change it. World-creation restrictions belong at world creation; normal Minecraft spectator behavior should remain available afterward.

## Tuning snapshot
- Grass strip progress: 1 / 156 per mining tick.
- Hand-clear foliage progress: 1 / 150 per mining tick.
- Bush cut progress: 1 / 60 per mining tick.
- Passive retaliation reach: 2.30 blocks.
- Generic passive retaliation damage: 2.5.
- Chicken retaliation damage: 2.0.
- Wild wolf proactive aggro range: 24 blocks.

## Assets and licensing
No new third-party assets are introduced. Alpha.5 deliberately restores Project Flint's alpha.3 temporary Loose Rock texture/model instead of alpha.4's Minecraft-stone placeholder treatment. Bush visuals remain unchanged from alpha.4.

## Validation performed
- Parsed all JSON resources.
- Verified the active forage/worldgen graph remains unchanged from alpha.4.
- Verified alpha.5's exact requested tuning constants.
- Verified the runtime Hardcore/Spectator enforcement mixins (`PrimaryLevelDataMixin` and `ServerPlayerMixin`) are no longer registered while the primitive block-breaking `ServerPlayerGameModeMixin` remains active.
- Verified world-creation and Open-to-LAN client mixins are registered.
- Verified the personal crafting cover moved to background rendering and personal crafting slots are inactive.
- Verified the Loose Rock and Rock item models resolve back to the alpha.3 placeholders.

## Known limitations
- The create-world game-mode cycle is constrained through the world-creation state. Minecraft may still internally attempt to select Survival while cycling, but Project Flint immediately resolves that selection to Hardcore, leaving Hardcore and Creative as the usable choices.
- This environment cannot launch the Fabric client, so the local build/run remains the final mixin and visual validation gate.

Continue from the next explicit playtest notes without re-tuning already accepted behavior.
