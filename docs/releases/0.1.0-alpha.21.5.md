# Project Flint 0.1.0-alpha.21.5

## Summary
This patch tightens the clay-workstation presentation and placement rules without reintroducing any assistant-authored texture work.

## Changes
- disables phantom spawning by default by forcing `doInsomnia` off during server startup;
- makes the crude clay kiln face the player on placement;
- prevents crude clay kilns from being placed on air and breaks them if their support is removed;
- rotates the crude clay kiln multipart blockstate/model by facing;
- adjusts the baked kiln top model/collision so the upper chimney visually joins the lower base more cleanly;
- rebuilds the clay grinder model so the visible top piece is a saw blade instead of the previous stray protrusion;
- adds `clay_grinder_saw.png` as an exact unmodified copy of the supplied human-made `stonecutter_saw.png` asset.

## Texture policy
No generated or edited texture pixels were introduced in this patch. The only added texture file is a direct copy from the approved source pack.

## Expected player-facing result
- crude kilns no longer float or ignore the player-facing placement direction;
- the kiln top no longer has the small visual disconnect from the lower body;
- the clay grinder once again shows an actual saw piece rather than the odd top nub;
- phantoms stay disabled by default.
