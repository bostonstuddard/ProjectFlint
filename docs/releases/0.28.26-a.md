# Project Flint v0.28.26-a

## Intent
Repair several progression leaks and restore important player guidance while laying the first hidden-groundwater foundation for the future Well system.

## Player-facing behavior
- Horses no longer drop vanilla Leather; each horse kill has a 50% chance for 1 Raw Leather and independently a 50% chance for 1 Animal Bones.
- Night Vision and Creative mode now bypass Project Flint true darkness instead of remaining trapped under the hardened nighttime lightmap.
- Important concise advancement milestones return for Crude Stone Cutters, direct plant-string harvesting, Filed Bone/Bone Club/Bone Firestarter, Woven Wool/Sleeping Bag/Bone Brush, Clay Pot progression, and late Flint tool pieces/upgrades.
- Advancement tab backgrounds now visually match their era: Stone for Tool Era, Clay for Clay Era, and Oak Planks for Wood Era.
- Crimson and Warped wood conversion recipes are removed from Clay/Wooden Grinder processing.
- A creative-only Aquifer Finder can reveal nearby generated Project Flint aquifers for development/testing.

## Architecture
Project Flint aquifers are generated as a recognizable five-source-water cross roughly 20–26 blocks below local terrain, with a clay seal below the center used as a lightweight natural signature. `AquiferSystem` centralizes detection and biome-yield categories so a later Well multiblock can query the same groundwater data without changing worldgen. The Aquifer Finder only visualizes this shared system and has no survival recipe.

Creative true-darkness bypass is implemented by routing Creative through Minecraft's existing NightVisionFactor lightmap input. Night Vision/Creative then use a vanilla-style lightmap branch, while normal survival remains on Project Flint's hardened true-darkness branch.

## Design reasoning
Horse drops should feed Project Flint's existing hide/bone progression instead of leaking vanilla Leather. Advancement pages should remain short mini-guides, but removing meaningful tool and yield upgrades made progression harder to understand, so those milestones are restored without returning to the old micro-advancement clutter.

Aquifers are deliberately small and hidden. Their value is not a free underground lake; they create discoverable groundwater sites that future settlement infrastructure can exploit.

## Tuning snapshot
- Horse Raw Leather: 50% chance ×1.
- Horse Animal Bones: 50% chance ×1.
- Aquifer water body: 5 source blocks.
- Aquifer depth: approximately 20–26 blocks below local surface.
- Aquifer generation attempts: humid 1/5 chunks, temperate 1/12, arid 1/30.
- Future Well yield multipliers: Scarce 0.25×, Normal 0.60×, Good 0.85×, Abundant 1.20×.
- Aquifer Finder search radius: 96 blocks, maximum 8 highlighted results.

## Assets and licenses
No new texture pixels are introduced. Aquifer Finder reuses Minecraft's compass item model as a temporary creative-development visual.

## Advancement coverage
The Tool/Clay/Wood era split remains. Twelve useful guidance milestones have been restored or added while keeping descriptions to short one-sentence instructions. Era backgrounds are Stone, Clay, and Oak Planks respectively.

## Known limitations
- The future Well multiblock is intentionally not implemented in this release.
- Aquifer groundwater is represented by a compact generated signature rather than a full geological simulation.
- The creative Aquifer Finder highlights generated Project Flint aquifers only; it is not a general vanilla-cave-water detector.
- A full Gradle build still depends on Fabric Loom being available to the build environment.

## Validation
The release validator checks horse resource replacement, true-darkness bypass wiring, restored advancement guidance/backgrounds, Nether-wood grinder removal, aquifer registration/worldgen/finder/future-Well query hooks, resource JSON syntax, versioning, and established Project Flint invariants.

## Next release pressure
Design the Well multiblock around `AquiferSystem.findBelow`, including construction materials, extraction cadence, storage, and how biome groundwater yield should interact with drought/rainfall systems later.
