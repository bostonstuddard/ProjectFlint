# Project Flint v0.31.41-b

## Intent
Remove the overly powerful Tool Belt while fixing primitive harvesting permissions and drops.

## Player-facing behavior
- Tool Belt remains obtainable in Creative only, with no crafting recipe, equip bonus, armor penalty, or functional tooltip.
- Wooden Axe now mines regular and stripped logs through both mining and break-permission rules.
- A Grass Block can be scraped for Plant Fiber only with an empty main hand. Wooden Shovels and Multitools retain their purpose-built block processing; irrelevant tools cannot scrape for Fiber.
- A Wooden Shovel mining a Grass Path returns Dirt rather than a Path block.
- Leaves require a real harvesting interval even with the Utility Vest, regardless of held item; existing Plant Cutter tier timings remain available.

## Architecture
Disabled the legacy Tool Belt in its item property factory and removed its separate mining-speed path; the item ID and model remain usable in Creative. Mining rules are aligned across the attack callback, server break permission, mining progress and completion handler. No PF-EMI plugin was reintroduced.

## Design reasoning
Hand scraping must not allow a pickaxe or other unrelated tool to generate Fiber. Log harvest was blocked by the permission callbacks despite having a Wooden Axe mining-progress and drop route. Existing vanilla Grass Path drops were overridden by a custom shovel recovery branch. A Utility Vest privilege should confer harvest permission rather than instantaneous destruction of leaf blocks with every held item.

## Tuning snapshot
- Tool Belt: no crafting, armor or speed bonuses; creative item remains.
- Wooden Axe log speed: existing slow rule (minimum 1/105 progress per tick), no balance change.
- Utility Vest leaf harvest: 1/40 progress per tick; special cutters keep their tier-specific progression.
- Hand Grass scrape timing/fiber chance: unchanged; main hand must be empty.
- Wooden Shovel Grass Path: 1 Dirt.

## Assets and licenses
No new textures, models, audio, or external assets.

## Advancement coverage
No advancements or new recipes. Tool Belt entry removed from the personal-crafting recipe guide along with the real recipe.

## Known limitations
A full Gradle compilation and in-game verification require the host Minecraft/Fabric dependencies. Existing player inventories may retain Tool Belt stacks, but these are inert.

## Validation
Release validator and simulated patch application checked. Java syntax parsing is distinct from a full Gradle/loader test.

## Next release pressure
Test in Survival with and without the Utility Vest: bare-hand Grass scraping, invalid tools on Grass, Wooden Axe on normal/stripped logs, shovel Grass Path drops, and regular leaves under different held items.
