# Project Flint v0.27.5-a

## World / placement
- Place-in-World displays are lowered to sit almost flush with the supporting surface.
- Crushed Stone now falls like a gravity block.
- Crushed Stone Slabs now exist, fall with gravity, and are made 1 Crushed Stone -> 2 slabs in the Clay Grinder or Wooden Grinder. Two slabs can be ground back into one Crushed Stone.
- Breaking Dirt or Grass Block with any multitool checks the six directly adjacent faces; each adjacent vanilla Dirt block independently has a 50% chance to become Loose Soil.
- Loose Soil looks like Loose Dirt, falls with gravity, and yields ordinary Dirt rather than Loose Dirt.

## Kilns
- Mortar Kiln uses the Advanced Kiln front/back/left/right/top/bottom textures on one 16x16x16 block, without 2x2 UV slicing.
- Mortar Kiln Base uses the Baked Clay Kiln lower/body geometry but with Mortar Bricks as its texture.

## Inventory / stacks
- Food tooltip now displays Hunger and Saturation on separate lines.
- Vanilla foods that previously stacked to 64 now stack to 16.
- Vanilla Leather stacks to 16.
- Project Flint stack sizes were updated to the requested values; see `docs/reference/STACK_SIZES_v0.27.5-a.md`.
