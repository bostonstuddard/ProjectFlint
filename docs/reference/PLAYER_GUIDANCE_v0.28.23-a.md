# Player Guidance Reference — v0.28.23-a

## Advancements
Project Flint progression is split into **Tool Era**, **Clay Era**, and **Wood Era**. Advancement descriptions should remain compact one-sentence mini-guides that point toward the next meaningful action.

## Recipe discovery
Do **not** expose or repurpose Minecraft's survival recipe book. Project Flint survival inventory recipe-book access stays hidden/disabled.

Recipe discovery belongs to the custom workstation guide:
- Clay Grinder → **Recipes**
- Wooden Grinder → **Recipes**
- Advanced Kiln → **Recipes**

The custom screen may browse the supported Project Flint processing stations, but its entry points remain the workstation GUIs rather than the vanilla inventory.
