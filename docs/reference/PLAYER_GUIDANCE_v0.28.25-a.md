# Player Guidance Reference — v0.28.25-a

- Survival's vanilla recipe book remains hidden and disabled.
- Press **K** to open Project Flint's custom recipe guide.
- Clay Grinder, Wooden Grinder, and Advanced Kiln expose the same guide through an inset Book icon in their title bars.
- Hover guide ingredient/output icons to see their item names.
- The Advanced Kiln guide must contain only Advanced Kiln processes; Wattled Daub Bricks are not an Advanced Kiln recipe.
