# Project Flint v0.28.0-a — Expanded Meat System

## New meats
- Fox, Frog, Goat, Horse, Llama, Dolphin, Polar Bear, and Camel now have raw and cooked meat items.
- All new meats stack to 16.
- Raw variants use Project Flint's shared raw-meat sickness profile.
- Raw variants can be cooked anywhere the existing primitive meat recipes work.
- Animals killed while burning drop the cooked form directly.

## Drop balance
- Fox: 1
- Frog: 1
- Goat: 1–2
- Horse: 2–3
- Llama: 2–3
- Dolphin: 1–2
- Polar Bear: 2–4
- Camel: 3–4
- Baby mobs do not produce the new meat drops.
